## 二、RLDS 数据格式深入解析

### 2.1 什么是 RLDS？

```
RLDS = Reinforcement Learning Datasets
├── 由DeepMind开发
├── 基于TensorFlow Datasets (tfds) 构建
├── 标准化的序列化格式
├── 支持多embodiment统一存储
└── 设计目标：统一机器人数据格式，方便跨数据集研究
```

```
┌──────────────────────────────────────────────────────────────────┐
│                     RLDS 格式层次结构                              │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Level 1: tfds.Dataset                                           │
│  ├── 包含所有episodes                                            │
│  ├── 支持 split (train/val/test)                                 │
│  └── 类似一个"数据库表"                                           │
│                                                                  │
│  Level 2: Episode                                                │
│  ├── 一条完整轨迹                                                │
│  ├── 包含 steps[] 列表                                           │
│  └── 包含 metadata                                               │
│                                                                  │
│  Level 3: Step                                                   │
│  ├── observation (dict of arrays)                                │
│  ├── action (array)                                              │
│  ├── reward, discount, is_first, is_terminal                     │
│  └── 单步数据                                                    │
│                                                                  │
│  存储：TFRecord格式，高效IO                                       │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 2.3 RLDS 数据加载核心代码

```python
"""
RLDS 数据加载 - 从底层理解
"""

import tensorflow as tf
import tensorflow_datasets as tfds
import numpy as np

# ============================================================
# 方法1：最直接的 tfds 加载（理解原理）
# ============================================================

def load_rlds_basic(dataset_name="bridge_v2", data_dir=None):
    """
    最基础的RLDS加载方式
    
    注意：这里用的是 tensorflow_datasets，不是 pytorch
    后续需要转换为 PyTorch 兼容格式
    """
    # 加载数据集
    # split="train" 表示加载训练集
    dataset = tfds.load(
        dataset_name,
        data_dir=data_dir,      # 数据存储路径
        split="train",
    )
    
    # dataset 是一个 tf.data.Dataset 对象
    # 每个元素是一个 episode（不是step！）
    
    for episode in dataset.take(1):  # 取1条episode看结构
        print("=" * 50)
        print("Episode结构：")
        print(f"  keys: {list(episode.keys())}")
        
        steps = episode["steps"]
        print(f"  steps数量: {len(list(steps))}")
        
        # 遍历前3步
        for i, step in enumerate(steps):
            if i >= 3:
                break
            print(f"\n  Step {i}:")
            print(f"    observation keys: {list(step['observation'].keys())}")
            print(f"    image shape: {step['observation']['image'].shape}")
            print(f"    image dtype: {step['observation']['image'].dtype}")
            print(f"    action shape: {step['action'].shape}")
            print(f"    action dtype: {step['action'].dtype}")
            print(f"    action values: {step['action'].numpy()}")
            print(f"    is_first: {step['is_first'].numpy()}")
            print(f"    is_terminal: {step['is_terminal'].numpy()}")
    
    return dataset

# 运行输出示例：
"""
Episode结构：
  keys: ['steps', 'episode_metadata']
  steps数量: 48

  Step 0:
    observation keys: ['image', 'state']
    image shape: (480, 640, 3)
    image dtype: uint8
    action shape: (7,)
    action dtype: float32

    is_terminal: False

  Step 1:
    ...

# ============================================================
# 方法2：RLDS → Flat Step 索引（OpenVLA实际使用）
# ============================================================

class RLDSStepIndexBuilder:
    """
    核心问题：RLDS是episode结构，但训练需要随机采样单个step
    
    解决方案：预构建flat索引
    
    原始RLDS：
        Episode 0: [step0, step1, ..., step47]    48步
        Episode 1: [step0, step1, ..., step31]    32步
        Episode 2: [step0, step1, ..., step55]    55步
        ...
    
    Flat索引：
        (0, 0), (0, 1), ..., (0, 47),
        (1, 0), (1, 1), ..., (1, 31),
        (2, 0), (2, 1), ..., (2, 55),
        ...
    
    这样就能通过单个idx随机访问任意step
    """
    
    def __init__(self, tfds_dataset):
        self.dataset = tfds_dataset
        self.index = []  # [(episode_idx, step_idx), ...]
        self.episode_lengths = []
        
        self._build()
    
    def _build(self):
        """
        遍历数据集构建索引
        这是一次性操作，可能较慢（取决于数据集大小）
        """
        print("Building step index...")
        for ep_idx, episode in enumerate(self.dataset):
            # 计算episode长度
            steps = episode["steps"]
            ep_len = len(list(steps))
            self.episode_lengths.append(ep_len)
            
            # 为每个step创建索引项
            for step_idx in range(ep_len):
                self.index.append((ep_idx, step_idx))
            
            if ep_idx % 1000 == 0:
                print(f"  Processed {ep_idx} episodes, "
                      f"{len(self.index)} steps so far")
        
        self.total_steps = len(self.index)
        self.total_episodes = len(self.episode_lengths)
        
        print(f"Index built: {self.total_episodes} episodes, "
              f"{self.total_steps} steps")
        print(f"Avg episode length: "
              f"{np.mean(self.episode_lengths):.1f} steps")
    
    def __len__(self):
        return self.total_steps
    
    def __getitem__(self, idx):
        ep_idx, step_idx = self.index[idx]
        return ep_idx, step_idx
```

### 2.4 PyTorch兼容的RLDS Dataset

```python
"""
将RLDS数据集包装为PyTorch Dataset
这是OpenVLA训练的核心数据组件
"""

import torch
from torch.utils.data import Dataset
import tensorflow_datasets as tfds
import numpy as np
from PIL import Image
from torchvision import transforms


class BridgeDataRLDSDataset(Dataset):
    """
    BridgeData v2 的PyTorch Dataset
    
    设计考量：
    1. RLDS底层是TensorFlow → 需要转numpy → 转torch
    2. Episode结构 → Flat step采样
    3. 图像预处理在__getitem__中完成
    4. 动作归一化需要预先计算的统计量
    """
    
    def __init__(
        self,
        data_dir,               # 数据存储路径
        dataset_name="bridge_v2",
        split="train",
        image_size=384,          # OpenVLA输入尺寸
        num_episodes=None,       # 加载多少episode（None=全部）
        obs_key="image",         # 使用哪个相机
        action_dim=7,
    ):
        super().__init__()
        
        self.image_size = image_size
        self.obs_key = obs_key
        self.action_dim = action_dim
        
        # ========== 1. 加载RLDS ==========
        print(f"Loading {dataset_name} from {data_dir}...")
        self.tfds_dataset = tfds.load(
            dataset_name,
            data_dir=data_dir,
            split=split,
        )
        
        if num_episodes is not None:
            self.tfds_dataset = self.tfds_dataset.take(num_episodes)
        
        # ========== 2. 预构建索引 + 缓存episode长度 ==========
        # 注意：RLDS的tf.data.Dataset不支持len()
        # 需要遍历一遍构建索引
        self._preprocess_dataset()
        
        # ========== 3. 图像预处理pipeline ==========
        self.image_transform = self._build_image_transform()
        
        # ========== 4. 加载动作统计量 ==========
        self._load_action_statistics()
        
        print(f"Dataset ready: {len(self)} steps from "
              f"{self.num_episodes} episodes")
    
    def _preprocess_dataset(self):
        """
        预处理：构建flat索引 + 预加载episode数据到内存
        
        注意：BridgeData约60K episodes, 2.4M frames
        全部预加载需要较大内存（~50GB for images）
        
        两种策略：
        A. 预加载到内存：快但费内存
        B. 每次从磁盘读：慢但省内存
        
        OpenVLA论文用的是策略B（lazy loading）
        这里演示策略A（更直观）
        """
        print("Building index and caching episode data...")
        
        self.episode_data = []   # 缓存所有episode
        self.step_index = []     # flat索引
        
        for ep_idx, episode in enumerate(self.tfds_dataset):
            steps = list(episode["steps"])
            ep_length = len(steps)
            
            # 缓存这个episode的step数据
            ep_steps = []
            for step_idx, step in enumerate(steps):
                ep_steps.append({
                    "image": step["observation"][self.obs_key].numpy(),
                    "action": step["action"].numpy()[:self.action_dim],
                    "is_first": step["is_first"].numpy(),
                })
                self.step_index.append((ep_idx, step_idx))
            
            self.episode_data.append(ep_steps)
            
            if ep_idx % 5000 == 0:
                print(f"  Processed {ep_idx} episodes...")
        
        self.num_episodes = len(self.episode_data)
        self.total_steps = len(self.step_index)
        
        # 计算episode长度统计
        ep_lengths = [len(ep) for ep in self.episode_data]
        print(f"  Episodes: {self.num_episodes}")
        print(f"  Total steps: {self.total_steps}")
        print(f"  Avg ep length: {np.mean(ep_lengths):.1f}")
        print(f"  Min/Max ep length: {min(ep_lengths)}/{max(ep_lengths)}")
    
    def _build_image_transform(self):
        """
        图像预处理pipeline
        
        OpenVLA的图像处理：
        1. PIL转换
        2. Resize到384×384（ViT输入要求）
        3. ToTensor：[0,255] → [0,1]
        4. Normalize：ImageNet均值/标准差
        
        为什么用ImageNet统计量？
        → SigLIP和DINOv2都在ImageNet上预训练
        → 输入分布匹配预训练分布
        """
        return transforms.Compose([
            # Step 1: Resize
            transforms.Resize(
                (self.image_size, self.image_size),
                interpolation=transforms.InterpolationMode.BICUBIC
            ),
            # BICUBIC插值质量最高，适合ViT的patch化
            
            # Step 2: ToTensor
            transforms.ToTensor(),
            # numpy [H,W,C] uint8 → torch [C,H,W] float32 [0,1]
            
            # Step 3: Normalize
            transforms.Normalize(
                mean=[0.485, 0.456, 0.406],  # ImageNet RGB均值
                std=[0.229, 0.224, 0.225],   # ImageNet RGB标准差
            ),
            # 标准化后：每个通道均值≈0，标准差≈1
        ])
    
    def _load_action_statistics(self):
        """
        加载或计算动作统计量
        用于min-max归一化到 [-1, 1]
        
        为什么需要归一化？
        → 不同维度的动作量纲不同（米 vs 弧度）
        → 不同embodiment的动作范围不同
        → 统一到[-1,1]让模型更容易学习
        → 离散化时256个bins均匀分布有意义
        
        预计算方式：
        遍历所有数据，统计每个维度的min/max
        """
        # 尝试加载预计算的统计量
        stats_path = f"action_stats/bridge_v2.npz"
        
        try:
            stats = np.load(stats_path)
            self.action_min = stats["min"]  # [7]
            self.action_max = stats["max"]  # [7]
            print(f"Loaded action stats from {stats_path}")
        except FileNotFoundError:
            print("Computing action statistics from data...")
            all_actions = []
            for ep in self.episode_data:
                for step in ep:
                    all_actions.append(step["action"])
            
            all_actions = np.stack(all_actions)  # [N, 7]
            self.action_min = all_actions.min(axis=0)  # [7]
            self.action_max = all_actions.max(axis=0)  # [7]
            
            # 保存
            np.savez(stats_path, min=self.action_min, max=self.action_max)
            print(f"Saved action stats to {stats_path}")
        
        print(f"Action range per dimension:")
        dim_names = ["Δx", "Δy", "Δz", "Δrx", "Δry", "Δrz", "grip"]
        for i, name in enumerate(dim_names):
            print(f"  {name}: [{self.action_min[i]:.4f}, "
                  f"{self.action_max[i]:.4f}]")
    
    def normalize_action(self, action):
        """Min-max归一化到 [-1, 1]"""
        normed = 2.0 * (action - self.action_min) / \
                 (self.action_max - self.action_min + 1e-8) - 1.0
        return np.clip(normed, -1.0, 1.0)
    
    def denormalize_action(self, action_normed):
        """反归一化"""
        return (action_normed + 1.0) / 2.0 * \
               (self.action_max - self.action_min) + self.action_min
    
    def __len__(self):
        return self.total_steps
    
    def __getitem__(self, idx):
        """
        获取一个训练样本
        
        Args:
            idx: flat step索引
            
        Returns:
            dict: {
                "image": [3, 384, 384],
                "action": [7],
                "action_raw": [7],  (未归一化，评估用)
                "episode_idx": int,
                "step_idx": int,
                "is_first": bool,
            }
        """
        ep_idx, step_idx = self.step_index[idx]
        step_data = self.episode_data[ep_idx][step_idx]
        
        # ====== 图像处理 ======
        # 原始: numpy [480, 640, 3] uint8
        image_raw = step_data["image"]
        
        # numpy → PIL → transform → tensor
        image_pil = Image.fromarray(image_raw)
        image_tensor = self.image_transform(image_pil)
        # 结果: [3, 384, 384] float32, normalized
        
        # ====== 动作处理 ======
        action_raw = step_data["action"].astype(np.float32)  # [7]
        action_normed = self.normalize_action(action_raw).astype(np.float32)
        
        return {
            "image": image_tensor,                     # [3, 384, 384]
            "action": torch.from_numpy(action_normed), # [7], [-1, 1]
            "action_raw": torch.from_numpy(action_raw),# [7], 原始值
            "episode_idx": ep_idx,
            "step_idx": step_idx,
            "is_first": step_data["is_first"],
        }
```

### 3.3 SimplerEnv 使用代码

```python
"""
SimplerEnv 评估流程
完整展示如何用仿真环境评估OpenVLA
"""

import numpy as np
import torch
from PIL import Image

def evaluate_openvla_in_simplerenv(
    model,
    processor,
    env_name="GoogleRobotPickCokeCanVisual",
    num_episodes=100,
    max_steps_per_episode=80,
    device="cuda",
):
    """
    在SimplerEnv中评估OpenVLA
    
    流程：
    1. 创建仿真环境
    2. 重置环境获取初始观察
    3. 用OpenVLA预测动作
    4. 在环境中执行动作
    5. 检查是否成功
    6. 重复直到完成或超时
    """
    import simplerenv
    from simplerenv import make
    
    # ====== Step 1: 创建环境 ======
    env = make(env_name)
    # 环境提供：
    # - reset() → observation (image + state)
    # - step(action) → (observation, reward, done, info)
    # - observation 包含 image: [480, 640, 3]
    
    # ====== Step 2: 定义任务指令 ======
    task_instructions = {
        "GoogleRobotPickCokeCanVisual": "pick up the coke can",
        "GoogleRobotMoveNear": "move the object near the target",
        "GoogleRobotOpenDrawer": "open the top drawer",
    }
    instruction = task_instructions.get(env_name, "complete the task")
    prompt = f"In: What action should the robot take to {instruction}?\nOut:"
    
    # ====== Step 3: 评估循环 ======
    successes = []
    episode_rewards = []
    
    for ep_idx in range(num_episodes):
        # 重置环境
        obs = env.reset()
        # obs: dict with "image": np.ndarray [480, 640, 3]
        
        episode_reward = 0
        done = False
        
        for step in range(max_steps_per_episode):
            # ---- 3a. 获取当前观察 ----
            image = obs["image"]  # numpy [480, 640, 3] uint8
            
            # ---- 3b. 预处理输入 ----
            image_pil = Image.fromarray(image)
            inputs = processor(prompt, image_pil).to(device, dtype=torch.bfloat16)
            
            # ---- 3c. OpenVLA推理 ----
            with torch.no_grad():
                action = model.predict_action(
                    **inputs,
                    unnorm_key="bridge_orig",
                    do_sample=False,
                )
            
            # ---- 3d. 动作格式确认 ----
            # predict_action 内部通常已经完成：
            # generate action token ids → decode_token_ids_to_actions → unnormalize action
            action = np.asarray(action, dtype=np.float32)
            
            # ---- 3e. 执行动作 ----
            obs, reward, done, info = env.step(action)
            episode_reward += reward
            
            if done:
                break
        
        # 记录结果
        success = info.get("success", False)
        successes.append(success)
        episode_rewards.append(episode_reward)
        
        if ep_idx % 10 == 0:
            recent_sr = np.mean(successes[-10:]) if successes else 0
            print(f"Episode {ep_idx}/{num_episodes}: "
                  f"success={success}, "
                  f"running_SR={recent_sr:.2%}")
    
    # ====== Step 4: 汇总结果 ======
    results = {
        "success_rate": np.mean(successes),
        "avg_reward": np.mean(episode_rewards),
        "num_episodes": num_episodes,
        "per_episode": list(zip(range(num_episodes), successes, episode_rewards)),
    }
    
    print("\n" + "=" * 60)
    print(f"评估结果 - {env_name}")
    print("=" * 60)
    print(f"成功率: {results['success_rate']:.2%}")
    print(f"平均奖励: {results['avg_reward']:.3f}")
    print(f"评估episodes: {num_episodes}")
    
    return results
```

### 4.2 动作预处理全流程

```python
"""
动作预处理：原始数据 → 模型可学习的格式

完整流程：
原始动作 → 范围裁剪 → Min-Max归一化 → [-1,1] → 256 bins量化 → token ID
"""

class ActionPreprocessor:
    """
    动作预处理器
    处理从原始传感器数据到模型训练标签的完整转换
    """
    
    def __init__(self, action_stats, tokenizer, n_bins=256, action_dim=7):
        """
        Args:
            action_stats: dict with 'min' and 'max' arrays
            tokenizer: OpenVLA tokenizer，用于获取 vocab_size
            n_bins: 离散化bin数量
            action_dim: 动作维度
        """
        self.action_min = action_stats['min']  # [7]
        self.action_max = action_stats['max']  # [7]
        self.tokenizer = tokenizer
        self.vocab_size = tokenizer.vocab_size
        self.n_bins = n_bins
        self.action_dim = action_dim
        
        # 计算每个维度的实际范围
        self.action_range = self.action_max - self.action_min
        
        # bin大小（用于量化）
        self.bin_size = 2.0 / n_bins  # 因为目标范围是[-1, 1]
    
    def preprocess_full_pipeline(self, raw_action):
        """
        完整预处理pipeline演示
        
        Args:
            raw_action: [7] 原始动作值
            
        Returns:
            action_token_ids: [7] token IDs (用于训练)
        """
        print(f"\n{'='*60}")
        print("动作预处理完整Pipeline")
        print(f"{'='*60}")
        
        # ====== Step 1: 原始动作 ======
        print(f"\n[Step 1] 原始动作")
        print(f"  值: {raw_action}")
        print(f"  含义: Δx={raw_action[0]:.4f}m, Δy={raw_action[1]:.4f}m, "
              f"Δz={raw_action[2]:.4f}m")
        print(f"         Δrx={raw_action[3]:.4f}rad, Δry={raw_action[4]:.4f}rad, "
              f"Δrz={raw_action[5]:.4f}rad")
        print(f"         gripper={raw_action[6]:.1f}")
        
        # ====== Step 2: 数值裁剪 ======
        # 防止异常值
        clipped = np.clip(raw_action, 
                          self.action_min - 0.1 * self.action_range,
                          self.action_max + 0.1 * self.action_range)
        print(f"\n[Step 2] 裁剪 (防止异常值)")
        print(f"  裁剪后: {clipped}")
        
        # ====== Step 3: Min-Max归一化 → [-1, 1] ======
        normalized = 2.0 * (clipped - self.action_min) / \
                     (self.action_range + 1e-8) - 1.0
        normalized = np.clip(normalized, -1.0, 1.0)
        
        print(f"\n[Step 3] Min-Max归一化 → [-1, 1]")
        print(f"  公式: norm = 2 * (x - min) / (max - min) - 1")
        print(f"  归一化后: {normalized}")
        print(f"  范围检查: [{normalized.min():.4f}, {normalized.max():.4f}]")
        
        # 验证一个维度的计算
        i = 0
        print(f"\n  [验证] dim {i} (Δx):")
        print(f"    原始: {raw_action[i]:.6f}")
        print(f"    min={self.action_min[i]:.6f}, max={self.action_max[i]:.6f}")
        print(f"    norm = 2×({raw_action[i]:.6f} - {self.action_min[i]:.6f}) "
              f"/ ({self.action_range[i]:.6f}) - 1")
        print(f"         = {normalized[i]:.6f}")
        
        # ====== Step 4: 量化为Bin Index ======
        # [-1, 1] → [0, 255]
        bin_indices = np.clip(
            ((normalized + 1.0) / 2.0 * self.n_bins).astype(int),
            0, self.n_bins - 1
        )
        
        print(f"\n[Step 4] 量化为Bin Index [0, {self.n_bins-1}]")
        print(f"  公式: bin = int((norm + 1) / 2 × {self.n_bins})")
        print(f"  Bin indices: {bin_indices}")
        print(f"  Bin size: {self.bin_size:.6f} (= 2.0 / {self.n_bins})")
        
        # ====== Step 5: 映射到词表末尾共享action token ======
        # 官方口径：使用 tokenizer.vocab_size 末尾 n_bins 个 token 作为共享动作bin。
        # 这里用 vocab_size 代表 tokenizer.vocab_size。
        action_token_ids = self.vocab_size - (bin_indices + 1)
        
        print(f"\n[Step 5] 映射到词表末尾共享action token")
        print(f"  token_id = vocab_size - (bin_index + 1)")
        print(f"  Token IDs: {action_token_ids}")
        
        # ====== Step 6: 验证反向解码 ======
        print(f"\n[Step 6] 反向验证 (Token → 连续动作)")
        decoded_bin = self.vocab_size - action_token_ids - 1
        decoded_normalized = (decoded_bin + 0.5) / self.n_bins * 2.0 - 1.0
        decoded_original = (decoded_normalized + 1.0) / 2.0 * \
                          self.action_range + self.action_min
        
        print(f"  解码后 (归一化): {decoded_normalized}")
        print(f"  解码后 (原始): {decoded_original}")
        print(f"  量化误差: {np.abs(raw_action - decoded_original)}")
        print(f"  最大量化误差: {np.abs(raw_action - decoded_original).max():.6f}")
        
        return action_token_ids
    
    def compute_quantization_error(self, all_actions):
        """
        计算整个数据集的量化误差统计
        面试时可展示对精度的理解
        """
        errors = []
        for action in all_actions:
            # 正向
            normed = 2.0 * (action - self.action_min) / \
                     (self.action_range + 1e-8) - 1.0
            normed = np.clip(normed, -1.0, 1.0)
            bins = np.clip(
                ((normed + 1.0) / 2.0 * self.n_bins).astype(int),
                0, self.n_bins - 1
            )
            # 反向
            decoded_normed = (bins + 0.5) / self.n_bins * 2.0 - 1.0
            decoded = (decoded_normed + 1.0) / 2.0 * \
                      self.action_range + self.action_min
            
            errors.append(np.abs(action - decoded))
        
        errors = np.stack(errors)  # [N, 7]
        
        dim_names = ["Δx", "Δy", "Δz", "Δrx", "Δry", "Δrz", "grip"]
        print("\n量化误差统计 (256 bins):")
        print("-" * 60)
        for i, name in enumerate(dim_names):
            print(f"  {name}: mean={errors[:, i].mean():.6f}, "
                  f"max={errors[:, i].max():.6f}, "
                  f"std={errors[:, i].std():.6f}")
        
        # 物理意义转换
        print("\n物理意义（假设动作空间映射）:")
        print(f"  位置精度: ~{errors[:, :3].mean()*1000:.2f} mm (平均)")
        print(f"  旋转精度: ~{errors[:, 3:6].mean()*180/np.pi:.2f} ° (平均)")
        
        return errors
```

### 4.4 官方文件入口与复现注意事项

如果要把 D108 的知识落到 OpenVLA 复现里，建议优先对照这些官方入口：

| 目标 | 官方入口 | 作用 |
|---|---|---|
| LoRA/全参微调 | `vla-scripts/finetune.py` | 微调主入口，包含模型加载、LoRA、DDP、数据管线 |
| 动作token化 | `prismatic/vla/action_tokenizer.py` | 连续动作和共享 action bin token 的转换 |
| RLDS数据读取 | `prismatic/vla/datasets/rlds/` | RLDS Dataset、BatchTransform、数据混合 |
| OXE/Bridge转换 | `prismatic/vla/datasets/rlds/oxe/transforms.py` | 不同数据集字段到统一动作/观察格式的转换 |
| Bridge评估 | `experiments/robot/bridge/run_bridgev2_eval.py` | BridgeData/Bridge 环境相关评估入口 |

复现 BridgeData v2 时还要注意：

1. 官方脚本通常期待数据集 key/name 与动作统计量一致，例如 `bridge_orig`。
2. BridgeData v2 数据体量很大，完整下载和解压需要提前规划磁盘空间。
3. `unnorm_key` 必须和训练/评估所用数据统计量匹配，否则动作尺度会错。
4. 如果只做小实验，先用少量 episode 跑通 RLDS → batch → model forward，再扩大数据规模。
5. `ActionTokenizer` 的官方实现默认使用 tokenizer 词表最后 256 个 token 作为共享动作 bin，不要回到手写 `32000 + bin_index` 的旧理解。

"""
数据Pipeline中常见的bug及排查方法
面试和实战都很重要

def debug_data_pipeline(dataset, collator, tokenizer, num_samples=5):
    """
    数据Pipeline debug检查清单
    """
    print("=" * 60)
    print("Data Pipeline Debug检查")
    print("=" * 60)
    
    issues = []
    
    for i in range(min(num_samples, len(dataset))):
        sample = dataset[i]
        
        # ====== 检查1: 图像 ======
        image = sample["image"]
        
        # 形状检查
        assert image.shape == (3, 384, 384), \
            f"图像形状错误: {image.shape}, 期望 (3, 384, 384)"
        
        # 数值范围检查（归一化后应该在合理范围）
        if image.min() < -5 or image.max() > 5:
            issues.append(f"样本{i}: 图像数值异常 [{image.min():.2f}, {image.max():.2f}]")
        
        # 检查是否全黑/全白
        if image.std() < 0.01:
            issues.append(f"样本{i}: 图像几乎是常数 (std={image.std():.4f})")
        
        # NaN检查
        if torch.isnan(image).any():
            issues.append(f"样本{i}: 图像包含NaN!")
        
        # ====== 检查2: 动作 ======
        action = sample["action"]
        
        assert action.shape == (7,), \
            f"动作形状错误: {action.shape}, 期望 (7,)"
        
        # 归一化范围检查
        if action.min() < -1.1 or action.max() > 1.1:
            issues.append(f"样本{i}: 动作超出[-1,1]: [{action.min():.4f}, {action.max():.4f}]")
        
        # NaN检查
        if torch.isnan(action).any():
            issues.append(f"样本{i}: 动作包含NaN!")
        
        # Gripper值检查（通常是-1或1，或0或1）
        gripper = action[6]
        if abs(gripper) < 0.9 and abs(gripper) > 0.1:
            issues.append(f"样本{i}: gripper值不在极值: {gripper:.4f}")
    
    # ====== 检查3: Collator输出 ======
    batch_samples = [dataset[i] for i in range(min(4, len(dataset)))]
    batch = collator(batch_samples)
    
    print(f"\nBatch形状:")
    for key, val in batch.items():
        if isinstance(val, torch.Tensor):
            print(f"  {key}: {val.shape} {val.dtype}")
    
    # input_ids检查
    input_ids = batch["input_ids"]
    print(f"\nToken IDs范围: [{input_ids.min()}, {input_ids.max()}]")
    
    # labels检查
    labels = batch["labels"]
    print(f"Labels范围: [{labels.min()}, {labels.max()}]")
    
    # 检查action token是否在词表末尾共享bin范围内。
    # 注意：序列labels里可能有ignore_index=-100，应先过滤。
    valid_labels = labels[labels >= 0]
    action_begin = tokenizer.vocab_size - 256
    if valid_labels.numel() and (valid_labels.min() < action_begin or valid_labels.max() >= tokenizer.vocab_size):
        issues.append(f"Action token IDs超出预期范围: "
                     f"[{valid_labels.min()}, {valid_labels.max()}]")
    
    # ====== 汇总 ======
    print(f"\n{'='*60}")
    if issues:
        print(f"发现 {len(issues)} 个问题:")
        for issue in issues:
            print(f"  ❌ {issue}")
    else:
        print("✅ 所有检查通过!")
    print(f"{'='*60}")
    
    return issues

## 五、面试模拟

**Q1: 请描述BridgeData的完整数据流，从磁盘到模型输入。**

> **回答框架**：
> 1. 磁盘上以RLDS（TFRecord）格式存储
> 2. `tfds.load()` 读取为 `tf.data.Dataset`，每个元素是一个episode
> 3. 预构建flat索引 `(episode_idx, step_idx)`，实现O(1)随机访问
> 4. `__getitem__` 中：图像numpy→PIL→Resize(384)→Normalize；动作→min-max归一化→[-1,1]
> 5. Collator/BatchTransform：stack图像为`[B,3,384,384]`，tokenize文本为`[B,seq_len]`，把动作转成词表末尾共享bin token并构造序列labels
> 6. DataLoader：pin_memory + 多worker + 持久化worker
> 7. 送入模型：图像→视觉编码器→投影→visual tokens，拼接text tokens后送LLM

**Q2: 为什么用RLDS而不是HDF5？**

> **回答要点**：
> - OXE统一标准：22个embodiment用同一种格式
> - 高效IO：TFRecord支持并行读取和自动prefetch
> - 懒加载：不需要全部加载到内存
> - 生态：google推动，工具链成熟
> - 缺点：依赖TensorFlow，与PyTorch生态有摩擦

**Q3: 256 bins的动作离散化精度够吗？**

> **回答要点**：
> - 数学：2/256 ≈ 0.008，即每个bin宽度0.008
> - 位置：假设1对应0.5m，精度≈4mm，桌面操作够用
> - 旋转：假设1对应π，精度≈1.4°，多数场景够用
> - 局限：需要极高精度的任务（如精密装配）不够
> - 改进方案：FAST tokenizer（DCT压缩，更高精度+更少token数）
