> **优化新增：D110 学习导读**  
> D110 的重点是任务适配：当预训练 OpenVLA 在新任务上表现不够时，如何用 LoRA 或其他策略微调。  
> 核心问题：为什么微调？LoRA 微调和全参数微调如何取舍？数据集怎么组织？训练循环怎么写？训练曲线异常如何诊断？预训练和微调结果如何对比？  
> 当天产出建议：整理一份 LoRA 微调 checklist，并能解释 loss 下降但成功率不升的可能原因。

> **准确性与工程口径补充**  
> 下面的代码是为了讲清楚 LoRA、数据集、训练循环和曲线诊断的教学骨架，不应直接等同于某个 OpenVLA 仓库版本的完整官方脚本。真实项目中应优先参考当前仓库的 `finetune.py` / training scripts / config，并确认模型类、processor、action tokenizer、`unnorm_key`、数据 collator 与 checkpoint 保存方式。  
> PEFT 中更稳妥的任务类型写法通常是 `TaskType.CAUSAL_LM` 或按当前 PEFT 版本省略 `task_type` 后显式指定 `target_modules`；`TaskType.VLM` 不是通用稳定枚举。访问 `model.vision_backbone`、`model.projector`、`model.llm_backbone` 属于源码级示例，不保证所有分支都一致。

> **D110 的核心判断**  
> 微调不是为了让训练 loss 好看，而是为了提升目标任务的闭环成功率。训练 loss 下降但成功率不升，常见原因包括：动作反归一化错误、验证集分布不一致、数据质量差、gripper 标签噪声、过拟合、评估环境随机性太大、推理时 prompt / `unnorm_key` / action stats 与训练不一致。

> **训练标签关键修订**  
> VLA 微调时不能简单把 `labels` 理解成 `[B, 7]` 的动作 token 张量再直接传给 CausalLM。更严谨的做法是把 `prompt tokens + action tokens` 拼成完整 `input_ids`，同时构造同长度 `labels`，其中 prompt 部分置为 `-100`，只让 action token 位置参与 loss。下面原始代码保留为教学骨架，后面新增了更接近真实训练的 label mask 构造示例。

## 二、微调实战：LoRA微调详解

### 2.1 LoRA微调原理

```
LoRA (Low-Rank Adaptation) 原理：

原始权重矩阵 W ∈ ℝ^{d×k}
LoRA分解：W + ΔW = W + BA
其中 B ∈ ℝ^{d×r}, A ∈ ℝ^{r×k}, r << min(d,k)

ΔW = B × A (低秩分解)

优势：
1. 参数效率：只训练A和B，参数量从d×k减少到(d+k)×r
   原始: 7B参数 → LoRA(r=32): ~100M参数 (1.4%)
2. 显存效率：梯度和优化器状态大幅减少
3. 可组合性：不同任务的LoRA模块可插拔
4. 保持预训练：原始权重W不变，避免灾难性遗忘
```

```
LoRA 在 OpenVLA 中的应用：

┌─────────────────────────────────────────────────────────────────┐
│                    OpenVLA LoRA微调配置                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  应用层：LLM的注意力层和FFN层                                    │
│                                                                 │
│  目标模块：                                                     │
│  ├── q_proj: 查询投影 (Q = XW_q)                               │
│  ├── k_proj: 键投影 (K = XW_k)                                 │
│  ├── v_proj: 值投影 (V = XW_v)                                 │
│  ├── o_proj: 输出投影 (Attention_out = Attn×W_o)              │
│  ├── gate_proj: 门控投影 (SwiGLU中的门控)                      │
│  ├── up_proj: 上投影                                            │
│  └── down_proj: 下投影                                          │
│                                                                 │
│  典型配置：                                                     │
│  ├── rank (r): 32 或 64                                         │
│  ├── alpha: 32 或 64 (缩放因子)                                 │
│  ├── dropout: 0.1                                               │
│  └── 可训练参数: ~100M (r=32) 或 ~200M (r=64)                  │
│                                                                 │
│  对比全参数微调：                                                │
│  ├── 全参数: 7.0B可训练参数                                    │
│  ├── LoRA(r=32): 0.1B可训练参数 (1.4%)                         │
│  ├── LoRA(r=64): 0.2B可训练参数 (2.8%)                         │
│  └── 显存节省: ~60-70%                                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 完整微调代码实现

```python
"""
OpenVLA LoRA微调完整实现
包含数据准备、模型配置、训练和评估
"""

import torch
import torch.nn as nn
from torch.utils.data import DataLoader, Dataset
from transformers import (
    AutoModelForVision2Seq, 
    AutoProcessor, 
    AutoTokenizer,
    TrainingArguments,
    Trainer,
)
from peft import (
    LoraConfig, 
    get_peft_model, 
    prepare_model_for_kbit_training,
    TaskType,
)
import wandb
import numpy as np
from PIL import Image
import os

class OpenVLAFineTuner:
    """
    OpenVLA 微调器
    支持LoRA和全参数微调
    """
    
    def __init__(
        self,
        base_model_name="openvla/openvla-7b",
        output_dir="./finetuned_openvla",
        method="lora",          # "lora", "full", "frozen"
        device="cuda",
    ):
        self.base_model_name = base_model_name
        self.output_dir = output_dir
        self.method = method
        self.device = device
        
        # 加载基础模型
        self.model, self.processor, self.tokenizer = self._load_base_model()
        
        # 配置微调策略
        self._configure_finetuning()
        
    def _load_base_model(self):
        """加载预训练OpenVLA模型"""
        print(f"加载基础模型: {self.base_model_name}")
        
        processor = AutoProcessor.from_pretrained(
            self.base_model_name,
            trust_remote_code=True,
        )
        
        model = AutoModelForVision2Seq.from_pretrained(
            self.base_model_name,
            torch_dtype=torch.bfloat16,
            trust_remote_code=True,
            low_cpu_mem_usage=True,
        ).to(self.device)
        
        tokenizer = processor.tokenizer
        
        print(f"模型加载完成: {sum(p.numel() for p in model.parameters())/1e9:.2f}B 参数")
        
        return model, processor, tokenizer
    
    def _configure_finetuning(self):
        """配置微调策略"""
        if self.method == "lora":
            self._configure_lora()
        elif self.method == "full":
            self._configure_full_finetuning()
        elif self.method == "frozen":
            self._configure_frozen_finetuning()
        else:
            raise ValueError(f"不支持的微调方法: {self.method}")
    
    def _configure_lora(self):
        """配置LoRA微调"""
        print("配置LoRA微调...")
        
        # 为量化训练准备模型（如果使用4/8bit量化）
        # self.model = prepare_model_for_kbit_training(self.model)
        
        # LoRA配置
        lora_config = LoraConfig(
            # OpenVLA最终仍通过语言模型式的action token预测训练；
            # 若当前PEFT版本不支持该枚举，也可以省略task_type并显式设置target_modules。
            task_type=TaskType.CAUSAL_LM,
            r=32,                     # 秩
            lora_alpha=32,            # 缩放因子
            lora_dropout=0.1,         # Dropout
            target_modules=[          # 应用LoRA的模块
                "q_proj", "k_proj", "v_proj", "o_proj",
                "gate_proj", "up_proj", "down_proj"
            ],
            bias="none",              # 不训练bias
            modules_to_save=None,     # 如需同时保存projector，可按当前模型命名显式配置
        )
        
        # 应用LoRA
        self.model = get_peft_model(self.model, lora_config)
        
        # 打印参数统计
        trainable_params = sum(p.numel() for p in self.model.parameters() 
                              if p.requires_grad)
        total_params = sum(p.numel() for p in self.model.parameters())
        
        print(f"LoRA配置完成:")
        print(f"  可训练参数: {trainable_params/1e6:.1f}M ({trainable_params/total_params*100:.1f}%)")
        print(f"  总参数: {total_params/1e6:.1f}M")
        
        # 冻结其他参数。注意：不同OpenVLA分支中projector命名可能不同，
        # 真实项目应先print_trainable_parameters并核对目标模块是否真的可训练。
        for name, param in self.model.named_parameters():
            if "lora_" not in name and "projector" not in name:
                param.requires_grad = False
            elif "projector" in name:
                param.requires_grad = True
        
        print("  已冻结: 视觉编码器, LLM主干 (仅保留LoRA和投影器)")
    
    def _configure_full_finetuning(self):
        """配置全参数微调"""
        print("配置全参数微调...")
        
        # 冻结视觉编码器
        for param in self.model.vision_backbone.parameters():
            param.requires_grad = False
        
        # 微调投影器和LLM
        for param in self.model.projector.parameters():
            param.requires_grad = True
        for param in self.model.llm_backbone.parameters():
            param.requires_grad = True
        
        trainable_params = sum(p.numel() for p in self.model.parameters() 
                              if p.requires_grad)
        print(f"全参数微调配置完成: {trainable_params/1e9:.2f}B 可训练参数")
    
    def _configure_frozen_finetuning(self):
        """配置冻结微调（只微调投影器）"""
        print("配置冻结微调...")
        
        # 冻结所有参数
        for param in self.model.parameters():
            param.requires_grad = False
        
        # 只训练投影器
        for param in self.model.projector.parameters():
            param.requires_grad = True
        
        trainable_params = sum(p.numel() for p in self.model.parameters() 
                              if p.requires_grad)
        print(f"冻结微调配置完成: {trainable_params/1e6:.1f}M 可训练参数 (投影器)")
```

### 2.3 数据准备与DataLoader

```python
"""
微调数据集准备
针对特定任务的数据处理
"""

class FineTuningDataset(Dataset):
    """
    微调数据集
    
    数据格式要求：
    每个样本是一个字典：
    {
        "image": PIL.Image 或 numpy array,
        "instruction": str,  # 任务指令
        "action": list[float],  # 7维动作
    }
    """
    
    def __init__(
        self,
        data_path,           # 数据目录或文件
        processor,           # OpenVLA处理器
        action_tokenizer,    # 动作分词器
        max_samples=None,    # 最大样本数
        augment=False,       # 是否数据增强
    ):
        self.processor = processor
        self.action_tokenizer = action_tokenizer
        self.augment = augment
        
        # 加载数据
        self.data = self._load_data(data_path, max_samples)
        
        print(f"加载微调数据集: {len(self.data)} 样本")
        
        # 计算动作统计
        self._compute_action_statistics()
        
        # 数据增强
        if augment:
            self.augmentation = self._build_augmentation()
    
    def _load_data(self, data_path, max_samples):
        """加载微调数据"""
        data = []
        
        if os.path.isdir(data_path):
            # 目录形式：每个子目录是一个episode
            episodes = sorted(os.listdir(data_path))
            
            for ep_name in episodes[:max_samples] if max_samples else episodes:
                ep_path = os.path.join(data_path, ep_name)
                
                # 加载episode数据
                episode_data = self._load_episode(ep_path)
                data.extend(episode_data)
                
        elif data_path.endswith('.npz'):
            # NPZ文件形式
            loaded = np.load(data_path, allow_pickle=True)
            
            if 'data' in loaded:
                data = loaded['data'].tolist()
            else:
                # 假设格式为：image_files, actions, instructions
                for i in range(len(loaded['image_files'])):
                    data.append({
                        "image_file": loaded['image_files'][i],
                        "action": loaded['actions'][i],
                        "instruction": loaded['instructions'][i],
                    })
        
        if max_samples:
            data = data[:max_samples]
        
        return data
    
    def _load_episode(self, ep_path):
        """加载一个episode的数据"""
        # 实现取决于具体数据格式
        # 示例：加载BridgeData格式
        episode_data = []
        
        # 这里需要根据实际数据格式实现
        # 假设episode_path下有images/, actions.npy, instruction.txt
        
        return episode_data
    
    def _compute_action_statistics(self):
        """计算动作统计"""
        all_actions = np.array([d["action"] for d in self.data])
        
        self.action_mean = all_actions.mean(axis=0)
        self.action_std = all_actions.std(axis=0)
        self.action_min = all_actions.min(axis=0)
        self.action_max = all_actions.max(axis=0)
        
        print(f"动作统计:")
        print(f"  均值: {self.action_mean[:3]}...")
        print(f"  标准差: {self.action_std[:3]}...")
        print(f"  范围: [{self.action_min.min():.3f}, {self.action_max.max():.3f}]")
    
    def _build_augmentation(self):
        """构建数据增强"""
        from torchvision import transforms
        
        augmentation = transforms.Compose([
            transforms.RandomHorizontalFlip(p=0.3),
            transforms.RandomRotation(degrees=10),
            transforms.ColorJitter(
                brightness=0.2,
                contrast=0.2,
                saturation=0.2,
                hue=0.1
            ),
            transforms.RandomAffine(
                degrees=0,
                translate=(0.1, 0.1),
                scale=(0.9, 1.1),
            ),
        ])
        
        return augmentation
    
    def normalize_action(self, action):
        """动作归一化到 [-1, 1]"""
        action_norm = 2.0 * (action - self.action_min) / \
                     (self.action_max - self.action_min + 1e-8) - 1.0
        return np.clip(action_norm, -1.0, 1.0)
    
    def denormalize_action(self, action_norm):
        """动作反归一化"""
        action = (action_norm + 1.0) / 2.0 * \
                (self.action_max - self.action_min) + self.action_min
        return action
    
    def __len__(self):
        return len(self.data)
    
    def __getitem__(self, idx):
        """
        获取一个训练样本
        """
        sample = self.data[idx]
        
        # 1. 图像处理
        if isinstance(sample["image"], str):
            # 如果是文件路径
            image = Image.open(sample["image"]).convert("RGB")
        elif isinstance(sample["image"], np.ndarray):
            # 如果是numpy array
            image = Image.fromarray(sample["image"])
        else:
            image = sample["image"]
        
        # 数据增强（仅训练时）
        if self.augment:
            image = self.augmentation(image)
        
        # 2. 动作处理
        action = np.array(sample["action"], dtype=np.float32)
        action_norm = self.normalize_action(action)
        
        # 3. 文本指令
        instruction = sample.get("instruction", "complete the task")
        
        # 4. 构造输入
        prompt = f"In: What action should the robot take to {instruction}?\nOut:"
        
        # 使用processor处理图像和文本
        inputs = self.processor(
            prompt, 
            image, 
            return_tensors="pt",
            padding=False,
        )
        
        # 5. 动作token IDs
        action_token_ids = self.action_tokenizer.encode(
            torch.tensor([action_norm])
        )[0]  # [7]
        
        return {
            "pixel_values": inputs["pixel_values"].squeeze(0),  # [3, 384, 384]
            "input_ids": inputs["input_ids"].squeeze(0),        # [seq_len]
            "attention_mask": inputs["attention_mask"].squeeze(0), # [seq_len]
            "labels": action_token_ids,                         # [7]
            "action_continuous": torch.tensor(action_norm),     # [7]
            "instruction": instruction,
        }


def create_finetuning_dataloader(
    dataset,
    batch_size=32,
    num_workers=4,
    shuffle=True,
):
    """创建微调DataLoader"""
    
    def collate_fn(batch):
        """自定义collate函数"""
        # 由于序列长度可能不同，需要padding
        pixel_values = torch.stack([s["pixel_values"] for s in batch])
        
        # 对input_ids和attention_mask进行padding
        max_len = max(len(s["input_ids"]) for s in batch)
        
        padded_input_ids = []
        padded_attention_mask = []
        
        for s in batch:
            input_ids = s["input_ids"]
            attention_mask = s["attention_mask"]
            
            # 右侧padding
            pad_len = max_len - len(input_ids)
            padded_input_ids.append(
                torch.cat([input_ids, torch.zeros(pad_len, dtype=input_ids.dtype)])
            )
            padded_attention_mask.append(
                torch.cat([attention_mask, torch.zeros(pad_len, dtype=attention_mask.dtype)])
            )
        
        input_ids = torch.stack(padded_input_ids)
        attention_mask = torch.stack(padded_attention_mask)
        labels = torch.stack([s["labels"] for s in batch])
        action_continuous = torch.stack([s["action_continuous"] for s in batch])
        
        return {
            "pixel_values": pixel_values,
            "input_ids": input_ids,
            "attention_mask": attention_mask,
            "labels": labels,
            "action_continuous": action_continuous,
        }
    
    dataloader = DataLoader(
        dataset,
        batch_size=batch_size,
        shuffle=shuffle,
        num_workers=num_workers,
        collate_fn=collate_fn,
        pin_memory=True,
        drop_last=True,
    )
    
    return dataloader
```

### 2.4 训练标签与 label mask：最容易出错的地方

上面的 Dataset/Collator 代码为了讲解清晰，把 `labels` 写成了 `[7]` 的 action token。真实的 CausalLM 式 VLA 训练更常见的结构是：

```text
input_ids = [prompt tokens..., action token 1, action token 2, ..., action token 7]
labels    = [-100, -100, ..., action token 1, action token 2, ..., action token 7]
```

也就是说，模型看到图像和指令后，只在动作 token 位置计算 next-token loss。prompt 部分是条件，不应该参与动作预测 loss。否则模型可能把大量损失花在复述 prompt 上，训练 loss 看起来下降，但动作策略并没有真正变好。

```python
def build_vla_training_example(processor, action_tokenizer, image, instruction, action_norm):
    """
    更接近真实VLA训练的样本构造示意。
    重点是：action tokens要拼到输入序列末尾，labels只监督action部分。
    """
    prompt = f"In: What action should the robot take to {instruction}?\nOut:"
    prompt_inputs = processor(
        prompt,
        image,
        return_tensors="pt",
        padding=False,
    )

    prompt_ids = prompt_inputs["input_ids"].squeeze(0)          # [T]
    prompt_mask = prompt_inputs["attention_mask"].squeeze(0)    # [T]

    # action_tokenizer应使用当前OpenVLA版本的官方实现；
    # 不要手写token_id offset或假设固定词表起点。
    action_token_ids = action_tokenizer.encode(
        torch.tensor([action_norm])
    ).squeeze(0).to(prompt_ids.device)                          # [A], 通常是7个动作token

    input_ids = torch.cat([prompt_ids, action_token_ids], dim=0)
    attention_mask = torch.cat([
        prompt_mask,
        torch.ones_like(action_token_ids),
    ], dim=0)

    labels = torch.full_like(input_ids, fill_value=-100)
    labels[-len(action_token_ids):] = action_token_ids

    return {
        "pixel_values": prompt_inputs["pixel_values"].squeeze(0),
        "input_ids": input_ids,
        "attention_mask": attention_mask,
        "labels": labels,
        "action_token_ids": action_token_ids,
        "action_continuous": torch.tensor(action_norm),
    }
```

对应的 `collate_fn` 也要 padding `input_ids / attention_mask / labels` 三者，并且 `labels` 的 padding 位置必须是 `-100`，不能用 `0`。

```python
def collate_vla_examples(batch, pad_token_id):
    max_len = max(len(s["input_ids"]) for s in batch)

    padded_input_ids = []
    padded_attention_mask = []
    padded_labels = []

    for s in batch:
        pad_len = max_len - len(s["input_ids"])

        padded_input_ids.append(torch.cat([
            s["input_ids"],
            torch.full((pad_len,), pad_token_id, dtype=s["input_ids"].dtype),
        ]))
        padded_attention_mask.append(torch.cat([
            s["attention_mask"],
            torch.zeros(pad_len, dtype=s["attention_mask"].dtype),
        ]))
        padded_labels.append(torch.cat([
            s["labels"],
            torch.full((pad_len,), -100, dtype=s["labels"].dtype),
        ]))

    return {
        "pixel_values": torch.stack([s["pixel_values"] for s in batch]),
        "input_ids": torch.stack(padded_input_ids),
        "attention_mask": torch.stack(padded_attention_mask),
        "labels": torch.stack(padded_labels),
        "action_continuous": torch.stack([s["action_continuous"] for s in batch]),
    }
```

**排查口诀**：

1. `input_ids` 里必须真的包含 action tokens，否则 `outputs.logits[:, -7:, :]` 没有意义。
2. `labels` 长度必须和 `input_ids` 一致。
3. prompt token、padding token 的 label 必须是 `-100`。
4. action token 的编码/解码必须用当前 OpenVLA 版本的官方 ActionTokenizer。
5. 训练和推理的 prompt 模板、`unnorm_key`、action stats 必须一致。

### 2.5 训练循环实现

```python
"""
OpenVLA微调训练循环
支持LoRA、全参数和冻结微调
"""

class OpenVLATrainer:
    """
    OpenVLA微调训练器
    """
    
    def __init__(
        self,
        model,
        train_dataloader,
        val_dataloader=None,
        training_args=None,
        method="lora",
    ):
        self.model = model
        self.train_dataloader = train_dataloader
        self.val_dataloader = val_dataloader
        self.method = method
        
        # 默认训练参数
        if training_args is None:
            training_args = self._get_default_training_args()
        
        self.training_args = training_args
        
        # 优化器
        self.optimizer = self._create_optimizer()
        
        # 学习率调度器
        self.scheduler = self._create_scheduler()
        
        # 损失函数
        self.loss_fn = nn.CrossEntropyLoss(ignore_index=-100)
        
        # 训练统计
        self.training_stats = {
            "train_loss": [],
            "val_loss": [],
            "learning_rate": [],
            "grad_norm": [],
            "epochs": [],
        }
        
        # 最佳模型
        self.best_val_loss = float('inf')
        self.best_model_state = None
    
    def _get_default_training_args(self):
        """获取默认训练参数"""
        if self.method == "lora":
            return {
                "learning_rate": 2e-5,
                "weight_decay": 0.01,
                "max_grad_norm": 1.0,
                "num_epochs": 30,
                "warmup_steps": 500,
                "log_interval": 10,
                "eval_interval": 500,
                "save_interval": 1000,
                "mixed_precision": "bf16",
                "gradient_accumulation": 4,
            }
        elif self.method == "full":
            return {
                "learning_rate": 5e-6,
                "weight_decay": 0.01,
                "max_grad_norm": 1.0,
                "num_epochs": 20,
                "warmup_steps": 1000,
                "log_interval": 10,
                "eval_interval": 500,
                "save_interval": 1000,
                "mixed_precision": "bf16",
                "gradient_accumulation": 8,
            }
        else:  # frozen
            return {
                "learning_rate": 1e-4,
                "weight_decay": 0.0,
                "max_grad_norm": 1.0,
                "num_epochs": 50,
                "warmup_steps": 200,
                "log_interval": 10,
                "eval_interval": 500,
                "save_interval": 1000,
                "mixed_precision": "bf16",
                "gradient_accumulation": 2,
            }
    
    def _create_optimizer(self):
        """创建优化器"""
        # 区分需要权重衰减和不需要的参数
        decay_params = []
        no_decay_params = []
        
        for name, param in self.model.named_parameters():
            if not param.requires_grad:
                continue
            
            if "bias" in name or "LayerNorm" in name or "layernorm" in name:
                no_decay_params.append(param)
            else:
                decay_params.append(param)
        
        optimizer_groups = [
            {"params": decay_params, "weight_decay": self.training_args["weight_decay"]},
            {"params": no_decay_params, "weight_decay": 0.0},
        ]
        
        optimizer = torch.optim.AdamW(
            optimizer_groups,
            lr=self.training_args["learning_rate"],
            betas=(0.9, 0.999),
            eps=1e-8,
        )
        
        return optimizer
    
    def _create_scheduler(self):
        """创建学习率调度器"""
        from transformers import get_cosine_schedule_with_warmup
        
        total_steps = len(self.train_dataloader) * self.training_args["num_epochs"]
        warmup_steps = self.training_args["warmup_steps"]
        
        scheduler = get_cosine_schedule_with_warmup(
            self.optimizer,
            num_warmup_steps=warmup_steps,
            num_training_steps=total_steps,
        )
        
        return scheduler
    
    def train(self):
        """执行训练"""
        print("=" * 80)
        print(f"开始训练: {self.method} 微调")
        print(f"训练样本: {len(self.train_dataloader.dataset)}")
        print(f"批大小: {self.train_dataloader.batch_size}")
        print(f"总轮数: {self.training_args['num_epochs']}")
        print(f"总步数: {len(self.train_dataloader) * self.training_args['num_epochs']}")
        print("=" * 80)
        
        # 初始化wandb
        wandb.init(
            project="openvla-finetuning",
            config={
                "method": self.method,
                "base_model": "openvla-7b",
                **self.training_args,
            }
        )
        
        global_step = 0
        
        for epoch in range(self.training_args["num_epochs"]):
            print(f"\n{'='*60}")
            print(f"Epoch {epoch+1}/{self.training_args['num_epochs']}")
            print(f"{'='*60}")
            
            # 训练一个epoch
            train_loss = self._train_epoch(epoch, global_step)
            
            # 验证
            if self.val_dataloader and (epoch + 1) % 5 == 0:
                val_loss, val_metrics = self._validate(epoch)
                
                # 记录验证结果
                self.training_stats["val_loss"].append(val_loss)
                
                # 保存最佳模型
                if val_loss < self.best_val_loss:
                    self.best_val_loss = val_loss
                    self.best_model_state = self.model.state_dict().copy()
                    print(f"新的最佳验证损失: {val_loss:.4f}")
            
            # 保存checkpoint
            if (epoch + 1) % 5 == 0:
                self._save_checkpoint(f"checkpoint_epoch_{epoch+1}")
            
            # 更新全局步数
            global_step += len(self.train_dataloader)
        
        # 保存最终模型
        self._save_final_model()
        
        # 关闭wandb
        wandb.finish()
        
        return self.training_stats
    
    def _train_epoch(self, epoch, global_step):
        """训练一个epoch"""
        self.model.train()
        
        epoch_loss = 0.0
        epoch_steps = 0
        
        for batch_idx, batch in enumerate(self.train_dataloader):
            # 移动到设备
            batch = {k: v.to(self.device) if isinstance(v, torch.Tensor) else v 
                    for k, v in batch.items()}
            
            # 前向传播
            outputs = self.model(
                pixel_values=batch["pixel_values"],
                input_ids=batch["input_ids"],
                attention_mask=batch["attention_mask"],
                labels=batch["labels"],
            )
            
            loss = outputs.loss
            
            # 梯度累积
            loss = loss / self.training_args["gradient_accumulation"]
            
            # 反向传播
            loss.backward()
            
            # 梯度累积步
            if (batch_idx + 1) % self.training_args["gradient_accumulation"] == 0:
                # 梯度裁剪
                grad_norm = torch.nn.utils.clip_grad_norm_(
                    self.model.parameters(),
                    self.training_args["max_grad_norm"],
                )
                
                # 参数更新
                self.optimizer.step()
                self.scheduler.step()
                self.optimizer.zero_grad()
                
                # 记录统计
                self.training_stats["grad_norm"].append(grad_norm.item())
                self.training_stats["learning_rate"].append(
                    self.scheduler.get_last_lr()[0]
                )
                
                global_step += 1
            
            # 记录损失
            epoch_loss += loss.item() * self.training_args["gradient_accumulation"]
            epoch_steps += 1
            
            # 日志记录
            if batch_idx % self.training_args["log_interval"] == 0:
                current_loss = epoch_loss / epoch_steps
                current_lr = self.scheduler.get_last_lr()[0]
                
                wandb.log({
                    "train/loss": current_loss,
                    "train/learning_rate": current_lr,
                    "train/grad_norm": grad_norm.item() if 'grad_norm' in locals() else 0,
                    "train/epoch": epoch + batch_idx / len(self.train_dataloader),
                    "train/global_step": global_step,
                })
                
                print(f"  Step {batch_idx}/{len(self.train_dataloader)}: "
                      f"loss={current_loss:.4f}, lr={current_lr:.2e}")
        
        # 计算epoch平均损失
        avg_loss = epoch_loss / epoch_steps
        self.training_stats["train_loss"].append(avg_loss)
        self.training_stats["epochs"].append(epoch + 1)
        
        print(f"Epoch {epoch+1} 完成: 平均损失 = {avg_loss:.4f}")
        
        return avg_loss
    
    def _validate(self, epoch):
        """验证"""
        print(f"\n验证 Epoch {epoch+1}...")
        
        self.model.eval()
        val_loss = 0.0
        val_steps = 0
        
        all_preds = []
        all_labels = []
        
        with torch.no_grad():
            for batch in self.val_dataloader:
                batch = {k: v.to(self.device) if isinstance(v, torch.Tensor) else v 
                        for k, v in batch.items()}
                
                outputs = self.model(
                    pixel_values=batch["pixel_values"],
                    input_ids=batch["input_ids"],
                    attention_mask=batch["attention_mask"],
                    labels=batch["labels"],
                )
                
                loss = outputs.loss
                val_loss += loss.item()
                val_steps += 1
                
                # 收集预测结果用于计算指标。
                # 注意：只有当input_ids末尾已经拼接了action tokens时，
                # outputs.logits[:, -A:, :] 才能对应动作位置。
                logits = outputs.logits[:, -7:, :]  # 取最后7个位置
                preds = torch.argmax(logits, dim=-1)
                
                all_preds.extend(preds.cpu().numpy())
                all_labels.extend(batch["labels"].cpu().numpy())
        
        avg_val_loss = val_loss / val_steps
        self.training_stats["val_loss"].append(avg_val_loss)
        
        # 计算额外指标
        metrics = self._compute_metrics(all_preds, all_labels)
        
        wandb.log({
            "val/loss": avg_val_loss,
            "val/action_accuracy": metrics["accuracy"],
            "val/mae": metrics["mae"],
        })
        
        print(f"验证结果: loss={avg_val_loss:.4f}, "
              f"准确率={metrics['accuracy']:.3f}, MAE={metrics['mae']:.4f}")
        
        return avg_val_loss, metrics
    
    def _compute_metrics(self, preds, labels):
        """计算评估指标"""
        preds = np.array(preds)
        labels = np.array(labels)
        
        # 动作准确率（token级别）
        accuracy = np.mean(preds == labels)
        
        # 计算MAE（需要将token转换为连续动作）
        # 这里简化计算token级别的差异。真实报告中应使用ActionTokenizer
        # decode回连续动作，再分别统计xyz/rpy/gripper误差。
        mae = np.mean(np.abs(preds - labels))
        
        return {
            "accuracy": accuracy,
            "mae": mae,
        }
    
    def _save_checkpoint(self, name):
        """保存checkpoint"""
        checkpoint_dir = os.path.join(self.output_dir, name)
        os.makedirs(checkpoint_dir, exist_ok=True)
        
        # 保存模型
        if self.method == "lora":
            # LoRA只保存适配器权重
            self.model.save_pretrained(checkpoint_dir)
        else:
            # 全参数微调保存完整模型
            torch.save(self.model.state_dict(), 
                      os.path.join(checkpoint_dir, "model.pt"))
        
        # 保存训练统计
        stats_path = os.path.join(checkpoint_dir, "training_stats.json")
        import json
        with open(stats_path, 'w') as f:
            json.dump(self.training_stats, f, indent=2)
        
        print(f"Checkpoint已保存到: {checkpoint_dir}")
    
    def _save_final_model(self):
        """保存最终模型"""
        final_dir = os.path.join(self.output_dir, "final_model")
        os.makedirs(final_dir, exist_ok=True)
        
        if self.method == "lora":
            # 合并LoRA权重到基础模型
            merged_model = self.model.merge_and_unload()
            merged_model.save_pretrained(final_dir)
        else:
            # 保存完整模型
            self.model.save_pretrained(final_dir)
        
        # 保存processor
        # 注意：processor通常不是model属性，真实代码应在Trainer中保留self.processor。
        # self.processor.save_pretrained(final_dir)
        
        print(f"最终模型已保存到: {final_dir}")
```

### 2.6 Checkpoint 选择与连续动作评估

微调时不要只用 `best_val_loss` 选 checkpoint。VLA 的离线 loss 和闭环成功率不总是一致，尤其在以下场景：

- 验证集 action token loss 很低，但 gripper 开合时机错，真实抓取失败。
- token 级 accuracy 提升，但连续动作反归一化后尺度偏大，机器人运动过冲。
- 验证集来自相邻帧，泄漏严重，val loss 好看但 held-out episode 成功率差。
- LoRA adapter 在训练态评估正常，merge 后因为 dtype/device/保存方式不同导致效果变化。

推荐 checkpoint 选择表：

| 维度 | 应记录指标 | 通过标准 |
|---|---|---|
| 训练稳定性 | train loss、grad norm、learning rate | 无持续震荡、无梯度爆炸 |
| 离线验证 | val loss、action token accuracy | held-out episode 上稳定改善 |
| 连续动作 | xyz/rpy MAE、gripper error、action saturation | 关键动作维度误差下降 |
| 闭环任务 | success rate、partial success、failure type | 目标任务提升且泛化任务不明显下降 |
| 部署代价 | latency、memory、adapter merge consistency | 推理成本可接受，merge 前后结果一致 |

连续动作评估建议用官方 action tokenizer 解码：

```python
def evaluate_continuous_action_error(action_tokenizer, pred_token_ids, label_token_ids):
    """
    token级准确率只能说明离散分类是否接近；
    VLA报告应进一步decode到连续动作空间。
    """
    pred_actions = action_tokenizer.decode_token_ids_to_actions(pred_token_ids)
    label_actions = action_tokenizer.decode_token_ids_to_actions(label_token_ids)

    diff = pred_actions - label_actions
    metrics = {
        "xyz_mae": np.mean(np.abs(diff[..., :3])),
        "rot_mae": np.mean(np.abs(diff[..., 3:6])),
        "gripper_error": np.mean(pred_actions[..., 6] != label_actions[..., 6]),
        "action_l2": np.mean(np.linalg.norm(diff[..., :6], axis=-1)),
        "saturation_rate": np.mean(np.abs(pred_actions[..., :6]) > 0.95),
    }
    return metrics
```

如果当前 OpenVLA 版本的 action tokenizer API 名称不同，应以仓库源码为准；原则是不手写 token offset，不把 token id 差值当成最终动作误差。

```python
"""
训练曲线分析与可视化
帮助理解训练过程，诊断问题
"""

import matplotlib.pyplot as plt
import numpy as np
import json
from pathlib import Path

class TrainingCurveAnalyzer:
    """
    训练曲线分析器
    """
    
    def __init__(self, training_stats_path=None, training_stats=None):
        """
        Args:
            training_stats_path: 训练统计JSON文件路径
            training_stats: 训练统计字典
        """
        if training_stats_path:
            with open(training_stats_path, 'r') as f:
                self.stats = json.load(f)
        elif training_stats:
            self.stats = training_stats
        else:
            raise ValueError("需要提供训练统计路径或字典")
        
        # 确保关键字段存在
        self._validate_stats()
    
    def _validate_stats(self):
        """验证统计字典结构"""
        required_keys = ["train_loss", "epochs"]

                print(f"警告: 缺少关键统计字段 {key}")
        
        # 初始化缺失字段
        if "val_loss" not in self.stats:
            self.stats["val_loss"] = []
        if "learning_rate" not in self.stats:
            self.stats["learning_rate"] = []
        if "grad_norm" not in self.stats:
            self.stats["grad_norm"] = []
    
    def plot_training_curves(self, save_path=None):
        """绘制训练曲线"""
        fig, axes = plt.subplots(2, 3, figsize=(18, 10))
        
        # 1. 训练损失
        ax = axes[0, 0]
        if self.stats["train_loss"]:
            epochs = self.stats["epochs"][:len(self.stats["train_loss"])]
            ax.plot(epochs, self.stats["train_loss"], 'b-', label='Train Loss', linewidth=2)
            ax.set_xlabel('Epoch')
            ax.set_ylabel('Loss')
            ax.set_title('Training Loss')
            ax.grid(True, alpha=0.3)
            ax.legend()
            
            # 添加趋势线
            if len(self.stats["train_loss"]) > 10:
                z = np.polyfit(epochs, self.stats["train_loss"], 3)
                p = np.poly1d(z)
                ax.plot(epochs, p(epochs), 'r--', alpha=0.5, label='Trend')
        
        # 2. 验证损失
        ax = axes[0, 1]
        if self.stats["val_loss"]:
            val_epochs = np.linspace(0, max(self.stats["epochs"]), 
                                    len(self.stats["val_loss"]))
            ax.plot(val_epochs, self.stats["val_loss"], 'r-', 
                   label='Validation Loss', linewidth=2)
            ax.set_xlabel('Epoch')
            ax.set_ylabel('Loss')
            ax.set_title('Validation Loss')
            ax.grid(True, alpha=0.3)
            ax.legend()
        
        # 3. 学习率
        ax = axes[0, 2]
        if self.stats["learning_rate"]:

            ax.plot(steps, self.stats["learning_rate'], 'g-', linewidth=2)
            ax.set_xlabel('Step')
            ax.set_ylabel('Learning Rate')
            ax.set_title('Learning Rate Schedule')
            ax.grid(True, alpha=0.3)
            ax.set_yscale('log')
        
        # 4. 梯度范数

        if self.stats["grad_norm"]:
            steps = range(len(self.stats["grad_norm"]))
            ax.plot(steps, self.stats["grad_norm'], 'purple', linewidth=2)
            ax.set_xlabel('Step')
            ax.set_ylabel('Gradient Norm')
            ax.set_title('Gradient Norm')
            ax.grid(True, alpha=0.3)
            
            # 添加阈值线
            ax.axhline(y=1.0, color='r', linestyle='--', alpha=0.5, label='Max Grad Norm')
            ax.legend()
        
        # 5. 训练/验证损失对比
        ax = axes[1, 1]
        if self.stats["train_loss"] and self.stats["val_loss"]:
            train_epochs = self.stats["epochs"][:len(self.stats["train_loss"])]
            val_epochs = np.linspace(0, max(train_epochs), len(self.stats["val_loss"]))
            
            ax.plot(train_epochs, self.stats["train_loss"], 'b-', 
                   label='Train Loss', linewidth=2)
            ax.plot(val_epochs, self.stats["val_loss"], 'r-',

            ax.set_xlabel('Epoch')
            ax.set_ylabel('Loss')
            ax.set_title('Train vs Validation Loss')
            ax.grid(True, alpha=0.3)
            ax.legend()
            
            # 计算过拟合程度
            if len(self.stats["train_loss"]) == len(self.stats["val_loss"]):
                overfitting = np.array(self.stats["val_loss"]) - np.array(self.stats["train_loss"])
                ax2 = ax.twinx()
                ax2.plot(train_epochs, overfitting, 'g--', alpha=0.5, label='Overfitting Gap')
                ax2.set_ylabel('Val - Train Loss')
                ax2.legend(loc='upper left')
        
        # 6. 训练统计摘要
        ax = axes[1, 2]
        ax.axis('off')
        
        # 统计摘要
        summary = self._generate_summary()

        if save_path:
            plt.savefig(save_path, dpi=150, bbox_inches='tight')
            print(f"训练曲线已保存到: {save_path}")
        
        plt.show()
    
    def _generate_summary(self):
        """生成训练统计摘要"""
        summary = {}
        
        if self.stats["train_loss"]:
            summary["最终训练损失"] = self.stats["train_loss"][-1]
            summary["最低训练损失"] = min(self.stats["train_loss"])
            summary["最低损失epoch"] = self.stats["epochs"][self.stats["train_loss"].index(min(self.stats["train_loss"]))]
        
        if self.stats["val_loss"]:
            summary["最终验证损失"] = self.stats["val_loss"][-1]
            summary["最低验证损失"] = min(self.stats["val_loss"])
        
        if self.stats["learning_rate"]:
            summary["初始学习率"] = self.stats["learning_rate"][0]
            summary["最终学习率"] = self.stats["learning_rate"][-1]
        
        if self.stats["grad_norm"]:
            summary["平均梯度范数"] = np.mean(self.stats["grad_norm"])
            summary["最大梯度范数"] = max(self.stats["grad_norm"])
        
        return summary
    
    def diagnose_training(self):
        """诊断训练问题"""
        print("=" * 80)
        print("训练问题诊断")
        print("=" * 80)
        
        issues = []
        suggestions = []
        
        # 1. 检查损失下降情况
        if self.stats["train_loss"]:
            loss_changes = np.diff(self.stats["train_loss"])
            
            # 检查是否收敛
            if len(loss_changes) > 10:
                recent_changes = loss_changes[-10:]
                if np.all(np.abs(recent_changes) < 1e-4):
                    issues.append("训练可能已收敛，损失变化很小")
                    suggestions.append("可以停止训练或降低学习率")
                
                # 检查是否震荡
                if np.std(recent_changes) > np.mean(np.abs(recent_changes)) * 2:
                    issues.append("训练损失震荡")
                    suggestions.append("降低学习率或增加批量大小")
        
        # 2. 检查过拟合
        if self.stats["train_loss"] and self.stats["val_loss"]:
            if len(self.stats["train_loss"]) == len(self.stats["val_loss"]):
                final_gap = self.stats["val_loss"][-1] - self.stats["train_loss"][-1]
                if final_gap > 0.5:
                    issues.append(f"严重过拟合: 验证损失比训练损失高{final_gap:.3f}")
                    suggestions.extend([
                        "增加数据增强",
                        "增加正则化 (weight_decay, dropout)",
                        "减少模型复杂度",
                        "使用早停",
                    ])
        
        # 3. 检查梯度问题
        if self.stats["grad_norm"]:
            max_grad = max(self.stats["grad_norm"])
            avg_grad = np.mean(self.stats["grad_norm"])
            
            if max_grad > 100:
                issues.append(f"梯度爆炸: 最大范数={max_grad:.2f}")
                suggestions.append("降低学习率或增加梯度裁剪")
            
            if avg_grad < 1e-5:
                issues.append("梯度消失: 平均范数过小")
                suggestions.append("检查模型结构，考虑使用残差连接")
        
        # 4. 检查学习率
        if self.stats["learning_rate"]:
            lr_changes = np.diff(self.stats["learning_rate"])
            if np.all(lr_changes > 0):
                issues.append("学习率一直在增加")
                suggestions.append("检查学习率调度器配置")
        
        # 输出诊断结果
        if not issues:
            print("✅ 训练过程正常，未发现明显问题")
        else:
            print("❌ 发现以下问题:")
            for i, issue in enumerate(issues, 1):
                print(f"  {i}. {issue}")
            
            print("\n改进建议:")
            for i, suggestion in enumerate(suggestions, 1):
                print(f"  {i}. {suggestion}")
        
        return {
            "issues": issues,
            "suggestions": suggestions,
        }
```

```python
"""
预训练模型 vs 微调模型 全面对比
"""

import numpy as np
import matplotlib.pyplot as plt

class PretrainVsFineTuneComparison:
    """
    预训练与微调对比分析
    """
    
    def __init__(self, pretrain_results, finetune_results):
        """
        Args:
            pretrain_results: 预训练模型评估结果
            finetune_results: 微调模型评估结果
        """
        self.pretrain = pretrain_results
        self.finetune = finetune_results
        
        # 计算改进
        self.improvements = self._compute_improvements()
    
    def _compute_improvements(self):
        """计算各项指标的改进"""
        improvements = {}
        
        # 成功率改进
        if "success_rate" in self.pretrain and "success_rate" in self.finetune:
            sr_pre = self.pretrain["success_rate"]
            sr_ft = self.finetune["success_rate"]
            improvements["success_rate"] = {
                "pretrain": sr_pre,
                "finetune": sr_ft,
                "absolute_improvement": sr_ft - sr_pre,
                "relative_improvement": (sr_ft - sr_pre) / max(sr_pre, 1e-6) * 100,
            }
        
        # 动作误差改进
        if "action_mae" in self.pretrain and "action_mae" in self.finetune:
            mae_pre = self.pretrain["action_mae"]
            mae_ft = self.finetune["action_mae"]
            improvements["action_mae"] = {
                "pretrain": mae_pre,
                "finetune": mae_ft,
                "absolute_improvement": mae_pre - mae_ft,  # 误差减少
                "relative_improvement": (mae_pre - mae_ft) / max(mae_pre, 1e-6) * 100,
            }
        
        # 推理速度对比
        if "inference_time_ms" in self.pretrain and "inference_time_ms" in self.finetune:
            time_pre = self.pretrain["inference_time_ms"]
            time_ft = self.finetune["inference_time_ms"]
            improvements["inference_time"] = {
                "pretrain": time_pre,
                "finetune": time_ft,
                "absolute_change": time_ft - time_pre,
                "relative_change": (time_ft - time_pre) / max(time_pre, 1e-6) * 100,
            }
        
        return improvements
    
    def create_comparison_report(self, save_path="pretrain_vs_finetune_report.html"):
        """创建对比报告"""
        report = {
            "summary": self._generate_summary(),
            "detailed_metrics": self._generate_detailed_metrics(),
            "visualization_data": self._prepare_visualization_data(),
            "recommendations": self._generate_recommendations(),
        }
        
        # 保存报告
        import json
        with open(save_path.replace('.html', '.json'), 'w') as f:
            json.dump(report, f, indent=2, default=str)
        
        # 生成可视化
        self._generate_visualizations(save_path.replace('.html', ''))
        
        print(f"对比报告已保存到: {save_path}")
        
        return report
    
    def _generate_summary(self):
        """生成摘要"""
        summary = {}
        
        if "success_rate" in self.improvements:
            sr_imp = self.improvements["success_rate"]
            summary["成功率改进"] = f"{sr_imp['absolute_improvement']:.1%} (相对: {sr_imp['relative_improvement']:.1f}%)"
        
        if "action_mae" in self.improvements:
            mae_imp = self.improvements["action_mae"]
            summary["动作误差改进"] = f"{mae_imp['absolute_improvement']:.4f} (相对: {mae_imp['relative_improvement']:.1f}%)"
        
        # 总体评估
        if "success_rate" in self.improvements:
            sr_imp = self.improvements["success_rate"]
            if sr_imp["relative_improvement"] > 50:
                summary["总体评估"] = "微调带来显著改进"
            elif sr_imp["relative_improvement"] > 20:
                summary["总体评估"] = "微调带来明显改进"
            elif sr_imp["relative_improvement"] > 5:
                summary["总体评估"] = "微调带来一定改进"
            else:
                summary["总体评估"] = "微调改进有限"
        
        return summary
    
    def _generate_detailed_metrics(self):
        """生成详细指标对比"""
        metrics = {}
        
        # 常见指标
        common_metrics = [
            "success_rate", "action_mae", "action_mse", 
            "inference_time_ms", "control_frequency_hz",
            "memory_usage_gb",
        ]
        
        for metric in common_metrics:
            if metric in self.pretrain and metric in self.finetune:
                pre_val = self.pretrain[metric]
                ft_val = self.finetune[metric]
                
                metrics[metric] = {
                    "pretrain": pre_val,
                    "finetune": ft_val,
                    "difference": ft_val - pre_val,
                    "percent_change": (ft_val - pre_val) / max(abs(pre_val), 1e-6) * 100,
                }
        
        return metrics
    
    def _prepare_visualization_data(self):
        """准备可视化数据"""
        viz_data = {}
        
        # 条形图数据
        if "success_rate" in self.improvements:
            viz_data["success_rate_bar"] = {
                "categories": ["Pretrain", "Finetune"],
                "values": [
                    self.pretrain["success_rate"],
```

```python
"""
微调效果影响因素分析
理解什么因素影响微调成功
"""

class FineTuningFactorAnalysis:
    """
    微调效果影响因素分析
    """
    
    @staticmethod
    def analyze_data_factors(data_stats, performance_metrics):
        """
        分析数据因素对微调效果的影响
        """
        factors = {}
        
        # 1. 数据量影响
        data_size = data_stats.get("num_demos", 0)
        success_rate = performance_metrics.get("success_rate", 0)
        
        if data_size > 0:
            # 计算数据效率
            factors["data_efficiency"] = success_rate / (data_size / 100)  # 每100个demos的成功率
        
        # 2. 数据多样性
        diversity_score = data_stats.get("diversity_score", 0)
        if diversity_score > 0:
            factors["data_diversity_impact"] = {
                "score": diversity_score,
                "impact": "高" if diversity_score > 0.7 else "中" if diversity_score > 0.4 else "低",
            }
        
        # 3. 数据质量
        quality_score = data_stats.get("quality_score", 0)
        if quality_score > 0:
            factors["data_quality_impact"] = {
                "score": quality_score,
                "impact": "高" if quality_score > 0.8 else "中" if quality_score > 0.5 else "低",
            }
        
        return factors
    
    @staticmethod
    def analyze_model_factors(model_config, performance_metrics):
        """
        分析模型因素对微调效果的影响
        """
        factors = {}
        
        # 1. 预训练质量
        pretrain_quality = model_config.get("pretrain_quality", "unknown")
        factors["pretrain_quality"] = {
            "value": pretrain_quality,
            "impact": "高质量预训练模型通常微调效果更好",
        }
        
        # 2. 微调方法
        method = model_config.get("method", "lora")
        factors["finetuning_method"] = {
            "method": method,
            "expected_impact": {
                "lora": "参数高效，适合中小数据",
                "full": "全参数微调，适合大数据",
                "frozen": "只训练投影器，适合极少数据",
            }.get(method, "未知方法"),
        }
        
        # 3. 模型大小
        model_size = model_config.get("model_size_b", 7)
        factors["model_size"] = {
            "size_b": model_size,
            "impact": "大模型通常泛化能力更强，但需要更多数据",
        }
        
        return factors
    
    @staticmethod
    def analyze_training_factors(training_config, training_stats):
        """
        分析训练因素对微调效果的影响
        """
        factors = {}
        
        # 1. 学习率
        lr = training_config.get("learning_rate", 2e-5)
        factors["learning_rate"] = {
            "value": lr,
            "impact": "适中学习率通常效果最好",
            "suggestion": "如果过拟合，降低学习率；如果欠拟合，提高学习率",
        }
        
        # 2. 训练步数
        total_steps = training_config.get("total_steps", 20000)
        train_loss = training_stats.get("train_loss", [])
        
        if train_loss:
            # 检查是否收敛
            if len(train_loss) > 10:
                recent_loss = np.mean(train_loss[-10:])
                early_loss = np.mean(train_loss[:10])
                
                if recent_loss < early_loss * 0.1:
                    factors["convergence"] = {
                        "status": "良好收敛",
                        "suggestion": "训练步数可能足够",
                    }
                elif recent_loss < early_loss * 0.5:
                    factors["convergence"] = {
                        "status": "部分收敛",
                        "suggestion": "可能需要更多训练步数",
                    }
                else:
                    factors["convergence"] = {
                        "status": "收敛不佳",
                        "suggestion": "检查学习率、数据质量、模型配置",
                    }
        
        # 3. 批量大小
        batch_size = training_config.get("batch_size", 32)
        factors["batch_size"] = {
            "value": batch_size,
            "impact": "批量太小会导致训练不稳定，太大会降低泛化能力",
        }
        
        return factors
    
    @staticmethod
    def generate_factor_report(all_factors, performance_metrics):
        """
        生成因素分析报告
        """
        report = {
            "summary": {},
            "detailed_analysis": all_factors,
            "recommendations": [],
        }
        
        # 生成总结
        success_rate = performance_metrics.get("success_rate", 0)
        
        if success_rate > 0.8:
            report["summary"]["overall"] = "微调效果优秀"
            report["summary"]["success_level"] = "高"
        elif success_rate > 0.6:
            report["summary"]["overall"] = "微调效果良好"
            report["summary"]["success_level"] = "中高"
        elif success_rate > 0.4:
            report["summary"]["overall"] = "微调效果一般"
            report["summary"]["success_level"] = "中"
        else:
            report["summary"]["overall"] = "微调效果不佳"
            report["summary"]["success_level"] = "低"
        
        # 基于因素生成建议
        data_factors = all_factors.get("data", {})
        model_factors = all_factors.get("model", {})
        training_factors = all_factors.get("training", {})
        
        # 数据相关建议
        if data_factors.get("data_efficiency", 0) < 0.1:
            report["recommendations"].append({
                "category": "数据",
                "suggestion": "数据效率低，考虑收集更多样化的数据",
                "priority": "高",
            })
        
        # 模型相关建议
        if model_factors.get("finetuning_method", {}).get("method") == "full" and \
           data_factors.get("num_demos", 0) < 500:
            report["recommendations"].append({
                "category": "模型",
                "suggestion": "全参数微调数据不足，建议使用LoRA",
                "priority": "中",
            })
        
        # 训练相关建议
        convergence = training_factors.get("convergence", {}).get("status", "")
        if convergence == "收敛不佳":
            report["recommendations"].append({
                "category": "训练",
                "suggestion": "训练收敛不佳，建议降低学习率或检查数据",
                "priority": "高",
            })
        
        return report
```

**Q1: 请描述OpenVLA微调的完整流程，从数据准备到模型部署。**

> **回答框架**：
> 1. **数据准备**：收集任务特定的演示数据（图像+指令+动作），清洗和预处理
> 2. **策略选择**：根据数据量选择LoRA/全参数/冻结微调
> 3. **模型配置**：加载预训练模型，应用微调配置（如LoRA适配器）
> 4. **训练循环**：前向传播→计算损失→反向传播→参数更新，监控训练曲线
> 5. **验证评估**：在验证集上评估，防止过拟合，选择最佳checkpoint
> 6. **模型合并**：如果使用LoRA，将适配器权重合并回基础模型
> 7. **部署测试**：在实际机器人上测试，测量成功率和推理速度
> 8. **持续优化**：收集失败案例，迭代改进

**Q2: 微调过程中出现过拟合，如何解决？**

> **解决方案**：
> 1. **数据层面**：增加数据增强、收集更多数据、提高数据多样性
> 2. **模型层面**：增加正则化（weight_decay, dropout）、减少模型容量
> 3. **训练层面**：降低学习率、使用早停、增加梯度裁剪
> 4. **策略层面**：使用参数高效微调（LoRA）、冻结部分层
> 5. **监控层面**：密切监控训练/验证损失差距，及时调整

**Q3: 预训练模型在目标任务上成功率只有60%，微调后提升到90%，如何评估微调效果？**

> **评估维度**：
> 1. **绝对提升**：成功率从60%提升到90%（+30个百分点）
> 2. **相对提升**：相对改进50%（30/60）
> 3. **任务覆盖**：是否在所有子任务上都有提升
> 4. **泛化能力**：在新场景/新物体上是否保持性能
> 5. **推理效率**：微调后推理速度/显存是否显著变化
> 6. **数据效率**：用了多少演示数据达到这个效果
> 7. **稳定性**：多次运行结果的方差
> 8. **对比基准**：与其他微调方法对比

**Q4: LoRA微调和全参数微调如何选择？**

> **选择指南**：
> 1. **数据量**：<100 demos → LoRA；>500 demos → 可考虑全参数
> 2. **计算资源**：有限资源 → LoRA；充足资源 → 全参数
> 3. **任务复杂度**：简单任务 → LoRA；复杂任务 → 全参数
> 4. **泛化需求**：需要强泛化 → LoRA（保留预训练能力）
> 5. **部署约束**：需要快速迭代 → LoRA；最终部署 → 全参数
> 6. **实验结果**：小规模实验对比两者性能

**Q5: 训练曲线显示验证损失先降后升，如何诊断和解决？**

> **诊断流程**：
> 1. **确认过拟合**：检查训练损失是否持续下降
> 2. **分析原因**：数据量不足？模型太复杂？训练太久？
> 3. **解决方案**：
>    - 增加数据增强
>    - 增加正则化（weight_decay, dropout）
>    - 使用早停（基于验证损失）
>    - 减少模型容量或使用LoRA
>    - 降低学习率
> 4. **验证改进**：重新训练，监控训练/验证曲线
