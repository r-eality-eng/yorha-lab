## 三、Model 代码精读：从顶层到底层

### 3.1 最顶层：VLA类（`prismatic/models/vla.py`）

这是整个模型的核心类，理解它就理解了OpenVLA的全貌：

```python
"""
核心类：VLA（Vision-Language-Action Model）
继承自prismatic的VLM基类，增加action head
"""

class PrismaticVLA(nn.Module):
    """
    OpenVLA的完整模型定义
    
    组成部分：
    1. Visual Encoder (冻结): SigLIP + DINOv2 → Prismatic融合
    2. Projector (可训练): MLP将视觉特征映射到LLM维度
    3. LLM Backbone (可训练): Llama2-7B
    4. Action Head (可训练): 离散token → 连续动作
    
    数据流：
    Image → [Visual Encoder] → [Projector] → [LLM + Text Tokens] → [Action Tokens] → Continuous Actions
    """
    
    def __init__(self, config):
        super().__init__()
        
        # ====== 1. 视觉编码器 ======
        self.vision_backbone = self._build_vision_backbone(config)
        # 内部包含 SigLIP 和 DINOv2 两个子模块
        
        # ====== 2. 视觉→语言投影器 ======
        self.projector = self._build_projector(config)
        # 通常是 MLP: [visual_dim] → [hidden_dim] → [llm_dim]
        
        # ====== 3. 语言模型骨干 ======
        self.llm_backbone = self._build_llm_backbone(config)
        # Llama2-7B， 可加载HuggingFace权重
        
        # ====== 4. Action Tokenizer ======
        self.action_tokenizer = self._build_action_tokenizer(config)
        # 256 bins 连续→离散 转换器
        
    def _build_vision_backbone(self, config):
        """
        构建Prismatic视觉编码器
        包含SigLIP和DINOv2，且参数冻结
        """
        from prismatic.models.visual_encoders import PrismaticVisualEncoder
        
        encoder = PrismaticVisualEncoder(
            siglip_model=config.siglip_model,  # "SigLIP-SO400M/14@384"
            dinov2_model=config.dinov2_model,  # "DINOv2-ViT-L/14"
            freeze=True,                        # 关键：冻结！
            num_fusion_layers=config.num_fusion_layers
        )
        return encoder
    
    def _build_projector(self, config):
        """
        MLP投影器：视觉特征维度 → LLM隐藏层维度
        
        SigLIP输出: 1152维
        DINOv2输出: 1024维
        融合后: 1152 + 1024 = 2176维 (拼接方式)
        LLM维度: 4096维 (Llama2-7B)
        
        所以: 2176 → 4096
        """
        projector = build_mlp_projector(
            input_dim=config.visual_input_dim,   # 2176 或融合后的维度
            hidden_dim=config.projector_hidden_dim,  # 4096
            output_dim=config.llm_hidden_dim,     # 4096
            num_layers=2                          # 2层MLP
        )
        return projector
    
    def _build_llm_backbone(self, config):
        """
        加载Llama2-7B
        使用HuggingFace transformers加载
        """
        from transformers import LlamaForCausalLM
        
        llm = LlamaForCausalLM.from_pretrained(
            config.llm_name,  # "meta-llama/Llama-2-7b-hf"
            torch_dtype=torch.bfloat16
        )
        return llm
    
    def forward(self, images, input_ids, attention_mask, 
                action_labels=None, **kwargs):
        """
        前向传播完整流程
        
        Args:
            images: [B, 3, H, W]    输入图像
            input_ids: [B, seq_len]  文本token IDs（含instruction）
            attention_mask: [B, seq_len] 注意力掩码
            action_labels: [B, 7]   连续动作标签（训练时）
            
        Returns:
            logits: [B, seq_len, vocab_size] 词表logits
            action_preds: [B, 7] 连续动作预测（推理时）
        """
        # ====== Step 1: 视觉编码 ======
        # 输入: [B, 3, 384, 384]
        # 输出: [B, num_patches, visual_dim]  例如 [B, 729, 2176]
        visual_features = self.vision_backbone(images)
        
        # ====== Step 2: 视觉→LLM投影 ======
        # 输入: [B, 729, 2176]
        # 输出: [B, 729, 4096]
        visual_tokens = self.projector(visual_features)
        # 现在 visual_tokens 的维度和 LLM 的 embedding 维度一致
        
        # ====== Step 3: 拼接 visual tokens 和 text tokens ======
        # 先获取text的embedding
        text_embeddings = self.llm_backbone.get_input_embeddings()(input_ids)
        # text_embeddings: [B, text_seq_len, 4096]
        
        # 拼接：[visual_tokens | text_embeddings]
        # [B, 729, 4096] + [B, text_seq_len, 4096]
        # → [B, 729 + text_seq_len, 4096]
        inputs_embeds = torch.cat([visual_tokens, text_embeddings], dim=1)
        
        # 注意力掩码也要拼接
        # visual tokens 全部attend（全1）
        visual_mask = torch.ones(
            visual_tokens.shape[:2], device=visual_tokens.device
        )
        full_attention_mask = torch.cat([visual_mask, attention_mask], dim=1)
        
        # ====== Step 4: 送入LLM ======
        outputs = self.llm_backbone(
            inputs_embeds=inputs_embeds,       # 注意：用inputs_embeds而不是input_ids
            attention_mask=full_attention_mask,
            labels=action_labels,               # 训练时计算loss
            **kwargs
        )
        
        return outputs
    
    def predict_action(self, images, input_ids, attention_mask):
        """
        推理时的action预测
        
        自回归生成7个action tokens，然后解码为连续动作
        """
        # Step 1-3 同forward
        visual_features = self.vision_backbone(images)
        visual_tokens = self.projector(visual_features)
        text_embeddings = self.llm_backbone.get_input_embeddings()(input_ids)
        inputs_embeds = torch.cat([visual_tokens, text_embeddings], dim=1)
        visual_mask = torch.ones(visual_tokens.shape[:2], device=visual_tokens.device)
        full_attention_mask = torch.cat([visual_mask, attention_mask], dim=1)
        
        # Step 4: 自回归生成action tokens
        # 不是直接forward，而是用 generate()
        generated_ids = self.llm_backbone.generate(
            inputs_embeds=inputs_embeds,
            attention_mask=full_attention_mask,
            max_new_tokens=7,           # 只生成7个token（7维动作）
            do_sample=False,            # 贪心解码（确定性）
            temperature=1.0,
            pad_token_id=self.llm_backbone.config.eos_token_id
        )
        # generated_ids: [B, total_seq_len]
        # 最后7个token就是action tokens
        
        action_token_ids = generated_ids[:, -7:]  # [B, 7]
        
        # Step 5: Token → 连续动作
        continuous_actions = self.action_tokenizer.decode(action_token_ids)
        # [B, 7] 每个维度都是 [-1, 1] 范围的连续值
        
        return continuous_actions
```

### 3.2 视觉编码器详解（`prismatic/models/visual_encoders/`）

```python
"""
Prismatic视觉编码器
融合SigLIP和DINOv2的特征
"""

class PrismaticVisualEncoder(nn.Module):
    def __init__(self, siglip_model, dinov2_model, freeze=True):
        super().__init__()
        
        # 加载预训练编码器
        self.siglip_encoder = load_siglip(siglip_model)
        self.dinov2_encoder = load_dinov2(dinov2_model)
        
        # 获取输出维度
        # SigLIP-SO400M/14: hidden_dim=1152
        # DINOv2-ViT-L/14: hidden_dim=1024
        self.siglip_dim = self.siglip_encoder.config.hidden_size  # 1152
        self.dinov2_dim = self.dinov2_encoder.config.hidden_size  # 1024
        
        # 融合策略：拼接
        # 融合后维度 = 1152 + 1024 = 2176
        self.fused_dim = self.siglip_dim + self.dinov2_dim  # 2176
        
        if freeze:
            self._freeze_encoders()
    
    def _freeze_encoders(self):
        """冻结所有视觉编码器参数"""
        for param in self.siglip_encoder.parameters():
            param.requires_grad = False
        for param in self.dinov2_encoder.parameters():
            param.requires_grad = False
        
        self.siglip_encoder.eval()
        self.dinov2_encoder.eval()
        
        print(f"[PrismaticVisualEncoder] 视觉编码器已冻结")
        print(f"  SigLIP参数量: {sum(p.numel() for p in self.siglip_encoder.parameters())/1e6:.1f}M")
        print(f"  DINOv2参数量: {sum(p.numel() for p in self.dinov2_encoder.parameters())/1e6:.1f}M")
    
    def forward(self, images):
        """
        Args:
            images: [B, 3, 384, 384]
            
        Returns:
            fused_features: [B, num_patches, 2176]
        """
        with torch.no_grad():  # 视觉编码器不需要梯度
            
            # SigLIP编码
            # 输入: [B, 3, 384, 384]
            # Patch化: 384/14 = 27 → 27×27 = 729 patches
            # 输出: [B, 729, 1152]
            siglip_features = self.siglip_encoder.get_intermediate_layers(
                images, 
                n=1  # 只取最后一层
            )[-1]
            
            # DINOv2编码
            # 同样：384/14 = 27 → 729 patches
            # 输出: [B, 729, 1024]
            dinov2_features = self.dinov2_encoder.get_intermediate_layers(
                images,
                n=1
            )[-1]
        
        # 沿特征维度拼接
        # [B, 729, 1152] cat [B, 729, 1024] → [B, 729, 2176]
        fused_features = torch.cat([siglip_features, dinov2_features], dim=-1)
        
        return fused_features  # [B, 729, 2176]
```

**关键理解**：
```
图像 [384×384] 
    ↓ 
Patch化 [14×14 per patch]
    ↓
729个patch (27×27 grid)
    ↓
┌─────────────────┬─────────────────┐
│ SigLIP编码       │ DINOv2编码       │
│ 729×1152        │ 729×1024         │
│ (语义特征)       │ (空间特征)        │
└────────┬────────┴────────┬────────┘
         │    拼接          │
         └────────┬─────────┘
                  ↓
         729 × 2176 fused features
                  ↓
         送入Projection层
```

### 3.3 投影器详解

```python
"""
MLP Projector
将视觉特征映射到LLM的embedding空间
"""

class MLPProjector(nn.Module):
    """
    结构：Linear → GELU → Linear
    
    输入: 2176维 (视觉特征)
    输出: 4096维 (Llama2隐藏维度)
    """
    def __init__(self, input_dim=2176, hidden_dim=4096, output_dim=4096):
        super().__init__()
        
        self.projector = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),   # 2176 → 4096
            nn.GELU(),                          # 激活函数
            nn.Linear(hidden_dim, output_dim),  # 4096 → 4096
        )
        
        # 初始化（Xavier）
        self._init_weights()
    
    def _init_weights(self):
        for module in self.projector:
            if isinstance(module, nn.Linear):
                nn.init.xavier_uniform_(module.weight)
                nn.init.zeros_(module.bias)
    
    def forward(self, visual_features):
        """
        Args:
            visual_features: [B, 729, 2176]
        Returns:
            projected: [B, 729, 4096]
        """
        return self.projector(visual_features)
```

**为什么要投影器？**
```
SigLIP训练目标：图文对比学习 → 特征空间偏"语义"
DINOv2训练目标：自监督 → 特征空间偏"空间"
Llama2训练目标：语言建模 → embedding空间偏"语言"

三个空间不同！投影器的作用就是：
把视觉特征"翻译"到语言模型能理解的空间
```

### 3.4 Action Tokenizer 详解

```python
"""
Action Tokenizer
连续动作 ↔ 离散token 的转换

核心思想：
每个动作维度独立地离散化为256个bins
7维动作 → 7个token
"""

class ActionTokenizer:
    """
    将连续动作空间离散化
    
    原始动作空间: [-1, 1]^7
    离散化: 每个动作值映射到共享的256个bins
    
    例如 Δx = 0.35：
    - 256个bins覆盖 [-1, 1]
    - bin_width = 2.0 / 256 = 0.0078125
    - bin_index = int((0.35 + 1.0) / 0.0078125) = 172
    - token_id 映射到 tokenizer 词表最后的 action bin token

    注意：
    官方 OpenVLA 的实现不是 dim_0、dim_1、...、dim_6 各自占用一段独立词表。
    它默认使用 tokenizer 词表最后 n_bins 个 token 作为共享动作 bin。
    动作维度由生成序列中的位置隐式区分：第1个动作 token 表示 Δx，
    第2个表示 Δy，依此类推。
    """
    
    def __init__(self, tokenizer, n_bins=256, min_action=-1.0, max_action=1.0):
        """
        Args:
            tokenizer: 基础 LLM/VLM tokenizer
            n_bins: 每个维度的离散bins数量
            min_action: 动作最小值
            max_action: 动作最大值
        """
        self.tokenizer = tokenizer
        self.n_bins = n_bins
        self.min_action = min_action
        self.max_action = max_action
        self.bins = np.linspace(min_action, max_action, n_bins)
        self.bin_centers = (self.bins[:-1] + self.bins[1:]) / 2.0
        
        # 官方实现的关键：
        # 使用 tokenizer 词表最后 n_bins 个 token 作为动作 token 区间
        self.action_token_begin_idx = int(tokenizer.vocab_size - (n_bins + 1))
        
    def __call__(self, continuous_actions):
        """
        连续动作 → action token 字符串
        
        Args:
            continuous_actions: [B, 7] 或 [7] 连续动作值，范围 [-1, 1]
            
        Returns:
            action_tokens: 可被 tokenizer 拼接到文本序列中的动作 token
            
        Example:
            continuous: [0.35, -0.2, 0.1, 0.0, 0.5, -0.1, 1.0]
            tokens:     [172,  102,  138, 128, 192, 115, 255]
            token IDs:  tokenizer.vocab_size - discretized_action
        """
        # 1. 裁剪到合法范围
        actions = np.clip(continuous_actions, self.min_action, self.max_action)
        
        # 2. 每个动作值离散化到共享 bins
        discretized_action = np.digitize(actions, self.bins)
        
        # 3. 映射到词表最后 n_bins 个 token
        action_token_ids = self.tokenizer.vocab_size - discretized_action
        return self.tokenizer.decode(action_token_ids.tolist())
    
    def decode_token_ids_to_actions(self, action_token_ids):
        """
        离散token IDs → 连续动作
        
        Args:
            action_token_ids: [B, 7] 离散token IDs
            
        Returns:
            continuous_actions: [B, 7] 连续动作值
            
        解码是编码的逆过程
        """
        # 1. token id → bin index
        discretized_actions = self.tokenizer.vocab_size - action_token_ids
        
        # 2. digitize 返回的是 bin 边界索引，需要减1并裁剪到 bin_centers 范围
        discretized_actions = np.clip(
            discretized_actions - 1,
            a_min=0,
            a_max=self.bin_centers.shape[0] - 1,
        )
        
        return self.bin_centers[discretized_actions]
    
    @property
    def num_action_tokens(self):
        """共享动作bin token数量：默认256"""
        return self.n_bins


# ====== 精度分析 ======
def analyze_precision():
    """分析256 bins的精度损失"""
    n_bins = 256
    action_range = 2.0  # [-1, 1]
    bin_size = action_range / n_bins  # 0.0078125
    
    print(f"Bin size: {bin_size:.6f}")
    print(f"最大量化误差: {bin_size/2:.6f}")
    
    # 对于位置控制（假设1对应0.5m）
    # 精度 = 0.5m × 0.0078125 = 0.0039m ≈ 3.9mm
    # 对于大多数桌面操作，这个精度够用
    
    # 对于旋转控制（假设1对应π rad）
    # 精度 = π × 0.0078125 ≈ 0.0245 rad ≈ 1.4°
    # 大多数场景够用

# 输出：
# Bin size: 0.007812
# 最大量化误差: 0.003906
```

**动作token在词表中的位置**：
```
Llama2原始词表：
[0, 1, 2, ..., vocab_size - 257]  ← 常规语言tokens和其它低频tokens

OpenVLA动作token区间：
[vocab_size - 256, ..., vocab_size - 1]  ← 共享的256个动作bin token

7维动作如何区分？
第1个生成的 action token → Δx
第2个生成的 action token → Δy
第3个生成的 action token → Δz
第4个生成的 action token → Δrx
第5个生成的 action token → Δry
第6个生成的 action token → Δrz
第7个生成的 action token → gripper
```

**教学版和官方版的区别**：

| 项目 | 教学直觉版 | 官方 OpenVLA 实现 |
|---|---|---|
| 动作词表 | 容易误解成 `7 × 256 = 1792` 个 token | 默认共享最后 `256` 个 token |
| 维度区分 | 通过 `dim_id * n_bins` 显式区分 | 通过生成序列位置隐式区分 |
| 编码方向 | `vocab_offset + bin_index` | `tokenizer.vocab_size - discretized_action` |
| 解码函数 | 手写 offset 反解码 | `decode_token_ids_to_actions()` |
| 重要变量 | `vocab_offset` | `action_token_begin_idx` |

### 4.2 数据加载代码

```python
"""
OpenVLA数据加载流程
从RLDS格式到训练batch的完整pipeline
"""

import tensorflow_datasets as tfds
import tensorflow as tf
import numpy as np
import torch
from torch.utils.data import Dataset, DataLoader
from torchvision import transforms

class OXEDataset(Dataset):
    """
    Open X-Embodiment 数据集加载器
    
    关键设计：
    1. 使用tensorflow-datasets读取RLDS格式
    2. 每次采样一个step（不是整个episode）
    3. 图像做预处理（resize到384×384）
    4. 动作做归一化（到[-1, 1]）
    """
    
    def __init__(self, 
                 dataset_name="bridge_v2",
                 data_dir=None,
                 image_size=384,
                 action_dim=7,
                 obs_history=1,
                 action_horizon=1):
        """
        Args:
            dataset_name: 数据集名称，如"bridge_v2"
            data_dir: 数据存储路径
            image_size: 图像resize到的尺寸
            action_dim: 动作维度
            obs_history: 用几帧历史观测（OpenVLA默认1）
            action_horizon: 预测几步动作（OpenVLA默认1）
        """
        self.dataset_name = dataset_name
        self.image_size = image_size
        self.action_dim = action_dim
        self.obs_history = obs_history
        self.action_horizon = action_horizon
        
        # 图像预处理
        self.image_transform = transforms.Compose([
            transforms.Resize((image_size, image_size)),
            transforms.ToTensor(),         # [0, 255] → [0, 1]
            transforms.Normalize(           # ImageNet标准化
                mean=[0.485, 0.456, 0.406],
                std=[0.229, 0.224, 0.225]
            ),
        ])
        
        # 加载RLDS数据集
        self._load_dataset(data_dir)
        
        # 构建step索引：(episode_idx, step_idx)
        self._build_index()
        
        # 加载动作统计量（用于归一化）
        self._load_action_stats()
    
    def _load_dataset(self, data_dir):
        """使用tensorflow-datasets加载RLDS格式数据"""
        import tensorflow_datasets as tfds
        
        self.tfds_dataset = tfds.load(
            self.dataset_name,
            data_dir=data_dir,
            split="train"
        )
    
    def _build_index(self):
        """
        构建flat索引
        将(episode, step)展开为一维索引，方便随机采样
        
        例如3个episode，长度分别为[5, 3, 4]:
        索引: [(0,0),(0,1),(0,2),(0,3),(0,4),
               (1,0),(1,1),(1,2),
               (2,0),(2,1),(2,2),(2,3)]
        """
        self.step_indices = []
        for ep_idx, episode in enumerate(self.tfds_dataset):
            ep_length = len(episode["steps"])
            for step_idx in range(ep_length):
                self.step_indices.append((ep_idx, step_idx))
        
        print(f"[OXEDataset] {self.dataset_name}: "
              f"{len(self.step_indices)} steps")
    
    def _load_action_stats(self):
        """
        加载动作统计量（均值、标准差/最大最小值）
        用于归一化动作到 [-1, 1]
        
        这些统计量是预先在整个数据集上计算好的
        """
        stats_path = f"action_stats/{self.dataset_name}.npz"
        stats = np.load(stats_path)
        
        self.action_mean = stats["mean"]      # [7]
        self.action_std = stats["std"]        # [7]
        self.action_min = stats["min"]        # [7]
        self.action_max = stats["max"]        # [7]
    
    def _normalize_action(self, action):
        """
        动作归一化到 [-1, 1]
        
        方法：min-max归一化
        action_norm = 2 * (action - min) / (max - min) - 1
        """
        action_norm = 2.0 * (action - self.action_min) / \
                      (self.action_max - self.action_min + 1e-8) - 1.0
        return np.clip(action_norm, -1.0, 1.0)
    
    def _denormalize_action(self, action_norm):
        """反归一化：[-1, 1] → 原始范围"""
        action = (action_norm + 1.0) / 2.0 * \
                 (self.action_max - self.action_min) + self.action_min
        return action
    
    def __len__(self):
        return len(self.step_indices)
    
    def __getitem__(self, idx):
        """
        获取一个训练样本
        
        返回:
            image: [3, 384, 384] 预处理后的图像
            action: [7] 归一化后的动作
            language_instruction: str 语言指令
        """
        ep_idx, step_idx = self.step_indices[idx]
        
        # 获取episode数据
        episode = self.tfds_dataset[ep_idx]
        step = episode["steps"][step_idx]
        
        # ====== 图像处理 ======
        # 原始图像: numpy array [H, W, 3], uint8
        image_raw = step["observation"]["image"].numpy()
        # 转为PIL Image
        from PIL import Image
        image_pil = Image.fromarray(image_raw)
        # 应用变换: resize + normalize
        image = self.image_transform(image_pil)  # [3, 384, 384]
        
        # ====== 动作处理 ======
        action = step["action"].numpy()[:self.action_dim]  # [7]
        action_normed = self._normalize_action(action)       # [-1, 1]^7
        
        # ====== 语言指令 ======
        # OXE数据集每条episode都有自然语言标注
        # 例如 "pick up the red cup"
        if "language_instruction" in episode:
            instruction = episode["language_instruction"].numpy().decode()
        else:
            instruction = ""  # 某些数据集没有语言标注
        
        return {
            "image": image,                     # [3, 384, 384]
            "action": torch.tensor(action_normed, dtype=torch.float32),  # [7]
            "instruction": instruction,          # str
        }
```

### 4.3 Collator：将样本整理为Batch

```python
"""
Data Collator
将多个样本整理成一个batch
关键：处理文本tokenization
"""

class OpenVLACollator:
    """
    将Dataset返回的字典整理为模型输入格式
    
    处理流程：
    1. Stack图像 → [B, 3, 384, 384]
    2. Stack动作 → [B, 7]
    3. Tokenize文本指令 → [B, seq_len]
    4. 拼接action token IDs作为label
    """
    
    def __init__(self, tokenizer, action_tokenizer, 
                 max_length=256):
        self.tokenizer = tokenizer
        self.action_tokenizer = action_tokenizer
        self.max_length = max_length
    
    def __call__(self, batch):
        """
        Args:
            batch: list of dicts from Dataset.__getitem__
            
        Returns:
            dict with keys: pixel_values, input_ids, attention_mask, labels
        """
        # 1. 图像
        pixel_values = torch.stack([s["image"] for s in batch])
        # [B, 3, 384, 384]
        
        # 2. 动作
        actions = torch.stack([s["action"] for s in batch])
        # [B, 7]
        
        # 3. 语言指令tokenization
        instructions = [s["instruction"] for s in batch]
        
        # 构造prompt格式
        prompts = []
        for inst in instructions:
            # OpenVLA的prompt格式
            prompt = f"In: What action should the robot take to {inst}?\nOut:"
            prompts.append(prompt)
        
        # Tokenize
        text_inputs = self.tokenizer(
            prompts,
            padding=True,
            truncation=True,
            max_length=self.max_length,
            return_tensors="pt"
        )
        input_ids = text_inputs.input_ids         # [B, text_seq_len]
        attention_mask = text_inputs.attention_mask # [B, text_seq_len]
        
        # 4. 构造动作监督
        # 教学简化：这里把动作 token 单独返回，便于理解。
        # 官方实现通常会把 action_token_string 拼到 prompt 后面，
        # 再由 tokenizer 形成 input_ids / labels，并使用 causal LM shift loss。
        action_token_strings = [self.action_tokenizer(a.numpy()) for a in actions]
        labels = build_action_labels(action_token_strings, text_inputs)
        
        return {
            "pixel_values": pixel_values,       # [B, 3, 384, 384]
            "input_ids": input_ids,             # [B, text_seq_len]
            "attention_mask": attention_mask,    # [B, text_seq_len]
            "labels": labels,                   # [B, seq_len]，非动作位置通常ignore
            "actions_continuous": actions,       # [B, 7] (评估用)
        }
```

**官方实现对照**：

| 教学材料中的名字 | 官方 OpenVLA 中更接近的实现 | 说明 |
|---|---|---|
| `OpenVLACollator` | `PaddedCollatorForActionPrediction` | 负责 padding、labels、attention mask 等 batch 整理 |
| `ActionTokenizer.encode()` | `ActionTokenizer.__call__()` | 官方把连续动作转成 action token 字符串，再进入 tokenizer 流程 |
| `labels = action_token_ids` | `input_ids/labels` 序列级监督 | 官方训练通常把 action tokens 拼到序列末尾，再用 causal LM 的 shift loss |
| `OXEDataset` | `RLDSDataset` / `RLDSBatchTransform` | 官方围绕 RLDS 数据和 batch transform 组织数据管线 |

### 5.2 损失函数详解

```python
"""
OpenVLA的损失函数

核心：在action token位置计算CrossEntropyLoss
不是整个序列都算loss，只算生成action的部分
"""

class OpenVLALoss(nn.Module):
    """
    OpenVLA使用标准的CrossEntropyLoss
    但需要注意：只在action token位置计算loss
    
    输入序列结构：
    [V₁...V₇₂₉ | L₁...Lₙ | A₁...A₇]
     ^^^^^^^^^^^^^^^^^^^^^^^^         ↑
     这些位置不计算loss              只在这里算loss
    """
    
    def __init__(self, vocab_size):
        super().__init__()
        self.loss_fn = nn.CrossEntropyLoss(
            ignore_index=-100,  # -100位置不参与loss计算
        )
    
    def forward(self, logits, labels):
        """
        Args:
            logits: [B, seq_len, vocab_size] 模型输出logits
            labels: [B, 7] action token IDs (目标)
            
        Returns:
            loss: scalar
        """
        # 方法1：如果labels直接是[B, 7] action token IDs
        # 需要从logits中取最后7个位置
        action_logits = logits[:, -7:, :]  # [B, 7, vocab_size]
        
        # Reshape for CrossEntropy
        action_logits = action_logits.reshape(-1, logits.shape[-1])  # [B*7, vocab_size]
        labels_flat = labels.reshape(-1)  # [B*7]
        
        loss = self.loss_fn(action_logits, labels_flat)
        
        return loss


# ====== 详细计算过程 ======
"""
假设：
- batch_size = 4
- seq_len = 729 + text_len + 7
- vocab_size = tokenizer.vocab_size

模型输出: logits [4, seq_len, vocab_size]

取action位置: action_logits [4, 7, vocab_size]

对每个位置计算softmax:
  P(token_k | context) = exp(logit_k) / Σ exp(logit_j)

目标token: labels [4, 7]
  例如: [vocab_size-172, vocab_size-102, ..., vocab_size-255]

Loss = -1/28 Σᵢ log P(labels[i] | context_i)
     = CrossEntropyLoss(action_logits, labels)
"""
```

**官方实现提醒**：
上面的代码是教学版，用来说明“只在动作位置算loss”。
官方 OpenVLA 训练里还要处理 next-token prediction 的 shift：
通常会用 `labels[:, 1:]` 对齐 `logits[:, :-1]`，并只取 action token 对应区间。
因此真正写训练代码时，不要只机械地取 `logits[:, -7:, :]`，而要确认 prompt、action token 和 label shift 的位置完全对齐。

### 6.1 安装后快速验证

```python
"""
快速验证OpenVLA推理
不需要训练数据，只需要预训练模型
"""

from transformers import AutoModelForVision2Seq, AutoProcessor
from PIL import Image
import torch

# ====== Step 1: 加载预训练模型 ======
# OpenVLA提供7B预训练权重，可以直接用
model = AutoModelForVision2Seq.from_pretrained(
    "openvla/openvla-7b",
    torch_dtype=torch.bfloat16,
    low_cpu_mem_usage=True,
    trust_remote_code=True,
).to("cuda")

processor = AutoProcessor.from_pretrained(
    "openvla/openvla-7b", 
    trust_remote_code=True
)

print(f"模型加载成功！参数量: {sum(p.numel() for p in model.parameters())/1e9:.2f}B")

# ====== Step 2: 准备输入 ======
# 加载一张图片（模拟机器人视角）
image = Image.open("test_image.jpg")  # 任意RGB图片

# 语言指令
instruction = "pick up the red cup"

# 构造prompt
prompt = f"In: What action should the robot take to {instruction}?\nOut:"

# ====== Step 3: 预处理 ======
inputs = processor(prompt, image).to("cuda", dtype=torch.bfloat16)
# inputs包含: pixel_values [1, 3, 384, 384], input_ids [1, seq_len]

# ====== Step 4: 推理 ======
import time

# 预热
for _ in range(3):
    with torch.no_grad():
        _ = model.generate(
            **inputs,
            max_new_tokens=7,
            do_sample=False,
        )

# 正式计时
torch.cuda.synchronize()
start = time.perf_counter()

action = model.predict_action(
    **inputs,
    unnorm_key="bridge_orig",  # 使用对应数据集/机器人动作统计量反归一化
    do_sample=False,           # 贪心解码
)

torch.cuda.synchronize()
elapsed = time.perf_counter() - start

print(f"\n推理耗时: {elapsed*1000:.1f} ms")
print(f"控制频率: {1/elapsed:.1f} Hz")
print(f"预测动作: {action}")

# ====== Step 5: 解释动作 ======
# predict_action 内部已经完成：
# generate action token ids → decode_token_ids_to_actions → unnormalize action

print(f"连续动作: {[f'{a:.4f}' for a in action]}")
print(f"  Δx={action[0]:.4f}, Δy={action[1]:.4f}, Δz={action[2]:.4f}")
print(f"  Δrx={action[3]:.4f}, Δry={action[4]:.4f}, Δrz={action[5]:.4f}")
print(f"  gripper={action[6]:.4f}")
```

## 七、面试模拟：代码相关问题

**Q1: 请描述OpenVLA训练的完整数据流，从原始数据到loss计算。**

> **回答框架（STAR式）**：
> 
> 1. **数据存储**：OXE数据集以RLDS格式存储在磁盘上（TFRecord）
> 2. **数据加载**：`tensorflow-datasets`读取，`OXEDataset.__getitem__`返回单个step
> 3. **预处理**：图像resize到384×384 + ImageNet归一化；动作min-max归一化到[-1,1]
> 4. **Batch整理**：`Collator`将图像stack为`[B,3,384,384]`，文本tokenize为`[B,seq_len]`，动作encode为`[B,7]`的token IDs
> 5. **模型前向**：图像→双编码器→投影→visual tokens；与text tokens拼接→Llama2
> 6. **Loss计算**：取最后7个位置的logits，用CrossEntropyLoss计算与action token labels的损失
> 7. **反向传播**：BF16混合精度 + gradient checkpointing + 梯度累积

**Q2: OpenVLA为什么要冻结视觉编码器？如果全部解冻会怎样？**

> **回答要点**：
> - 视觉编码器（SigLIP + DINOv2）已在大规模数据上预训练好，特征质量高
> - 冻结可节省约600M参数的梯度和优化器状态 → 省约30%显存
> - 避免小规模机器人数据破坏预训练特征
> - 如果全部解冻：需要更大batch + 更多数据 + 更小学习率；否则可能灾难性遗忘

**Q3: 动作token的CrossEntropyLoss和LLM语言建模的loss有什么区别？**

> **回答要点**：
> - 本质上是一样的：都是next-token prediction
> - 区别在于**计算位置**：只在action token位置算loss，文本位置ignore（`label=-100`）
> - 词表大小是 `tokenizer.vocab_size`，官方默认借用最后256个token作为共享动作bin
> - 面试追问：*"这意味着什么？"* → 动作离散化复用了语言模型的分类头，但动作维度由生成位置区分，存在词表复用和自回归延迟的取舍
