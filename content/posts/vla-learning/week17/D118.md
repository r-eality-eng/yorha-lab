> 论文对比：*Heterogeneous Pretrained Transformers (HPT)* vs *Robotics Diffusion Transformer (RDT)*  
> 核心问题：在机器人基础模型设计中，如何选择最佳的架构范式？

> **优化补充：D118 学习导读**  
> D118 是“架构设计空间”课，不是单篇论文复述。你要学会按任务需求选择架构：  
> - **HPT / Stem-Trunk-Head** 更像统一表征学习框架，重点解决异构机器人数据、不同输入模态、不同任务头的统一建模。  
> - **RDT / Diffusion Transformer** 更关注条件动作生成质量，适合多模态动作分布和较复杂的连续动作序列。  
> - **DiT Scaling** 是把 diffusion transformer 的缩放经验迁移到机器人动作生成，关注模型规模、数据规模、潜在空间、条件注入和采样步数之间的关系。

> **准确性提醒：代码是架构草图，不是官方实现**  
> 本节出现的 `HPT`、`RDT`、`DiTForRobotics` 等类用于解释模块边界和数据流，存在很多未定义组件，例如 `ImageEncoder`、`DiTBlockWithScaling`、`create_diffusion`、`FinalLayer`。它们不能直接运行。优化后的学习目标是理解设计维度，而不是把这些代码作为工程模板复制。

> **官方论文 vs 教学抽象**  
> | 内容 | 更稳妥的说法 | 不建议的说法 |
> |---|---|---|
> | HPT | 一类强调 heterogeneous embodiment / modality 统一表征、stem-trunk-head 或 adapter 式迁移的机器人基础模型设计思路 | HPT 就一定等于下面这份 Python 类 |
> | RDT | 以 Diffusion Transformer 为核心的机器人动作序列生成范式，关注多模态条件和动作去噪 | RDT 的官方代码就是下面这套 `DDPMScheduler + DiTBlock` |
> | DiT Scaling | 把 diffusion transformer 的缩放经验迁移到机器人动作生成，讨论模型规模、数据规模、采样步数和条件注入 | DiT Scaling 是一个固定模型名称 |
> | 对比实验 | 应按统一数据集、任务、硬件、采样步数比较 | 直接把不同论文的数字横向相减 |

> **面试表达建议**  
> 面试中讲 HPT/RDT/DiT 时，不要陷入代码细节。更好的回答结构是：  
> 1. 先说任务约束：实时性、动作多样性、跨机器人泛化、数据异构程度。  
> 2. 再说架构选择：HPT 偏表征和迁移，RDT 偏高质量生成，DiT 偏扩散模型缩放。  
> 3. 最后说 trade-off：单次前向 vs 多步采样，确定性回归 vs 多样性采样，模块化适配 vs 端到端生成。

## 一、设计空间概述

### 1.1 机器人基础模型的三大架构范式

```
机器人基础模型架构设计空间：

范式1: 纯编码器-解码器架构 (HPT)
┌─────────────────────────────────────┐
│ 输入异构数据 → Stem编码 → Trunk处理 → Head输出 │
│ 强调：数据异构性处理、表征学习            │
└─────────────────────────────────────┘

范式2: 扩散模型架构 (RDT)
┌─────────────────────────────────────┐
│ 条件输入 → 扩散过程 → Transformer生成 → 动作序列 │
│ 强调：生成质量、多模态分布               │
└─────────────────────────────────────┘

范式3: DiT缩放范式 (DiT for Robotics)
┌─────────────────────────────────────┐
│ 潜在变量 + 条件 → DiT块 → 去噪预测     │
│ 强调：缩放律、条件控制、高效生成         │
└─────────────────────────────────────┘
```

### 1.2 设计维度矩阵

```
设计维度         HPT                 RDT                 DiT Scaling
────────────────────────────────────────────────────────────────────
核心目标         表征学习             动作生成             条件生成
训练范式         预训练+微调          扩散训练             扩散+缩放
输入处理         多模态融合           条件编码             条件注入
输出类型         特征/动作            动作分布             潜在变量
计算效率         高（单次前向）       低（多次迭代）       中（可调迭代）
泛化能力         强（跨机器人）       中（任务特化）       强（缩放提升）
生成质量         中（确定性）         高（随机性）         高（可调多样性）
```

## 二、HPT: 异构预训练Transformer

### 2.1 核心思想

```
HPT的设计哲学：
  "用一个统一模型处理所有机器人数据"
  
关键创新：
1. Stem-Trunk-Head模块化架构
2. 异构数据统一编码
3. 跨机器人迁移学习
4. 轻量级适配机制
```

### 2.2 详细架构实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class HPT(nn.Module):
    """
    Heterogeneous Pretrained Transformer (HPT)
    
    核心组件：
    1. Stem: 处理异构输入（图像、状态、点云等）
    2. Trunk: 共享的Transformer编码器
    3. Head: 任务特定输出层
    4. Adapters: 轻量级适配模块
    """
    
    def __init__(self, config):
        super().__init__()
        
        self.config = config
        
        # 1. Stem: 多模态编码器
        self.stems = nn.ModuleDict({
            'image': ImageStem(config),
            'state': StateStem(config),
            'pointcloud': PointCloudStem(config),
            'language': LanguageStem(config)
        })
        
        # 2. Trunk: 共享Transformer
        self.trunk = TrunkTransformer(
            d_model=config.d_model,
            nhead=config.nhead,
            num_layers=config.num_layers,
            dim_feedforward=config.dim_feedforward
        )
        
        # 3. Head: 任务特定头
        self.heads = nn.ModuleDict({
            'manipulation': ManipulationHead(config),
            'navigation': NavigationHead(config),
            'locomotion': LocomotionHead(config)
        })
        
        # 4. Adapters: 机器人特定适配器
        self.adapters = nn.ModuleDict({
            robot_name: AdapterLayer(config)
            for robot_name in config.supported_robots
        })
        
        # 5. 统一嵌入空间投影
        self.unified_projector = nn.Linear(config.d_model, config.unified_dim)
        
    def forward(self, inputs, robot_type, task_type):
        """
        前向传播
        
        Args:
            inputs: dict - 包含各种模态的输入
                inputs['image']: [B, C, H, W]
                inputs['state']: [B, state_dim]
                ...
            robot_type: str - 机器人类型
            task_type: str - 任务类型
        """
        # 1. Stem编码：处理异构输入
        stem_outputs = []
        for modality, data in inputs.items():
            if modality in self.stems:
                stem_output = self.stems[modality](data)
                stem_outputs.append(stem_output)
        
        # 2. 拼接所有模态的嵌入
        # 每个stem输出: [B, seq_len, d_model]
        combined_stems = torch.cat(stem_outputs, dim=1)  # [B, total_seq_len, d_model]
        
        # 3. 应用机器人特定适配器
        if robot_type in self.adapters:
            combined_stems = self.adapters[robot_type](combined_stems)
        
        # 4. Trunk处理
        trunk_output = self.trunk(combined_stems)  # [B, total_seq_len, d_model]
        
        # 5. 统一嵌入空间（用于跨机器人迁移）
        unified_repr = self.unified_projector(trunk_output.mean(dim=1))  # [B, unified_dim]
        
        # 6. Head输出
        output = self.heads[task_type](trunk_output, unified_repr)
        
        return {
            'output': output,
            'unified_repr': unified_repr,
            'trunk_features': trunk_output
        }

class ImageStem(nn.Module):
    """图像编码器：使用ViT风格的Patch Embedding"""
    
    def __init__(self, config):
        super().__init__()
        
        self.patch_size = config.patch_size
        self.d_model = config.d_model
        
        # Patch嵌入
        self.patch_embedding = nn.Conv2d(
            in_channels=3,
            out_channels=config.d_model,
            kernel_size=config.patch_size,
            stride=config.patch_size
        )
        
        # 位置编码
        num_patches = (config.image_size // config.patch_size) ** 2
        self.position_embedding = nn.Parameter(
            torch.randn(1, num_patches + 1, config.d_model)  # +1 for CLS token
        )
        
        # CLS token
        self.cls_token = nn.Parameter(torch.randn(1, 1, config.d_model))
        
        # 编码器层
        self.encoder = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(
                d_model=config.d_model,
                nhead=config.nhead,
                dim_feedforward=config.dim_feedforward,
                batch_first=True
            ),
            num_layers=config.stem_layers
        )
    
    def forward(self, images):
        """图像编码"""
        batch_size = images.shape[0]
        
        # Patch嵌入
        patches = self.patch_embedding(images)  # [B, d_model, H/p, W/p]
        patches = patches.flatten(2).transpose(1, 2)  # [B, num_patches, d_model]
        
        # 添加CLS token
        cls_tokens = self.cls_token.expand(batch_size, -1, -1)
        patches = torch.cat([cls_tokens, patches], dim=1)  # [B, num_patches+1, d_model]
        
        # 添加位置编码
        patches = patches + self.position_embedding
        
        # Transformer编码
        output = self.encoder(patches)
        
        return output

class StateStem(nn.Module):
    """状态编码器：处理低维状态向量"""
    
    def __init__(self, config):
        super().__init__()
        
        self.state_dim = config.state_dim
        
        # 状态嵌入
        self.state_embedding = nn.Sequential(
            nn.Linear(config.state_dim, config.d_model),
            nn.LayerNorm(config.d_model),
            nn.GELU(),
            nn.Linear(config.d_model, config.d_model)
        )
        
        # 可学习的状态token（用于对齐不同模态的序列长度）
        self.state_token = nn.Parameter(torch.randn(1, 1, config.d_model))
        
    def forward(self, states):
        """状态编码"""
        batch_size = states.shape[0]
        
        # 嵌入状态
        state_embed = self.state_embedding(states)  # [B, d_model]
        state_embed = state_embed.unsqueeze(1)  # [B, 1, d_model]
        
        # 重复state token以匹配其他模态的序列长度
        # 这里简化处理，实际可能需要更复杂的对齐
        state_tokens = self.state_token.expand(batch_size, -1, -1)
        
        # 拼接（简单起见，这里只返回状态嵌入）
        output = torch.cat([state_tokens, state_embed], dim=1)
        
        return output

class PointCloudStem(nn.Module):
    """点云编码器"""
    
    def __init__(self, config):
        super().__init__()
        
        # 点云特征提取
        self.point_encoder = nn.Sequential(
            nn.Linear(3, 64),  # xyz坐标
            nn.ReLU(),
            nn.Linear(64, 128),
            nn.ReLU(),
            nn.Linear(128, config.d_model)
        )
        
        # Transformer编码点云
        self.transformer = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(
                d_model=config.d_model,
                nhead=config.nhead,
                dim_feedforward=config.dim_feedforward,
                batch_first=True
            ),
            num_layers=2
        )
        
    def forward(self, pointclouds):
        """点云编码"""
        # pointclouds: [B, N, 3]
        batch_size, num_points, _ = pointclouds.shape
        
        # 特征提取
        point_features = self.point_encoder(pointclouds)  # [B, N, d_model]
        
        # 添加全局token
        global_token = torch.mean(point_features, dim=1, keepdim=True)  # [B, 1, d_model]
        point_features = torch.cat([global_token, point_features], dim=1)
        
        # Transformer编码
        output = self.transformer(point_features)
        
        return output

class LanguageStem(nn.Module):
    """语言编码器"""
    
    def __init__(self, config):
        super().__init__()
        
        # 使用预训练语言模型的嵌入层
        self.embedding = nn.Embedding(config.vocab_size, config.d_model)
        
        # 位置编码
        self.position_embedding = nn.Embedding(config.max_seq_len, config.d_model)
        
        # Transformer编码器
        self.transformer = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(
                d_model=config.d_model,
                nhead=config.nhead,
                dim_feedforward=config.dim_feedforward,
                batch_first=True
            ),
            num_layers=2
        )
        
    def forward(self, language_tokens):
        """语言编码"""
        # language_tokens: [B, L]
        batch_size, seq_len = language_tokens.shape
        
        # 嵌入
        token_embed = self.embedding(language_tokens)  # [B, L, d_model]
        
        # 位置编码
        positions = torch.arange(seq_len, device=language_tokens.device).unsqueeze(0)
        pos_embed = self.position_embedding(positions)
        
        # 相加
        embeddings = token_embed + pos_embed
        
        # Transformer编码
        output = self.transformer(embeddings)
        
        return output

class TrunkTransformer(nn.Module):
    """共享Transformer主干"""
    
    def __init__(self, d_model, nhead, num_layers, dim_feedforward):
        super().__init__()
        
        # Transformer编码器
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model,
            nhead=nhead,
            dim_feedforward=dim_feedforward,
            batch_first=True,
            activation='gelu'
        )
        
        self.transformer = nn.TransformerEncoder(
            encoder_layer,
            num_layers=num_layers
        )
        
        # 层归一化
        self.norm = nn.LayerNorm(d_model)
        
    def forward(self, x):
        """前向传播"""
        # x: [B, total_seq_len, d_model]
        
        # Transformer处理
        output = self.transformer(x)
        
        # 层归一化
        output = self.norm(output)
        
        return output

class AdapterLayer(nn.Module):
    """轻量级适配器层（用于机器人特定调整）"""
    
    def __init__(self, config):
        super().__init__()
        
        self.d_model = config.d_model
        self.adapter_size = config.adapter_size
        
        # 下投影
        self.down_project = nn.Linear(config.d_model, config.adapter_size)
        
        # 非线性激活
        self.activation = nn.GELU()
        
        # 上投影
        self.up_project = nn.Linear(config.adapter_size, config.d_model)
        
        # 缩放因子（可学习）
        self.scale = nn.Parameter(torch.ones(1) * 0.1)
        
    def forward(self, x):
        """适配器前向传播"""
        # 残差连接
        residual = x
        
        # 适配器计算
        adapter_out = self.down_project(x)
        adapter_out = self.activation(adapter_out)
        adapter_out = self.up_project(adapter_out)
        
        # 缩放并添加残差
        output = residual + self.scale * adapter_out
        
        return output

class ManipulationHead(nn.Module):
    """操作任务头"""
    
    def __init__(self, config):
        super().__init__()
        
        # 特征聚合
        self.feature_aggregator = nn.Sequential(
            nn.Linear(config.d_model * 2, config.d_model),
            nn.ReLU(),
            nn.Linear(config.d_model, config.d_model)
        )
        
        # 动作预测
        self.action_predictor = nn.Sequential(
            nn.Linear(config.d_model, 256),
            nn.ReLU(),
            nn.Linear(256, config.action_dim)
        )
        
        # 值函数预测（可选）
        self.value_predictor = nn.Sequential(
            nn.Linear(config.d_model, 128),
            nn.ReLU(),
            nn.Linear(128, 1)
        )
        
    def forward(self, trunk_output, unified_repr):
        """前向传播"""
        # trunk_output: [B, seq_len, d_model]
        # unified_repr: [B, unified_dim]
        
        # 聚合特征
        global_feature = torch.mean(trunk_output, dim=1)  # [B, d_model]
        combined = torch.cat([global_feature, unified_repr], dim=-1)  # [B, d_model + unified_dim]
        
        # 特征处理
        processed = self.feature_aggregator(combined)  # [B, d_model]
        
        # 预测动作
        actions = self.action_predictor(processed)  # [B, action_dim]
        
        # 预测值函数（可选）
        value = self.value_predictor(processed)  # [B, 1]
        
        return {
            'actions': actions,
            'value': value
        }
```

## 三、RDT: 机器人扩散Transformer

### 3.1 核心思想

```
RDT的设计哲学：
  "用扩散模型生成高质量的机器人动作序列"
  
关键创新：
1. 条件扩散Transformer
2. 机器人动作序列建模
3. 任务条件注入
4. 多模态生成
```

### 3.2 详细架构实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
from diffusers import DDPMScheduler

class RDT(nn.Module):
    """
    Robotics Diffusion Transformer (RDT)
    
    核心组件：
    1. 条件编码器：处理图像、语言、状态条件
    2. 扩散调度器：管理噪声过程
    3. Transformer主干：预测噪声/动作
    4. 时间嵌入：扩散时间步编码
    """
    
    def __init__(self, config):
        super().__init__()
        
        self.config = config
        
        # 1. 条件编码器
        self.condition_encoder = ConditionEncoder(config)
        
        # 2. 扩散调度器
        self.scheduler = DDPMScheduler(
            num_train_timesteps=config.diffusion_steps,
            beta_schedule='squaredcos_cap_v2',
            prediction_type='epsilon'  # 或 'v_prediction'
        )
        
        # 3. 时间嵌入
        self.time_embedding = TimestepEmbedding(config.d_model)
        
        # 4. 动作嵌入
        self.action_embedding = ActionEmbedding(config)
        
        # 5. Transformer主干（DiT风格）
        self.transformer = DiTBlock(
            d_model=config.d_model,
            nhead=config.nhead,
            num_layers=config.num_layers,
            dim_feedforward=config.dim_feedforward,
            context_dim=config.context_dim
        )
        
        # 6. 输出头
        self.output_head = OutputHead(config)
        
    def forward(self, actions, conditions, timesteps=None, noise=None):
        """
        训练时前向传播
        
        Args:
            actions: [B, T, action_dim] - 目标动作序列
            conditions: dict - 条件信息（图像、语言、状态等）
            timesteps: [B] - 扩散时间步
            noise: [B, T, action_dim] - 可选的噪声
        """
        batch_size = actions.shape[0]
        
        # 1. 编码条件
        cond_embeddings = self.condition_encoder(conditions)
        # cond_embeddings: [B, context_len, context_dim]
        
        # 2. 添加噪声到动作序列
        if timesteps is None:
            timesteps = torch.randint(0, self.scheduler.num_train_timesteps, (batch_size,), device=actions.device)
        
        if noise is None:
            noise = torch.randn_like(actions)
        
        # 添加噪声
        noisy_actions = self.scheduler.add_noise(actions, noise, timesteps)
        
        # 3. 嵌入动作和时间
        action_embed = self.action_embedding(noisy_actions)  # [B, T, d_model]
        time_embed = self.time_embedding(timesteps)  # [B, d_model]
        
        # 4. 条件注入（通过拼接或交叉注意力）
        # 这里使用DiT风格的自适应层归一化
        transformer_output = self.transformer(
            x=action_embed,
            context=cond_embeddings,
            time_embed=time_embed
        )
        
        # 5. 预测噪声/动作
        predicted = self.output_head(transformer_output)
        
        # 6. 计算损失
        if self.scheduler.config.prediction_type == 'epsilon':
            target = noise
        elif self.scheduler.config.prediction_type == 'v_prediction':
            target = self.scheduler.get_velocity(actions, noise, timesteps)
        else:
            raise ValueError(f"Unknown prediction type: {self.scheduler.config.prediction_type}")
        
        loss = F.mse_loss(predicted, target)
        
        return {
            'loss': loss,
            'predicted': predicted,
            'noisy_actions': noisy_actions
        }
    
    @torch.no_grad()
    def generate(self, conditions, num_steps=50, return_trajectory=False):
        """
        生成动作序列
        
        Args:
            conditions: dict - 条件信息
            num_steps: 去噪步数
            return_trajectory: 是否返回中间轨迹
        """
        batch_size = next(iter(conditions.values())).shape[0]
        
        # 1. 初始化纯噪声
        actions = torch.randn(
            batch_size, 
            self.config.action_horizon, 
            self.config.action_dim,
            device=next(self.parameters()).device
        )
        
        # 2. 设置调度器
        self.scheduler.set_timesteps(num_steps)
        
        # 3. 迭代去噪
        trajectory = [actions.cpu()]
        
        for t in self.scheduler.timesteps:
            # 准备时间步
            timesteps = torch.full((batch_size,), t, device=actions.device, dtype=torch.long)
            
            # 预测噪声
            model_output = self.forward(
                actions=actions,
                conditions=conditions,
                timesteps=timesteps
            )
            
            # 去噪步骤
            actions = self.scheduler.step(
                model_output['predicted'],
                t,
                actions
            ).prev_sample
            
            if return_trajectory:
                trajectory.append(actions.cpu())
        
        # 4. 限制动作范围
        actions = torch.clamp(actions, -1.0, 1.0)
        
        if return_trajectory:
            return actions, trajectory
        else:
            return actions

class ConditionEncoder(nn.Module):
    """条件编码器：处理多模态条件输入"""
    
    def __init__(self, config):
        super().__init__()
        
        # 图像编码器（使用预训练CNN或ViT）
        self.image_encoder = ImageEncoder(config)
        
        # 语言编码器
        self.language_encoder = LanguageEncoder(config)
        
        # 状态编码器
        self.state_encoder = StateEncoder(config)
        
        # 多模态融合
        self.multimodal_fusion = nn.MultiheadAttention(
            embed_dim=config.context_dim,
            num_heads=config.nhead,
            batch_first=True
        )
        
        # 投影层
        self.projection = nn.Linear(config.d_model, config.context_dim)
        
    def forward(self, conditions):
        """编码条件"""
        embeddings = []
        
        # 图像条件
        if 'image' in conditions:
            img_embed = self.image_encoder(conditions['image'])  # [B, img_seq_len, d_model]
            embeddings.append(img_embed)
        
        # 语言条件
        if 'language' in conditions:
            lang_embed = self.language_encoder(conditions['language'])  # [B, lang_seq_len, d_model]
            embeddings.append(lang_embed)
        
        # 状态条件
        if 'state' in conditions:
            state_embed = self.state_encoder(conditions['state'])  # [B, state_seq_len, d_model]
            embeddings.append(state_embed)
        
        # 拼接所有嵌入
        if embeddings:
            combined = torch.cat(embeddings, dim=1)  # [B, total_seq_len, d_model]
            
            # 投影到上下文维度
            context = self.projection(combined)  # [B, total_seq_len, context_dim]
        else:
            # 如果没有条件，使用零向量
            batch_size = next(iter(conditions.values())).shape[0]
            context = torch.zeros(batch_size, 1, self.config.context_dim, 
                                 device=next(iter(conditions.values())).device)
        
        return context

class DiTBlock(nn.Module):
    """
    Diffusion Transformer块
    使用自适应层归一化（AdaLN）注入条件信息
    """
    
    def __init__(self, d_model, nhead, num_layers, dim_feedforward, context_dim):
        super().__init__()
        
        self.d_model = d_model
        self.context_dim = context_dim
        
        # Transformer层
        self.layers = nn.ModuleList([
            DiTLayer(d_model, nhead, dim_feedforward, context_dim)
            for _ in range(num_layers)
        ])
        
        # 最终层归一化
        self.norm = nn.LayerNorm(d_model)
        
        # 上下文投影
        self.context_proj = nn.Linear(context_dim, d_model * 2)  # 用于AdaLN的scale和shift
        
    def forward(self, x, context, time_embed):
        """
        前向传播
        
        Args:
            x: [B, T, d_model] - 带噪动作嵌入
            context: [B, context_len, context_dim] - 条件上下文
            time_embed: [B, d_model] - 时间嵌入
        """
        # 聚合上下文（平均池化）
        context_aggregated = torch.mean(context, dim=1)  # [B, context_dim]
        
        # 投影到AdaLN参数
        ada_params = self.context_proj(context_aggregated)  # [B, d_model * 2]
        scale, shift = ada_params.chunk(2, dim=-1)  # 各 [B, d_model]
        
        # 添加时间嵌入
        x = x + time_embed.unsqueeze(1)  # [B, T, d_model]
        
        # 通过Transformer层
        for layer in self.layers:
            x = layer(x, context, scale, shift)
        
        # 最终归一化
        x = self.norm(x)
        
        return x

class DiTLayer(nn.Module):
    """DiT层：自注意力 + FFN + AdaLN"""
    
    def __init__(self, d_model, nhead, dim_feedforward, context_dim):
        super().__init__()
        
        # 自注意力
        self.self_attn = nn.MultiheadAttention(
            d_model, nhead, batch_first=True
        )
        
        # 交叉注意力（用于条件注入）
        self.cross_attn = nn.MultiheadAttention(
            d_model, nhead, kdim=context_dim, vdim=context_dim, batch_first=True
        )
        
        # 前馈网络
        self.ffn = nn.Sequential(
            nn.Linear(d_model, dim_feedforward),
            nn.GELU(),
            nn.Linear(dim_feedforward, d_model)
        )
        
        # 自适应层归一化
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        
        # AdaLN参数
        self.ada_norm1 = AdaLN(d_model)
        self.ada_norm2 = AdaLN(d_model)
        self.ada_norm3 = AdaLN(d_model)
        
    def forward(self, x, context, scale, shift):
        """
        前向传播
        """
        # 1. 自注意力（带AdaLN）
        residual = x
        x_norm = self.ada_norm1(self.norm1(x), scale, shift)
        x_attn, _ = self.self_attn(x_norm, x_norm, x_norm)
        x = residual + x_attn
        
        # 2. 交叉注意力（条件注入）
        residual = x
        x_norm = self.ada_norm2(self.norm2(x), scale, shift)
        x_cross, _ = self.cross_attn(x_norm, context, context)
        x = residual + x_cross
        
        # 3. 前馈网络（带AdaLN）
        residual = x
        x_norm = self.ada_norm3(self.norm3(x), scale, shift)
        x_ffn = self.ffn(x_norm)
        x = residual + x_ffn
        
        return x

class AdaLN(nn.Module):
    """自适应层归一化"""
    
    def __init__(self, d_model):
        super().__init__()
        self.norm = nn.LayerNorm(d_model, elementwise_affine=False)
        
    def forward(self, x, scale, shift):
        """
        前向传播
        
        x: [B, T, d_model]
        scale: [B, d_model]
        shift: [B, d_model]
        """
        # 层归一化
        x_norm = self.norm(x)
        
        # 应用缩放和偏移
        # 扩展scale和shift以匹配序列维度
        scale = scale.unsqueeze(1)  # [B, 1, d_model]
        shift = shift.unsqueeze(1)  # [B, 1, d_model]
        
        x = x_norm * (1 + scale) + shift
        
        return x

class TimestepEmbedding(nn.Module):
    """时间步嵌入"""
    
    def __init__(self, d_model):
        super().__init__()
        
        self.d_model = d_model
        
        # 正弦位置编码
        half_dim = d_model // 2
        emb = np.log(10000) / (half_dim - 1)
        emb = torch.exp(torch.arange(half_dim) * -emb)
        self.register_buffer('emb', emb)
        
        # 投影层
        self.projection = nn.Sequential(
            nn.Linear(d_model, d_model * 4),
            nn.GELU(),
            nn.Linear(d_model * 4, d_model)
        )
        
    def forward(self, timesteps):
        """
        前向传播
        
        timesteps: [B] - 时间步
        """
        # 正弦编码
        emb = timesteps.float() * self.emb.unsqueeze(0)
        emb = torch.cat([torch.sin(emb), torch.cos(emb)], dim=-1)  # [B, d_model]
        
        # 投影
        emb = self.projection(emb)
        
        return emb

class ActionEmbedding(nn.Module):
    """动作序列嵌入"""
    
    def __init__(self, config):
        super().__init__()
        
        self.action_dim = config.action_dim
        self.d_model = config.d_model
        
        # 动作投影
        self.projection = nn.Sequential(
            nn.Linear(config.action_dim, config.d_model),
            nn.LayerNorm(config.d_model),
            nn.GELU(),
            nn.Linear(config.d_model, config.d_model)
        )
        
        # 位置编码
        self.position_embedding = nn.Embedding(config.action_horizon, config.d_model)
        
    def forward(self, actions):
        """
        前向传播
        
        actions: [B, T, action_dim]
        """
        batch_size, seq_len, _ = actions.shape
        
        # 投影动作
        action_embed = self.projection(actions)  # [B, T, d_model]
        
        # 添加位置编码
        positions = torch.arange(seq_len, device=actions.device).unsqueeze(0)
        pos_embed = self.position_embedding(positions)  # [1, T, d_model]
        
        action_embed = action_embed + pos_embed
        
        return action_embed

class OutputHead(nn.Module):
    """输出头：预测噪声或动作"""
    
    def __init__(self, config):
        super().__init__()
        
        # 最终投影
        self.final_proj = nn.Sequential(
            nn.Linear(config.d_model, config.d_model // 2),
            nn.GELU(),
            nn.Linear(config.d_model // 2, config.action_dim)
        )
        
        # 可选的额外层
        if config.use_extra_layers:
            self.extra_layers = nn.ModuleList([
                nn.Sequential(
                    nn.Linear(config.d_model, config.d_model),
                    nn.GELU()
                ) for _ in range(config.extra_layers_count)
            ])
        else:
            self.extra_layers = None
        
    def forward(self, x):
        """
        前向传播
        
        x: [B, T, d_model]
        """
        if self.extra_layers is not None:
            for layer in self.extra_layers:
                x = layer(x)
        
        # 最终投影
        output = self.final_proj(x)  # [B, T, action_dim]
        
        return output
```

### 4.2 详细架构实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Optional, Tuple

class DiTForRobotics(nn.Module):
    """
    DiT Scaling for Robotics
    
    特点：
    1. 使用潜在变量减少计算开销
    2. 自适应层归一化（AdaLN）注入条件
    3. 可扩展的架构设计
    4. 支持多种条件注入方式
    """
    
    def __init__(self, config):
        super().__init__()
        
        self.config = config
        
        # 1. 潜在空间编码器
        self.latent_encoder = LatentEncoder(config)
        
        # 2. 条件编码器
        self.condition_encoder = ConditionEncoderForDiT(config)
        
        # 3. DiT主干
        self.dit = DiTWithScaling(
            input_size=config.latent_dim,
            patch_size=config.patch_size,
            hidden_size=config.hidden_size,
            depth=config.depth,
            num_heads=config.num_heads,
            mlp_ratio=config.mlp_ratio,
            class_dropout_prob=config.class_dropout_prob,
            num_classes=config.num_classes,
            learn_sigma=config.learn_sigma
        )
        
        # 4. 潜在空间解码器
        self.latent_decoder = LatentDecoder(config)
        
        # 5. 扩散调度器
        self.scheduler = create_diffusion(
            timestep_respacing=config.timestep_respacing
        )
        
    def forward(self, 
                actions: torch.Tensor,
                conditions: dict,
                timesteps: Optional[torch.Tensor] = None,
                class_labels: Optional[torch.Tensor] = None):
        """
        训练时前向传播
        
        Args:
            actions: [B, T, action_dim] - 目标动作序列
            conditions: dict - 条件信息
            timesteps: [B] - 扩散时间步
            class_labels: [B] - 类别标签（可选）
        """
        batch_size = actions.shape[0]
        
        # 1. 编码到潜在空间
        latent_actions = self.latent_encoder(actions)  # [B, latent_dim]
        
        # 2. 编码条件
        cond_embedding = self.condition_encoder(conditions)  # [B, cond_dim]
        
        # 3. 添加噪声
        if timesteps is None:
            timesteps = torch.randint(
                0, self.scheduler.num_timesteps, (batch_size,), device=actions.device
            )
        
        noise = torch.randn_like(latent_actions)
        noisy_latent = self.scheduler.q_sample(latent_actions, timesteps, noise)
        
        # 4. DiT预测
        predicted_noise = self.dit(
            noisy_latent, 
            timesteps, 
            y=cond_embedding,
            class_labels=class_labels
        )
        
        # 5. 计算损失
        loss = F.mse_loss(predicted_noise, noise)
        
        return {
            'loss': loss,
            'predicted_noise': predicted_noise,
            'noisy_latent': noisy_latent,
            'latent_actions': latent_actions
        }
    
    @torch.no_grad()
    def generate(self, 
                 conditions: dict,
                 class_labels: Optional[torch.Tensor] = None,
                 num_steps: int = 50,
                 cfg_scale: float = 7.0):
        """
        生成动作序列
        
        Args:
            conditions: dict - 条件信息
            class_labels: [B] - 类别标签
            num_steps: 去噪步数
            cfg_scale: 分类器引导强度
        """
        batch_size = next(iter(conditions.values())).shape[0]
        device = next(iter(conditions.values())).device
        
        # 1. 编码条件
        cond_embedding = self.condition_encoder(conditions)
        
        # 2. 初始化潜在噪声
        latent = torch.randn(
            batch_size, 
            self.config.latent_dim,
            device=device
        )
        
        # 3. 设置扩散调度器
        self.scheduler.set_timesteps(num_steps)
        
        # 4. 迭代去噪
        for t in self.scheduler.timesteps:
            # 准备时间步
            timesteps = torch.full((batch_size,), t, device=device, dtype=torch.long)
            
            # 分类器引导（可选）
            if cfg_scale > 1.0:
                # 条件预测
                cond_pred = self.dit(latent, timesteps, y=cond_embedding)
                
                # 无条件预测
                uncond_embedding = torch.zeros_like(cond_embedding)
                uncond_pred = self.dit(latent, timesteps, y=uncond_embedding)
                
                # 引导采样
                pred = uncond_embedding + cfg_scale * (cond_pred - uncond_pred)
            else:
                pred = self.dit(latent, timesteps, y=cond_embedding)
            
            # 去噪步骤
            latent = self.scheduler.step(pred, t, latent).prev_sample
        
        # 5. 解码回动作空间
        actions = self.latent_decoder(latent)
        
        return actions

class LatentEncoder(nn.Module):
    """潜在空间编码器"""
    
    def __init__(self, config):
        super().__init__()
        
        self.config = config
        
        # 序列到潜在空间的映射
        self.encoder = nn.Sequential(
            nn.Linear(config.action_dim * config.action_horizon, config.hidden_size),
            nn.LayerNorm(config.hidden_size),
            nn.GELU(),
            nn.Linear(config.hidden_size, config.hidden_size),
            nn.LayerNorm(config.hidden_size),
            nn.GELU(),
            nn.Linear(config.hidden_size, config.latent_dim)
        )
        
        # 可选的VAE组件
        if config.use_vae:
            self.fc_mu = nn.Linear(config.latent_dim, config.latent_dim)
            self.fc_logvar = nn.Linear(config.latent_dim, config.latent_dim)
        else:
            self.fc_mu = None
            self.fc_logvar = None
            
    def forward(self, actions):
        """
        前向传播
        
        actions: [B, T, action_dim]
        """
        batch_size = actions.shape[0]
        
        # 展平动作序列
        actions_flat = actions.reshape(batch_size, -1)  # [B, T * action_dim]
        
        # 编码
        latent = self.encoder(actions_flat)  # [B, latent_dim]
        
        # VAE重参数化（可选）
        if self.fc_mu is not None:
            mu = self.fc_mu(latent)
            logvar = self.fc_logvar(latent)
            
            # 重参数化
            std = torch.exp(0.5 * logvar)
            eps = torch.randn_like(std)
            latent = mu + eps * std
            
            # 返回潜在变量和分布参数
            return latent, mu, logvar
        else:
            return latent

class LatentDecoder(nn.Module):
    """潜在空间解码器"""
    
    def __init__(self, config):
        super().__init__()
        
        self.config = config
        
        # 潜在空间到动作序列的映射
        self.decoder = nn.Sequential(
            nn.Linear(config.latent_dim, config.hidden_size),
            nn.LayerNorm(config.hidden_size),
            nn.GELU(),
            nn.Linear(config.hidden_size, config.hidden_size),
            nn.LayerNorm(config.hidden_size),
            nn.GELU(),
            nn.Linear(config.hidden_size, config.action_dim * config.action_horizon)
        )
        
    def forward(self, latent):
        """
        前向传播
        
        latent: [B, latent_dim]
        """
        # 解码
        actions_flat = self.decoder(latent)  # [B, T * action_dim]
        
        # 重塑回序列
        actions = actions_flat.reshape(-1, self.config.action_horizon, self.config.action_dim)
        
        return actions

class ConditionEncoderForDiT(nn.Module):
    """DiT专用条件编码器"""
    
    def __init__(self, config):
        super().__init__()
        
        self.config = config
        
        # 图像条件编码
        self.image_cond = nn.Sequential(
            nn.Linear(config.image_embed_dim, config.cond_dim),
            nn.GELU(),
            nn.Linear(config.cond_dim, config.cond_dim)
        )
        
        # 语言条件编码
        self.language_cond = nn.Sequential(
            nn.Linear(config.language_embed_dim, config.cond_dim),
            nn.GELU(),
            nn.Linear(config.cond_dim, config.cond_dim)
        )
        
        # 状态条件编码
        self.state_cond = nn.Sequential(
            nn.Linear(config.state_dim, config.cond_dim),
            nn.GELU(),
            nn.Linear(config.cond_dim, config.cond_dim)
        )
        
        # 条件融合
        self.fusion = nn.Sequential(
            nn.Linear(config.cond_dim * 3, config.cond_dim * 2),
            nn.GELU(),
            nn.Linear(config.cond_dim * 2, config.cond_dim)
        )
        
    def forward(self, conditions):
        """编码条件"""
        cond_embeddings = []
        
        # 图像条件
        if 'image' in conditions:
            img_cond = self.image_cond(conditions['image'])
            cond_embeddings.append(img_cond)
        else:
            cond_embeddings.append(torch.zeros_like(cond_embeddings[0]) if cond_embeddings 
                                  else torch.zeros(1, self.config.cond_dim))
        
        # 语言条件
        if 'language' in conditions:
            lang_cond = self.language_cond(conditions['language'])
            cond_embeddings.append(lang_cond)
        else:
            cond_embeddings.append(torch.zeros_like(cond_embeddings[0]))
        
        # 状态条件
        if 'state' in conditions:
            state_cond = self.state_cond(conditions['state'])
            cond_embeddings.append(state_cond)
        else:
            cond_embeddings.append(torch.zeros_like(cond_embeddings[0]))
        
        # 融合条件
        combined = torch.cat(cond_embeddings, dim=-1)
        cond_embedding = self.fusion(combined)
        
        return cond_embedding

class DiTWithScaling(nn.Module):
    """
    带缩放律的DiT实现
    
    基于论文 "Scalable Diffusion Models with Transformers"
    """
    
    def __init__(self, 
                 input_size: int,
                 patch_size: int,
                 hidden_size: int,
                 depth: int,
                 num_heads: int,
                 mlp_ratio: float = 4.0,
                 class_dropout_prob: float = 0.1,
                 num_classes: int = 1000,
                 learn_sigma: bool = True):
        super().__init__()
        
        self.input_size = input_size
        self.patch_size = patch_size
        self.hidden_size = hidden_size
        self.depth = depth
        self.num_heads = num_heads
        self.mlp_ratio = mlp_ratio
        self.num_classes = num_classes
        self.learn_sigma = learn_sigma
        
        # 输入投影
        self.x_embedder = nn.Linear(input_size, hidden_size)
        
        # 时间嵌入
        self.t_embedder = TimestepEmbedder(hidden_size)
        
        # 类别嵌入（可选）
        if num_classes > 0:
            self.y_embedder = nn.Embedding(num_classes + 1, hidden_size)  # +1 for unconditional
            self.null_class_emb = nn.Parameter(torch.zeros(hidden_size))
        else:
            self.y_embedder = None
            self.null_class_emb = None
            
        # DiT块
        self.blocks = nn.ModuleList([
            DiTBlockWithScaling(
                hidden_size=hidden_size,
                num_heads=num_heads,
                mlp_ratio=mlp_ratio,
                class_dropout_prob=class_dropout_prob,
                num_classes=num_classes
            ) for _ in range(depth)
        ])
        
        # 输出投影
        self.final_layer = FinalLayer(hidden_size, input_size)
        
        # 初始化
        self.initialize_weights()
        
    def initialize_weights(self):
        """初始化权重"""
        # 基本初始化
        def _basic_init(module):
            if isinstance(module, nn.Linear):
                torch.nn.init.xavier_uniform_(module.weight)
                if module.bias is not None:
                    nn.init.constant_(module.bias, 0)
        
        self.apply(_basic_init)
        
        # 时间嵌入初始化
        nn.init.normal_(self.t_embedder.mlp[0].weight, std=0.02)
        nn.init.normal_(self.t_embedder.mlp[2].weight, std=0.02)
        
        # 类别嵌入初始化
        if self.y_embedder is not None:
            nn.init.normal_(self.y_embedder.weight, std=0.02)
        
        # DiT块初始化
        for block in self.blocks:
            nn.init.constant_(block.adaLN_modulation[-1].weight, 0)
            nn.init.constant_(block.adaLN_modulation[-1].bias, 0)
        
        # 输出层初始化
        nn.init.constant_(self.final_layer.adaLN_modulation[-1].weight, 0)
        nn.init.constant_(self.final_layer.adaLN_modulation[-1].bias, 0)
        nn.init.constant_(self.final_layer.linear.weight, 0)
        nn.init.constant_(self.final_layer.linear.bias, 0)
    
    def forward(self, 
                x: torch.Tensor, 
                t: torch.Tensor, 
                y: Optional[torch.Tensor] = None,
                class_labels: Optional[torch.Tensor] = None):
        """
        前向传播
        
        Args:
            x: [B, input_size] - 带噪输入
            t: [B] - 时间步
            y: [B, cond_dim] - 条件嵌入（可选）
            class_labels: [B] - 类别标签（可选）
        """
        # 时间嵌入
        t_emb = self.t_embedder(t)  # [B, hidden_size]
        
        # 类别嵌入
        if self.y_embedder is not None and class_labels is not None:
            y_emb = self.y_embedder(class_labels)  # [B, hidden_size]
            # 分类器引导时的无条件处理
            if self.training:
                # 随机丢弃类别标签
                mask = torch.rand(class_labels.shape[0]) < self.class_dropout_prob
                y_emb[mask] = self.null_class_emb
        else:
            y_emb = torch.zeros_like(t_emb)
        
        # 合并时间和类别嵌入
        c = t_emb + y_emb  # [B, hidden_size]
        
        # 输入嵌入
        x = self.x_embedder(x)  # [B, hidden_size]
        
        # 通过DiT块
        for block in self.blocks:
            x = block(x, c)  # [B, hidden_size]
        
        # 输出
        x = self.final_layer(x, c)  # [B, input_size]
        
        return x
```

```python
class HybridArchitecture(nn.Module):
    """
    混合架构：结合HPT和RDT的优点
    
    设计思路：
    1. 使用HPT进行特征提取和表征学习
    2. 使用RDT进行高质量动作生成
    3. 使用DiT的缩放思想优化整体架构
    """
    
    def __init__(self, config):
        super().__init__()
        
        # HPT部分：特征提取
        self.hpt_encoder = HPTFeatureExtractor(config)
        
        # RDT部分：动作生成
        self.rdt_generator = RDTActionGenerator(config)
        
        # DiT部分：优化器
        self.dit_optimizer = DiTOptimizer(config)
        
        # 融合模块
        self.fusion = CrossModalFusion(config)
        
    def forward(self, inputs, robot_type, task_type):
        """混合前向传播"""
        # 1. HPT特征提取
        hpt_features = self.hpt_encoder(inputs, robot_type)
        
        # 2. 融合特征
        fused_features = self.fusion(hpt_features, inputs)
        
        # 3. RDT动作生成（带特征引导）
        actions = self.rdt_generator(fused_features, task_type)
        
        # 4. DiT优化（可选）
        if self.training:
            optimized_actions = self.dit_optimizer(actions, fused_features)
            return optimized_actions
        
        return actions
    
    def generate_with_diversity(self, inputs, num_samples=10):
        """生成多样本"""
        samples = []
        
        for _ in range(num_samples):
            # 不同的随机种子
            seed = torch.randint(0, 10000, (1,))
            torch.manual_seed(seed)
            
            # 生成样本
            sample = self.forward(inputs)
            samples.append(sample)
        
        return torch.stack(samples, dim=1)  # [B, num_samples, T, action_dim]
```

### 7.2 面试要点

**Q1: HPT、RDT、DiT各适用于什么场景？**
A1: 
- **HPT**: 机器人类型多样、需要快速推理、延迟敏感的场景
- **RDT**: 需要高质量生成、多样本探索、生成任务复杂的场景
- **DiT**: 大规模训练、需要高效计算、追求缩放律的场景

**Q2: 如何设计混合架构？**
A2: 关键设计原则：
1. **模块化设计**：HPT负责感知，RDT负责生成
2. **特征融合**：通过交叉注意力融合多模态特征
3. **训练策略**：先预训练HPT，再训练RDT，最后联合微调
4. **效率优化**：使用DiT的潜在空间减少计算开销

**Q3: 实际部署时有哪些考虑？**
A3: 主要考虑：
1. **推理延迟**：RDT需要多次迭代，可能不满足实时性要求
2. **内存占用**：RDT和DiT的Transformer层占用大量内存
3. **泛化能力**：HPT的跨机器人迁移能力更强
4. **生成多样性**：RDT的随机采样提供更多样化的动作

**Q4: 未来发展趋势是什么？**
A4: 主要趋势：
1. **统一架构**：开发能同时处理感知和生成的统一架构
2. **更高效生成**：减少扩散模型的迭代次数
3. **更好的缩放律**：探索机器人基础模型的缩放规律
4. **多模态融合**：更好地融合视觉、语言、触觉等多模态信息

### 7.4 架构选择打分矩阵

真实项目里很少存在“绝对最优架构”。更稳妥的方法是把需求拆成可打分维度，然后看哪种架构满足当前约束。

| 需求维度 | HPT / Stem-Trunk-Head | RDT / Diffusion Transformer | DiT Scaling |
|---|---|---|---|
| 低延迟部署 | 5：单次前向，最容易控延迟 | 2：多步采样，延迟压力大 | 3：可用少步采样或潜在空间折中 |
| 跨机器人迁移 | 5：天然强调异构输入和 adapter | 3：可迁移，但常依赖动作空间对齐 | 4：大模型和条件注入有利于迁移 |
| 复杂动作分布 | 3：确定性 head 容易平均化 | 5：扩散适合多峰动作 | 5：DiT 可扩展到复杂条件生成 |
| 工程可控性 | 5：模块边界清晰，debug 简单 | 3：采样链路长，排错复杂 | 3：缩放后调参成本高 |
| 训练成本 | 3：预训练成本高，但微调可控 | 3：扩散训练和采样都较重 | 2：大规模 DiT 成本最高 |
| 数据异构程度高 | 5：最适合多模态、多机器人统一表征 | 3：需要额外设计条件编码 | 4：条件注入强，但数据对齐仍难 |
| 追求生成多样性 | 2：通常偏确定性输出 | 5：天然支持采样多样性 | 5：扩散式生成能力强 |

一个实用选择规则：

```text
如果任务强调实时控制、跨机器人泛化、工程上线：优先 HPT。
如果任务强调复杂动作、多解动作、轨迹质量：优先 RDT。
如果有大规模数据和算力，并希望扩展模型容量：考虑 DiT Scaling。
如果既要跨机器人表征又要高质量动作：HPT encoder + RDT/DiT action generator。
```

#### 7.4.1 HTML架构选择器的评分公式

D118 HTML 里的交互式选择器使用的是启发式评分，不是论文指标。它的目的不是替代真实 benchmark，而是把 trade-off 显式化。

```python
def architecture_scores(latency, diversity, hetero, compute):
    """
    输入都是 0-10:
      latency: 实时性要求，越大表示越严格
      diversity: 动作多样性要求，越大表示越需要多峰生成
      hetero: 异构机器人/模态程度，越大表示越复杂
      compute: 可用算力/训练规模，越大表示资源越充足
    """
    hpt = latency * 0.36 + hetero * 0.42 + (10 - diversity) * 0.12 + (10 - compute) * 0.10
    rdt = diversity * 0.48 + compute * 0.25 + (10 - latency) * 0.20 + hetero * 0.07
    dit = compute * 0.42 + diversity * 0.30 + hetero * 0.18 + (10 - latency) * 0.10
    return {"HPT": hpt, "RDT": rdt, "DiT": dit}
```

这些权重背后的直觉：

- `HPT` 更喜欢高实时性、高异构程度，因为它是模块化表征路线，单次前向更容易控延迟。
- `RDT` 更喜欢高动作多样性和足够算力，因为扩散采样适合多峰轨迹，但需要多步去噪。
- `DiT` 更喜欢高算力、高多样性和较高异构程度，因为 DiT 的优势来自规模化条件生成。
- `(10 - latency)` 会提高 RDT/DiT 分数，因为实时性越不严格，多步采样越容易接受。

### 7.4.2 可运行实验：架构取舍与采样步数

本目录新增了一个可运行实验脚本：

```bash
python3 week17_html/d118_architecture_tradeoff_experiment.py
```

它会输出两类结果：

1. 不同项目场景下，HPT/RDT/DiT 的启发式推荐分数。
2. 扩散采样步数增加时，延迟、质量、稳定性和 `quality/ms` 的变化。

你应该重点观察：

| 现象 | 解释 |
|---|---|
| 工厂实时控制更偏 HPT | 实时性和工程可控性通常压倒生成多样性 |
| 厨房复杂操作常需要混合方案 | 既要跨场景泛化，又要复杂接触动作质量 |
| 大规模研究更偏 DiT | 算力充足时可以追求 scaling 和统一条件生成 |
| 采样步数越多质量越高 | 扩散模型有更多机会逐步修正动作 |
| `quality/ms` 会下降 | 质量收益逐渐饱和，但延迟近似线性增长 |

这能帮助你把“RDT质量高但慢”讲得更具体：不是简单说慢，而是说**采样步数带来质量-延迟曲线，部署时要选 operating point**。

### 7.6 面试Trade-off模板

如果面试官问“你会选 HPT 还是 RDT？”不要直接回答某一个模型更强。可以按下面模板回答：

```text
我会先看四个约束：
1. 是否实时：如果控制频率高、延迟严格，HPT或少步DiT更合适。
2. 动作是否多解：如果同一目标有多条合理轨迹，RDT/DiT更合适。
3. 数据是否异构：如果跨机器人、跨传感器，HPT的stem-trunk-head更稳。
4. 算力是否充足：如果训练和部署资源充足，可以考虑DiT scaling。

所以我的默认方案是：
- 先用HPT-style encoder统一多模态和多机器人表征；
- 再根据动作复杂度选择 deterministic head、RDT head 或 DiT head；
- 如果上线延迟不满足，再减少采样步数、蒸馏或切换到token/回归式head。
```

### 7.8 部署前排错清单

D118 的三类架构在真实部署前，都要做下面这些检查。

| 风险 | 常见表现 | 排查方法 |
|---|---|---|
| 动作空间未对齐 | 新机器人动作幅度异常、夹爪行为错乱 | 检查 action normalization、坐标系、关节/末端定义 |
| 条件注入失效 | 模型忽略语言或图像，只输出平均动作 | 做 condition ablation，看去掉语言/图像后输出是否变化 |
| RDT/DiT 延迟超标 | 控制频率达不到，动作滞后 | 减少采样步数、蒸馏、缓存条件特征、改用快速 head |
| 扩散采样不稳定 | 同一输入多次输出差异过大 | 固定随机种子、多样本筛选、安全过滤、降低噪声 |
| HPT adapter 迁移失败 | 新机器人表现远差于训练机器人 | 增加 adapter 容量、做 embodiment embedding、补充少量目标机器人数据 |
| 离线指标与闭环不一致 | MSE 好但真实任务失败 | 做闭环 rollout、统计 subtask success、碰撞率和恢复率 |
| 模型太大无法上线 | 显存爆、延迟高 | 量化、蒸馏、裁剪层数、分离 perception 与 action head |
