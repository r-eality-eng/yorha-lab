> 论文：*π0.5: a Vision-Language-Action Model with Open-World Generalization*  
> 作者：Physical Intelligence  
> 发表：2025年（π0的升级版本）

> **优化补充：D116 学习导读与边界**  
> D116 的价值在于把 VLA 从“短 horizon 感知到动作”推进到“长任务推理、子任务分解、动态重规划”。学习时要抓住三层：  
> 1. **Reasoning layer**：负责理解目标、识别对象、分解任务、给出执行顺序。  
> 2. **Skill / subtask layer**：把自然语言子任务变成可执行技能，例如 pick、place、open、wipe、navigate。  
> 3. **Low-level action layer**：把技能和参数变成连续动作序列，底层仍可使用 π0-style Flow Matching controller。  
>
> **准确性口径**  
> 本节中的任务图、技能库、状态机、动态重规划代码是工程化讲解模板，适合帮助你设计项目和面试回答，但不能直接等同于某篇论文的官方实现。真实系统通常会受到机器人平台、仿真环境、任务定义、数据标注粒度、失败检测接口的强约束。

> **论文机制补充：π0.5 更应该怎样理解**  
> π0.5 的重点不是简单“在 π0 上面加一个 planner”，而是让 VLA 具备更强的 open-world generalization。可以从四个角度理解：  
> 1. **从低层动作到高层语义**：模型不只预测连续动作，还要利用视觉语言知识预测高层语义状态、子目标或任务进展。  
> 2. **从单一机器人数据到异构数据混合**：通过不同机器人、不同任务、不同数据来源的 co-training，让模型学到更通用的语义和控制先验。  
> 3. **从短 horizon 到 long-horizon 任务**：长任务并不是一次性输出很长动作，而是持续感知、预测下一阶段语义目标、执行短 action chunk，再根据反馈更新。  
> 4. **从封闭任务到开放世界泛化**：关键评估不只是 seen tasks 的 success rate，还包括新物体、新环境、新组合指令和失败恢复能力。
>
> **和下文工程模板的关系**  
> 下文的 task graph、skill library、state machine、dynamic replanner 是为了把 π0.5 的 long-horizon 思路落到工程语言中。它们是“实现这种能力的一种教学抽象”，不是说 π0.5 官方系统必须显式包含这些 Python 类。

> **学习时要避免的误区**  
> - 不要把“长 horizon”理解成一次性输出 100 步动作。更常见的做法是高层持续重规划，底层 receding horizon 执行短 action chunk。  
> - 不要只看最终 success rate。长任务还要看 subtask success、replan success、failure recovery、执行时间、碰撞/安全事件。  
> - 不要假设 VLM 的文字推理天然可靠。机器人任务需要把推理结果约束成可执行结构，例如 JSON schema、任务图、技能参数和状态机。

## 一、从π0到π0.5：为什么需要升级？

### 1.1 π0的局限性

```
π0的能力边界：
┌─────────────────────────────────────────────────────────────────┐
│  π0 擅长的任务：                                                 │
│  ✅ 单步/少步操作：拿起杯子、放置物体                              │
│  ✅ 短horizon：3-5步内完成的任务                                  │
│  ✅ 已知物体/场景：训练分布内的任务                                │
│                                                                 │
│  π0 困难的任务：                                                 │
│  ❌ 长horizon：收拾餐桌（需要20+步）                              │
│  ❌ 需要推理：理解"把脏衣服放到洗衣机"的多步含义                   │
│  ❌ 新物体/新场景：泛化到未见过的环境                              │
│  ❌ 任务规划：决定先做什么、再做什么                               │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 核心挑战

```
长Horizon任务的挑战：

任务：收拾厨房桌面
人类执行过程：
  1. 观察桌面 → 识别物体（碗、盘子、杯子、垃圾）
  2. 规划顺序 → 先收垃圾，再收餐具，最后擦桌子
  3. 逐步执行 → 每一步都需要：
     - 识别当前物体
     - 规划抓取策略
     - 执行抓取
     - 导航到目标位置
     - 放置物体
  4. 处理异常 → 物体滑落、路径被挡

核心问题：
  π0只能处理单步"感知→动作"映射
  无法处理这种需要规划和推理的长horizon任务
```

### 1.3 π0.5的设计哲学

```
π0.5的核心思想：

高层（Reasoning）:  "做什么" — 任务理解、分解、规划
     ↓ 子任务指令
中层（Planning）:   "怎么做" — 动作序列规划
     ↓ 动作序列
低层（Execution）:  "执行" — 底层动作执行

类比人类：
  高层 = 厨师长：决定今天做什么菜、用什么食材
  中层 = 厨师：规划具体步骤（先切菜、再炒菜...）
  底层 = 手：执行具体动作（切、炒、翻...）
```

### 2.2 三层架构详解

class PiZeroPointFive(nn.Module):
    """
    π0.5: 三层层次化架构
    """
    def __init__(self):
        super().__init__()
        
        # Level 3: VLM推理层
        self.reasoning_layer = VLMReasoningLayer()
        
        # Level 2: 技能规划层
        self.skill_planner = SkillPlanningLayer()
        
        # Level 1: 底层控制层
        self.low_level_controller = FlowMatchingController()
        
        # 层间通信接口
        self.interface = HierarchicalInterface()
    
    def forward(self, images, language_command, proprioception):
        """
        完整的层次化前向传播
        
        Args:
            images: 视觉输入
            language_command: 语言指令（如"收拾桌面"）
            proprioception: 机器人本体感受
        """
        # Level 3: 推理与任务分解
        reasoning_output = self.reasoning_layer(images, language_command)
        # 输出: 子任务列表、物体位置、执行顺序
        
        # 依次执行每个子任务
        all_actions = []
        for subtask in reasoning_output.subtasks:
            # Level 2: 技能规划
            skill_sequence = self.skill_planner(
                subtask, 
                reasoning_output.object_positions,
                images
            )
            # 输出: 技能序列 [导航, 抓取, 导航, 放置]
            
            # Level 1: 底层执行
            for skill in skill_sequence:
                actions = self.low_level_controller(
                    skill,
                    images,
                    proprioception
                )
                all_actions.append(actions)
                
                # 执行后更新状态
                images, proprioception = self.execute_and_observe(actions)
        
        return all_actions
```

## 三、Level 3: VLM推理层（任务分解与规划）

### 3.1 推理层的核心能力

```python
class VLMReasoningLayer(nn.Module):
    """
    VLM推理层：负责任务理解、分解和高层规划
    
    核心能力：
    1. 任务理解：理解语言指令的语义
    2. 物体识别：识别场景中的相关物体
    3. 任务分解：将复杂任务分解为子任务
    4. 执行规划：确定子任务的执行顺序
    5. 异常处理：识别执行中的问题并调整计划
    """
    
    def __init__(self, vlm_model="paligemma-3b"):
        super().__init__()
        
        # 加载预训练VLM
        self.vlm = load_vlm(vlm_model)
        
        # 推理专用适配器
        self.reasoning_adapter = ReasoningAdapter()
        
        # 输出解析器
        self.output_parser = StructuredOutputParser()
    
    def forward(self, images, command):
        """
        推理过程
        
        Args:
            images: [B, C, H, W] 或 [B, T, C, H, W] 多帧图像
            command: str 语言指令
        
        Returns:
            ReasoningOutput: 结构化推理结果
        """
        # 1. 构建推理prompt
        reasoning_prompt = self._build_reasoning_prompt(command)
        
        # 2. VLM推理
        vlm_output = self.vlm.generate(
            images=images,
            prompt=reasoning_prompt,
            max_new_tokens=512
        )
        
        # 3. 解析结构化输出
        reasoning_result = self.output_parser.parse(vlm_output)
        
        return reasoning_result
    
    def _build_reasoning_prompt(self, command):
        """
        构建推理prompt，引导VLM进行结构化推理
        """
        prompt = f"""
你是一个机器人助手，正在执行任务：{command}

请分析这个任务，并提供以下信息：

1. **物体识别**：场景中有哪些与任务相关的物体？请列出它们的位置和状态。

2. **任务分解**：将这个任务分解为多个子任务（每个子任务应该是可独立执行的原子操作）。

3. **执行顺序**：确定子任务的执行顺序，考虑以下约束：
   - 物理约束（如必须先抓取才能移动）
   - 效率约束（如相近的物体一起处理）
   - 安全约束（如易碎物品最后处理）

4. **异常预案**：可能遇到的问题及应对策略。

请以JSON格式输出：
```json
{{
  "objects": [
    {{"name": "物体名", "position": [x, y, z], "state": "状态"}},
    ...
  ],
  "subtasks": [
    {{"id": 1, "description": "子任务描述", "target_object": "物体", "skill": "技能类型", "priority": 优先级}},
    ...
  ],
  "execution_order": [1, 2, 3, ...],
  "contingency_plans": [...]
}}
```
"""
        return prompt
```

### 3.3 任务图表示

```python
class TaskGraph:
    """
    任务图：表示任务分解和依赖关系
    
    节点：子任务/原子操作
    边：依赖关系（时间顺序、数据依赖、资源冲突）
    """
    
    def __init__(self):
        self.nodes = {}  # 任务节点
        self.edges = {}  # 依赖边
        self.execution_state = {}  # 执行状态
    
    def add_node(self, task_id, task_info):
        """添加任务节点"""
        self.nodes[task_id] = {
            'info': task_info,
            'status': 'pending',  # pending, ready, running, completed, failed
            'dependencies': [],   # 前置任务
            'dependents': [],     # 后续任务
            'skill': task_info.get('skill'),
            'parameters': task_info.get('parameters', {})
        }
    
    def add_edge(self, from_task, to_task, edge_type='sequential'):
        """
        添加依赖边
        
        edge_type:
        - 'sequential': 顺序执行（from必须在to之前完成）
        - 'resource': 资源共享（不能同时执行）
        - 'data': 数据依赖（from的输出是to的输入）
        """
        self.edges[(from_task, to_task)] = edge_type
        
        # 更新依赖关系
        self.nodes[to_task]['dependencies'].append(from_task)
        self.nodes[from_task]['dependents'].append(to_task)
    
    def get_ready_tasks(self):
        """获取可以执行的任务（所有依赖已完成）"""
        ready_tasks = []
        for task_id, task in self.nodes.items():
            if task['status'] != 'pending':
                continue
            
            # 检查所有依赖是否完成
            all_deps_completed = all(
                self.nodes[dep]['status'] == 'completed'
                for dep in task['dependencies']
            )
            
            if all_deps_completed:
                ready_tasks.append(task_id)
        
        return ready_tasks
    
    def mark_completed(self, task_id):
        """标记任务完成"""
        self.nodes[task_id]['status'] = 'completed'
    
    def mark_failed(self, task_id, reason):
        """标记任务失败"""
        self.nodes[task_id]['status'] = 'failed'
        self.nodes[task_id]['failure_reason'] = reason
    
    def visualize(self):
        """可视化任务图"""
        import networkx as nx
        import matplotlib.pyplot as plt
        
        G = nx.DiGraph()
        
        # 添加节点
        for task_id, task in self.nodes.items():
            G.add_node(task_id, **task['info'])
        
        # 添加边
        for (from_task, to_task), edge_type in self.edges.items():
            G.add_edge(from_task, to_task, type=edge_type)
        
        # 绘制
        pos = nx.spring_layout(G)
        nx.draw(G, pos, with_labels=True, node_color='lightblue', 
                node_size=2000, font_size=8)
        plt.title("Task Graph")
        plt.show()

# 示例：构建收拾桌面的任务图

        skill = self.skills[skill_name]

        for effect in skill['postconditions']:

class SkillPlanner(nn.Module):
    """
    技能规划器：将子任务映射为技能序列
    """
    
    def __init__(self, skill_library):
        super().__init__()
        self.skill_library = skill_library
        
        # 技能选择网络
        self.skill_selector = nn.Sequential(
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, len(skill_library.skills))
        )
        
        # 参数预测网络
        self.parameter_predictor = nn.ModuleDict({
            skill_name: ParameterPredictor(skill_info['parameters'])
            for skill_name, skill_info in skill_library.skills.items()
        })
    
    def plan(self, subtask, world_state, images):
        """
        为子任务规划技能序列
        
        Args:
            subtask: 子任务描述
            world_state: 当前世界状态
            images: 视觉输入
        
        Returns:
            skill_sequence: 技能序列
        """
        # 1. 编码子任务和世界状态
        task_embedding = self.encode_task(subtask)
        state_embedding = self.encode_state(world_state)
        visual_embedding = self.encode_visual(images)
        
        combined = torch.cat([task_embedding, state_embedding, visual_embedding], dim=-1)
        
        # 2. 选择技能
        skill_logits = self.skill_selector(combined)
        selected_skill = torch.argmax(skill_logits, dim=-1)
        skill_name = list(self.skill_library.skills.keys())[selected_skill]
        
        # 3. 预测技能参数
        parameters = self.parameter_predictor[skill_name](combined, world_state)
        
        # 4. 检查前置条件
        precond_met, missing = self.skill_library.check_preconditions(skill_name, world_state)
        
        if not precond_met:
            # 需要先满足前置条件
            prerequisite_skills = self._plan_prerequisites(missing, world_state)
            return prerequisite_skills + [{'skill': skill_name, 'params': parameters}]
        
        return [{'skill': skill_name, 'params': parameters}]

from enum import Enum

class SkillStateMachine:
    """
    技能状态机：管理技能执行流程
    
    状态：
    - IDLE: 空闲状态
    - EXECUTING: 执行中
    - TRANSITIONING: 技能切换中
    - RECOVERING: 错误恢复中
    """
    
    class State(Enum):
        IDLE = "idle"
        EXECUTING = "executing"
        TRANSITIONING = "transitioning"
        RECOVERING = "recovering"
        COMPLETED = "completed"
        FAILED = "failed"
    
    def __init__(self, skill_library):
        self.skill_library = skill_library
        self.current_state = self.State.IDLE
        self.current_skill = None
        self.skill_queue = []
        self.execution_history = []
    
    def start_skill_sequence(self, skill_sequence):
        """开始执行技能序列"""
        self.skill_queue = skill_sequence.copy()
        self.current_state = self.State.TRANSITIONING
        self._transition_to_next_skill()
    
    def _transition_to_next_skill(self):
        """过渡到下一个技能"""
        if not self.skill_queue:
            self.current_state = self.State.COMPLETED
            return
        
        next_skill = self.skill_queue.pop(0)
        self.current_skill = next_skill
        self.current_state = self.State.EXECUTING
        
        # 初始化技能控制器
        self._init_skill_controller(next_skill)
    
    def _init_skill_controller(self, skill_info):
        """初始化技能控制器"""
        skill_name = skill_info['skill']
        skill_def = self.skill_library.get_skill(skill_name)
        
        # 设置控制器参数
        controller = skill_def['controller']
        controller.set_parameters(skill_info['params'])
        controller.reset()
        
        self.active_controller = controller
    
    def update(self, observation):
        """
        更新状态机（每个控制周期调用）
        
        Args:
            observation: 当前观测
        
        Returns:
            action: 要执行的动作
            done: 是否完成
        """
        if self.current_state == self.State.IDLE:
            return None, True
        
        if self.current_state == self.State.EXECUTING:
            # 获取动作
            action, skill_done = self.active_controller.get_action(observation)
            
            if skill_done:
                # 当前技能完成
                self.execution_history.append({
                    'skill': self.current_skill,
                    'status': 'completed'
                })
                self.current_state = self.State.TRANSITIONING
                self._transition_to_next_skill()
                
                # 返回停止动作，等待下一技能
                return action, False
            
            return action, False
        
        if self.current_state == self.State.RECOVERING:
            # 执行恢复策略
            recovery_action = self._execute_recovery(observation)
            return recovery_action, False
        
        return None, False
    
    def handle_failure(self, error_info):
        """处理技能执行失败"""
        self.current_state = self.State.RECOVERING
        
        # 记录失败
        self.execution_history.append({
            'skill': self.current_skill,
            'status': 'failed',
            'error': error_info
        })
        
        # 决定恢复策略
        recovery_strategy = self._decide_recovery_strategy(error_info)
        
        if recovery_strategy == 'retry':
            # 重试当前技能
            self.skill_queue.insert(0, self.current_skill)
        elif recovery_strategy == 'skip':
            # 跳过当前技能
            pass
        elif recovery_strategy == 'replan':
            # 重新规划
            self._replan_from_current_state()
```

class HierarchicalFlowMatchingController(nn.Module):
    """
    层次化Flow Matching控制器
    
    条件来源：
    - VLM语义理解（来自Level 3）
    - 技能参数（来自Level 2）
    - 本体感受（来自机器人）
    - 视觉观测（来自摄像头）
    """
    
    def __init__(self):
        super().__init__()
        
        # 动作生成网络
        self.action_expert = ActionExpert(
            action_dim=7,
            num_chunks=4,
            hidden_dim=512
        )
        
        # 多层条件编码器
        self.condition_encoders = nn.ModuleDict({
            'vlm_semantic': nn.Linear(2048, 256),      # VLM语义
            'skill_params': nn.Linear(64, 256),         # 技能参数
            'proprioception': nn.Linear(32, 256),       # 本体感受
            'visual_state': nn.Linear(512, 256),        # 视觉状态
        })
        
        # 条件融合
        self.condition_fusion = nn.Sequential(
            nn.Linear(256 * 4, 512),
            nn.ReLU(),
            nn.Linear(512, 512)
        )
    
    def forward(self, noisy_actions, t, conditions):
        """
        前向传播
        
        Args:
            noisy_actions: [B, K, 7] 带噪动作序列
            t: [B, 1] 时间步
            conditions: dict 各种条件信息
        """
        # 1. 编码各层条件
        encoded_conditions = {}
        for cond_name, cond_value in conditions.items():
            encoded_conditions[cond_name] = self.condition_encoders[cond_name](cond_value)
        
        # 2. 融合条件
        combined_cond = torch.cat(list(encoded_conditions.values()), dim=-1)
        fused_condition = self.condition_fusion(combined_cond)
        
        # 3. 预测速度场
        velocity = self.action_expert(noisy_actions, t, fused_condition)
        
        return velocity
    
    def generate_actions(self, conditions, num_steps=10):
        """生成动作序列"""
        # 初始化噪声
        batch_size = conditions['proprioception'].shape[0]
        device = conditions['proprioception'].device
        a_t = torch.randn(batch_size, 4, 7, device=device)
        
        # ODE求解
        dt = 1.0 / num_steps
        t = 1.0
        
        for _ in range(num_steps):
            t_tensor = torch.full((batch_size, 1), t, device=device)
            velocity = self.forward(a_t, t_tensor, conditions)
            # velocity若是data->noise方向，生成时从noise->data需要反向积分
            a_t = a_t - velocity * dt
            t -= dt
        
        return torch.clamp(a_t, -1, 1)
```

class HierarchicalTrainingStrategy:
    """
    层次化训练策略
    
    训练顺序：
    1. 先训练底层控制器（大量机器人数据）
    2. 再训练技能规划器（中等规模数据）
    3. 最后训练VLM推理层（少量高质量数据）
    """
    
    def __init__(self, pi05_model):
        self.model = pi05_model
        
    def train_phase_1_low_level(self, robot_dataset):
        """
        阶段1：训练底层Flow Matching控制器
        
        数据：大量机器人遥操作数据
        目标：学习基本的运动技能
        """
        print("Phase 1: Training Low-level Controller")
        
        # 冻结高层
        for param in self.model.reasoning_layer.parameters():
            param.requires_grad = False
        for param in self.model.skill_planner.parameters():
            param.requires_grad = False
        
        # 只训练底层
        optimizer = torch.optim.Adam(
            self.model.low_level_controller.parameters(),
            lr=1e-4
        )
        
        for epoch in range(100):
            for batch in robot_dataset:
                images, actions, proprioception = batch
                
                # Flow Matching训练
                loss = self.model.low_level_controller.compute_loss(
                    images, actions, proprioception
                )
                
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
    
    def train_phase_2_skill_planning(self, skill_dataset):
        """
        阶段2：训练技能规划器
        
        数据：带技能标注的数据
        目标：学习子任务到技能的映射
        """
        print("Phase 2: Training Skill Planner")
        
        # 冻结VLM和底层
        for param in self.model.reasoning_layer.parameters():
            param.requires_grad = False
        for param in self.model.low_level_controller.parameters():
            param.requires_grad = False
        
        # 训练技能规划器
        optimizer = torch.optim.Adam(
            self.model.skill_planner.parameters(),
            lr=1e-4
        )
        
        for epoch in range(50):
            for batch in skill_dataset:
                subtask, target_skill, target_params = batch
                
                # 预测技能
                predicted_skill, predicted_params = self.model.skill_planner(subtask)
                
                # 计算损失
                skill_loss = F.cross_entropy(predicted_skill, target_skill)
                param_loss = F.mse_loss(predicted_params, target_params)
                loss = skill_loss + param_loss
                
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
    
    def train_phase_3_reasoning(self, reasoning_dataset):
        """
        阶段3：训练VLM推理层
        
        数据：高质量的任务分解示例
        目标：学习任务理解和分解
        """
        print("Phase 3: Training VLM Reasoning Layer")
        
        # 冻结底层和技能层
        for param in self.model.low_level_controller.parameters():
            param.requires_grad = False
        for param in self.model.skill_planner.parameters():
            param.requires_grad = False
        
        # 微调VLM
        optimizer = torch.optim.Adam(
            self.model.reasoning_layer.parameters(),
            lr=1e-5  # 小学习率，避免灾难性遗忘
        )
        
        for epoch in range(20):
            for batch in reasoning_dataset:
                command, images, target_decomposition = batch
                
                # VLM推理
                predicted_decomposition = self.model.reasoning_layer(images, command)
                
                # 计算损失（序列到序列损失）
                loss = self._compute_reasoning_loss(
                    predicted_decomposition,
                    target_decomposition
                )
                
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
    
    def train_end_to_end(self, full_dataset):
        """
        阶段4：端到端微调
        
        数据：完整的任务执行数据
        目标：整体性能优化
        """
        print("Phase 4: End-to-end Fine-tuning")
        
        # 解冻所有层
        for param in self.model.parameters():
            param.requires_grad = True
        
        # 差异化学习率
        optimizer = torch.optim.Adam([
            {'params': self.model.reasoning_layer.parameters(), 'lr': 1e-6},
            {'params': self.model.skill_planner.parameters(), 'lr': 1e-5},
            {'params': self.model.low_level_controller.parameters(), 'lr': 1e-4}
        ])
        
        for epoch in range(10):
            for batch in full_dataset:
                # 端到端前向传播
                loss = self.model.compute_end_to_end_loss(batch)
                
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()

```python
class LongHorizonContextManager:
    """
    长Horizon上下文管理
    
    挑战：
    - 任务可能需要30+分钟
    - 需要记住之前执行的步骤
    - 需要处理意外情况
    """
    
    def __init__(self, max_history=100):
        self.history = []
        self.max_history = max_history
        self.world_state = {}
        self.task_progress = {}
    
    def update(self, observation, action, result):
        """
        更新上下文
        
        Args:
            observation: 当前观测
            action: 执行的动作
            result: 执行结果
        """
        # 记录历史
        self.history.append({
            'timestamp': time.time(),
            'observation': observation,
            'action': action,
            'result': result
        })
        
        # 保持历史长度
        if len(self.history) > self.max_history:
            self.history = self.history[-self.max_history:]
        
        # 更新世界状态
        self._update_world_state(observation, result)
    
    def _update_world_state(self, observation, result):
        """更新世界状态"""
        # 更新物体位置
        for obj in observation.get('objects', []):
            self.world_state[obj['name']] = {
                'position': obj['position'],
                'state': obj['state'],
                'last_seen': time.time()
            }
        
        # 更新任务进度
        if result.get('task_completed'):
            self.task_progress[result['task_id']] = 'completed'
    
    def get_context_for_reasoning(self):
        """
        获取用于推理的上下文
        """
        context = {
            'world_state': self.world_state,
            'task_progress': self.task_progress,
            'recent_history': self.history[-10:],  # 最近10步
            'summary': self._generate_summary()
        }
        return context
    
    def _generate_summary(self):
        """生成执行历史摘要"""
        summary = {
            'total_steps': len(self.history),
            'completed_tasks': [
                task_id for task_id, status in self.task_progress.items()
                if status == 'completed'
            ],
            'failed_tasks': [
                task_id for task_id, status in self.task_progress.items()
                if status == 'failed'
            ],
            'current_objects': list(self.world_state.keys())
        }
        return summary

### 7.2 动态重规划

```python
class DynamicReplanner:
    """
    动态重规划器
    
    在执行过程中，如果遇到意外情况，需要重新规划
    """
    
    def __init__(self, reasoning_layer):
        self.reasoning_layer = reasoning_layer
        self.replan_count = 0
        self.max_replans = 5
    
    def check_need_replan(self, current_state, expected_state):
        """
        检查是否需要重规划
        
        触发条件：
        1. 物体位置与预期不符
        2. 技能执行失败
        3. 出现新的障碍物
        4. 超出预期时间
        """
        mismatches = []
        
        # 检查物体位置
        for obj_name in expected_state.get('objects', {}):
            if obj_name not in current_state.get('objects', {}):
                mismatches.append(f"Object {obj_name} not found")
            elif not self._positions_match(
                current_state['objects'][obj_name]['position'],
                expected_state['objects'][obj_name]['position'],
                threshold=0.05
            ):
                mismatches.append(f"Object {obj_name} at wrong position")
        
        return len(mismatches) > 0, mismatches
    
    def replan(self, current_context, original_plan, mismatches):
        """
        重新规划
        
        Args:
            current_context: 当前上下文
            original_plan: 原始计划
            mismatches: 不匹配项
        """
        if self.replan_count >= self.max_replans:
            raise Exception("Max replans exceeded")
        
        self.replan_count += 1
        
        # 构建重规划prompt
        replan_prompt = self._build_replan_prompt(
            current_context, original_plan, mismatches
        )
        
        # 调用VLM重新规划
        new_plan = self.reasoning_layer.replan(replan_prompt)
        
        return new_plan
    
    def _build_replan_prompt(self, context, original_plan, mismatches):
        """构建重规划prompt"""
        prompt = f"""
原始计划执行遇到问题，需要重新规划。

当前状态：
- 已完成任务：{context['task_progress']['completed']}
- 未完成任务：{context['task_progress']['pending']}
- 当前物体状态：{context['world_state']}

遇到的问题：
{chr(10).join(f"- {m}" for m in mismatches)}

原始计划：
{original_plan}

请根据当前状态和遇到的问题，制定新的执行计划。
新计划应该：
1. 避免重复已完成的任务
2. 解决遇到的问题
3. 保持任务目标不变
"""
        return prompt
```

### 8.1 评估指标

```python
class HierarchicalEvaluation:
    """
    层次化评估指标
    """
    
    def evaluate(self, model, test_tasks):
        """全面评估"""
        results = {
            'task_success_rate': [],
            'subtask_success_rate': [],
            'skill_accuracy': [],
            'planning_quality': [],
            'execution_efficiency': [],
            'recovery_success_rate': []
        }
        
        for task in test_tasks:
            # 执行任务
            execution_result = model.execute(task)
            
            # 评估各层
            results['task_success_rate'].append(
                self._evaluate_task_success(execution_result)
            )
            results['subtask_success_rate'].append(
                self._evaluate_subtask_success(execution_result)
            )
            results['skill_accuracy'].append(
                self._evaluate_skill_accuracy(execution_result)
            )
            results['planning_quality'].append(
                self._evaluate_planning_quality(execution_result)
            )
            results['execution_efficiency'].append(
                self._evaluate_efficiency(execution_result)
            )
            results['recovery_success_rate'].append(
                self._evaluate_recovery(execution_result)
            )
        
        # 汇总
        return {k: np.mean(v) for k, v in results.items()}
    
    def _evaluate_task_success(self, result):
        """评估任务成功率"""
        return 1.0 if result['final_state'] == 'task_completed' else 0.0
    
    def _evaluate_subtask_success(self, result):
        """评估子任务成功率"""
        completed = len([s for s in result['subtasks'] if s['status'] == 'completed'])
        total = len(result['subtasks'])
        return completed / total if total > 0 else 0.0
    
    def _evaluate_skill_accuracy(self, result):
        """评估技能选择准确性"""
        correct = 0
        total = 0
        for step in result['execution_steps']:
            if step['expected_skill'] == step['actual_skill']:
                correct += 1
            total += 1
        return correct / total if total > 0 else 0.0
    
    def _evaluate_planning_quality(self, result):
        """
        评估规划质量
        考虑：步骤数量、并行效率、约束满足
        """
        # 简化的评估：实际需要更复杂的指标
        num_steps = len(result['execution_steps'])
        optimal_steps = result.get('optimal_steps', num_steps)
        
        efficiency = optimal_steps / num_steps if num_steps > 0 else 0.0
        return min(efficiency, 1.0)
    
    def _evaluate_efficiency(self, result):
        """评估执行效率"""
        # 考虑时间、路径长度、重试次数
        time_efficiency = result['expected_time'] / result['actual_time']
        path_efficiency = result['optimal_path_length'] / result['actual_path_length']
        
        return (time_efficiency + path_efficiency) / 2
    
    def _evaluate_recovery(self, result):
        """评估错误恢复能力"""
        if result['num_failures'] == 0:
            return 1.0  # 没有失败，完美
        
        successful_recoveries = len([
            f for f in result['failures'] if f['recovered']
        ])
        
        return successful_recoveries / result['num_failures']
```

## 十、总结

π0.5代表了机器人基础模型的重要进化方向：

1. **从感知-动作到推理-规划-执行**：增加了显式的推理和规划能力
2. **从单步到长horizon**：支持复杂的多步骤任务
3. **从静态到动态**：能够根据执行情况动态调整计划
4. **从黑箱到可解释**：层次化架构提高了可解释性

这些改进使得π0.5能够处理更加复杂和真实的应用场景，是通向通用机器人智能的重要一步。
