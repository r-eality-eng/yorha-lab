Co-fine-tuning 深入：为什么不能只用机器人数据微调

RT-2 的核心训练问题是：既要让 VLM 学会“动作语言”，又不能把它原本的视觉语言知识洗掉。 Co-fine-tuning 本质是在“学新技能”和“保留旧能力”之间做平衡。

只用机器人数据

动作 loss 下降快，但 VLM 原有语义知识可能退化，模型变成“大号专用策略”。

只用图文数据

VLM 能力保持，但模型不会理解动作 token 的控制含义。

混合训练

让模型一边学习动作输出，一边持续看到原有视觉语言任务，缓解灾难性遗忘。

数据混合与损失：比例不是小细节

Co-fine-tuning 的效果高度依赖数据比例和 loss 权重。机器人数据太少，动作学不会；机器人数据权重太高，VLM 能力可能掉。

简化目标： L_total = λ_vl · L_vl + λ_robot · L_action。 其中 L_vl 保持视觉语言能力，L_action 训练动作 token。

涌现能力分析：真实迁移还是评估幻觉？

RT-2 的涌现能力来自 VLM 预训练知识和机器人动作学习的结合。但分析涌现能力时要谨慎： 成功可能来自语义迁移，也可能来自数据覆盖、视觉识别、prompt 偏差或评估任务过于简单。

离散 vs 连续动作：RT-2 的动作表示到底牺牲了什么

RT-2 选择离散动作 token，是为了和 VLM 语言建模接口统一。但机器人动作本质上是连续控制，离散化一定会带来精度和时序平滑问题。

离散动作表示

优点是可以直接用 CE loss 和 token prediction，训练稳定，适配 VLM。缺点是有量化误差，自回归步数随动作维度增加。

连续动作表示

优点是精度高、动作平滑、适合高频控制。缺点是很难直接塞进 LM 词表，需要额外 action head、Diffusion 或 Flow Matching。

混合方案

例如 π-FAST 用压缩 token 表示动作轨迹，π0 用 VLM 做语义推理，再用 Flow action expert 生成连续动作。

自回归 vs 并行：动作生成速度的关键矛盾

自回归生成能复用 LM 接口，但每个动作 token 依赖前一个 token。并行生成更快，但需要额外结构来保证动作维度之间协调。

FAST / 混合方案：为什么后续工作不满足于 256 bins

256 bins 对单步 7 维动作还可以接受，但如果要生成更长动作序列，token 数会迅速变多。 FAST 类方法尝试压缩动作序列，π0 类方法则把语义推理和连续动作生成解耦。

256 bins

简单直接，适合把动作塞进 VLM 词表，但长序列 token 开销大。

FAST / DCT 思路

对动作轨迹做频域压缩，用更少 token 表示一段动作。

π0 风格

VLM 负责理解任务，Flow Matching action expert 负责快速连续动作生成。

泛化评估：不能只说“模型更智能”

评估 VLA 泛化要拆层次。RT-2 的优势主要体现在语义、语言和组合泛化，但跨 embodiment、长程规划和真实部署仍然困难。

泛化层次

  1. 同任务新物体：杯子换成没见过的杯子。
  2. 同语义新表达：pick up 换成 grab。
  3. 组合泛化：见过红色、杯子、放置，但没见过红色杯子放到蓝碗。
  4. 常识泛化：找“能喝水的容器”。
  5. 跨 embodiment：换机器人、相机、动作空间。

面试问答：D101 的高区分度问题

高分回答模板： RT-2 的价值在于把 VLM 预训练知识迁移到机器人动作，但它不是最终形态。 Co-fine-tuning 解决动作学习与知识保持的平衡；涌现能力需要用消融和对照验证； 离散自回归动作带来统一建模优势，也带来速度和精度瓶颈。 下一代 VLA 的关键就是把 VLM 语义推理和高频连续动作生成更好地解耦。
Q1：Co-fine-tuning 为什么有效？如果不做会怎样？

它让模型在学习动作 token 的同时持续训练视觉语言任务，缓解灾难性遗忘。不做的话，模型可能退化成只会机器人数据分布内动作的专用策略，语义泛化下降。

Q2：RT-2 的涌现能力是真实的吗？

不能只凭 demo 判断。需要通过无 VLM 预训练、无图文混合、打乱语言、视觉遮挡等消融实验确认能力来源。更严谨的说法是：RT-2 展示了 VLM 知识迁移到动作的可能性，但能力边界仍需系统评估。

Q3：离散动作和连续动作未来哪个更有前景？

离散动作适合复用 LM 接口，训练稳定；连续动作更适合高精度高频控制。未来更可能是混合架构：VLM 做语义理解，专用连续动作模块负责控制。

Q4：如何评估一个 VLA 的泛化能力？

至少分物体、语言、组合、常识、场景和跨 embodiment 几个层次评估，并设置对照组、失败案例分析和视觉/策略错误拆分。

自测清单：看完是否真的理解 D101

1. 用一句话说明 D101 相比 D100 深在哪里。
D100 讲 RT-2 怎么工作，D101 讲它为什么有效、哪里会失败、如何评价和改进。
2. 为什么 co-fine-tuning 不是简单拼数据？
因为它涉及数据采样比例、loss权重和不同token位置的目标设计，本质是在动作学习和VLM能力保持之间做平衡。
3. RT-2 自回归动作生成的最大工程问题是什么？
推理延迟和错误累积。每个动作token依赖前一个token，生成多个动作维度需要多步解码，影响实时控制。

最终检查

  • 能解释 co-fine-tuning 的动机、公式和风险。
  • 能设计验证涌现能力的消融实验。
  • 能比较离散、连续、自回归、并行动作生成。
  • 能设计 VLA 泛化评估框架。

D101 → D102：为什么接下来学 Gato

D99-D101 都围绕机器人 VLA 展开：RT-1 是专用策略，RT-2 是 VLM→VLA。 D102 转向 Gato，是为了理解更一般的统一 tokenization 和 generalist agent 思想。

RT-1

机器人控制闭环：视觉、语言、动作。

RT-2

把动作纳入 VLM 的 token 生成范式。

Gato
