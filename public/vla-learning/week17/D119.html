VLA 技术演进时间线

三条技术路线

VLM-based

RT-2 / OpenVLA

把视觉语言模型的知识迁移到机器人动作。优势是语言和视觉理解强，代价是动作离散化、延迟和部署复杂度。

Continuous Generation

π0 / RDT / DiT

用 Flow Matching、Diffusion 或 DiT 生成连续动作。优势是精度和多峰分布，代价是采样/求解成本。

Hybrid

π0.5 / FAST / HPT

通过层次化推理、动作 tokenizer 或异构表征组合能力。优势是可扩展，代价是系统复杂。

核心 Trade-off

速度 vs 质量

离散 token 和回归 head 快；Flow/Diffusion 动作质量强，但要控制采样步数。

泛化 vs 部署

大 VLM 泛化强，但延迟、显存、量化、安全边界和工程成本更高。

确定性 vs 多样性

回归稳定但可能平均化；扩散采样能覆盖多解动作，但要控随机性和安全。

短 Horizon vs 长 Horizon

短 action chunk 易训练；长任务需要任务图、技能状态机、失败检测和重规划。

五分钟面试脚本

先定义问题：VLA 是把视觉、语言和机器人动作统一起来，让模型能根据图像观测和自然语言指令输出可执行动作。

讲演进：RT-1 任务特化，RT-2 引入 VLM 迁移，Octo/OpenVLA 推动开源复现，π0 用 Flow Matching 改善连续动作，π0.5/FAST/HPT/RDT/DiT 分别推进长任务、动作表示、异构表征和扩散缩放。

讲路线：VLM-based 强在语言视觉理解，continuous generation 强在连续动作质量，hybrid/hierarchical 强在长任务和工程组合。

给判断：实际项目按约束选，不背模型名。低延迟选 compact/HPT，复杂动作选 π0/RDT/DiT，长 horizon 选层次化，正式报告必须带统一 benchmark 和延迟统计。

面试速查卡

RT-2 / OpenVLA

共同点是 VLM-based：利用视觉语言预训练能力迁移到机器人动作。回答时强调语言泛化和动作 token 的取舍。

π0

关键是 VLM 理解 + Flow Matching action expert，代表从离散动作 token 转向高质量连续动作生成。

FAST

解决 action token 效率：沿时间维做频域压缩，用更少 token 表示更长、更平滑的动作 chunk。

HPT

适合多机器人、多模态、多任务的统一表征和迁移，优势是模块化和低延迟。

RDT / DiT

适合复杂连续动作、多峰轨迹和高质量生成，代价是采样延迟和训练部署成本。

π0.5

回答长 horizon 时重点讲任务分解、技能规划、失败检测和动态重规划，不是简单预测更长动作序列。

自测

1. 为什么不能直接比较不同论文的成功率？
因为机器人、任务集、硬件、控制频率、采样步数、episode 数和失败判定都可能不同。没有统一 benchmark 时只能讲趋势。
2. π0 相比 RT-2/OpenVLA 的关键变化是什么？
从离散 action token 路线转向 VLM + Flow Matching action expert，更强调连续动作生成质量。
3. 长 horizon VLA 为什么需要层次化？
因为长任务不只是输出更长动作序列，还需要任务分解、状态跟踪、失败检测、技能选择和动态重规划。

最终总结

D119 的一句话总结：VLA 演进不是单一路线胜出，而是在速度、质量、泛化、部署、确定性、多样性和长 horizon 之间不断重新分配工程预算。
